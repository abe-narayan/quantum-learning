export const binaryEntropyTerm = (lambda) => {
  if (lambda <= 1e-12) return 0;
  return -lambda * Math.log2(lambda);
}

export const jointEntropyOfDephasedBell = (rhoPrime) => {
  const outerBlock = new Matrix([
    [rhoPrime.get(0, 0), rhoPrime.get(0, 3)],
    [rhoPrime.get(3, 0), rhoPrime.get(3, 3)],
  ]);
  const innerBlock = new Matrix([
    [rhoPrime.get(1, 1), rhoPrime.get(1, 2)],
    [rhoPrime.get(2, 1), rhoPrime.get(2, 2)],
  ]);
  const eigs = [...eigenvaluesHermitian2x2(outerBlock), ...eigenvaluesHermitian2x2(innerBlock)];
  return eigs.reduce((sum, lam) => sum + binaryEntropyTerm(lam), 0);
}

export const mutualInformationAfterDephasingB = (lambda) => {
  const krausOnB = dephasingChannel(lambda).map((K) => IDENTITY.tensor(K));
  const rhoPrime = applyKrausChannel(rhoBell, krausOnB);
  const rhoA = partialTrace(rhoPrime, 2, [1]);
  const rhoBmarg = partialTrace(rhoPrime, 2, [0]);
  const S_A = vonNeumannEntropy(rhoA);
  const S_B = vonNeumannEntropy(rhoBmarg);
  const S_AB = jointEntropyOfDephasedBell(rhoPrime);
  return { S_A, S_B, S_AB, I: S_A + S_B - S_AB };
}

## Processing Cannot Create Information

Quantum Entropy and Information Measures defined quantum mutual
information $I(A:B)=S(A)+S(B)-S(AB)$ and computed $I(A:B)=2$ bits for a
Bell pair, the maximum two qubits can share. A natural next question:
what happens to that shared information if $B$'s qubit is then sent
down a noisy channel, or handed to an eavesdropper, or measured
and forgotten? Intuition says it can only get worse: you cannot learn
more about $A$ from a *processed* copy of $B$ than from $B$ itself. This
lesson turns that intuition into an actual theorem, derives its most
useful corollary in full, and checks it against a computed number.

## Monotonicity, and What Follows From It

### The monotonicity theorem

<TheoremBox title="Monotonicity of quantum relative entropy (data-processing for S(.||.))" provenance="cited">

**Hypotheses.** $\rho$ and $\sigma$ are density matrices on the same
finite-dimensional Hilbert space, and $\mathcal N$ is CPTP. Nothing is
assumed about commutation or purity, and the supports need not nest: if
$\text{supp}(\rho)\not\subseteq\text{supp}(\sigma)$ the right-hand side
is $+\infty$ by the convention of the previous course and the inequality
holds trivially. Where complete positivity is load-bearing is the
corollary below rather than the bare inequality: the corollary applies
$\text{id}_A\otimes\mathcal N$ to a bipartite state, and only complete
positivity guarantees that map sends states to states at all.
Transposition is the standard witness that mere positivity does not:
Relative Entropy and Mixed-State Entanglement's Werner state at $p=0.7$
has a partial transpose with eigenvalue $-0.275$, so
$\text{id}_A\otimes T$ carries a legitimate density matrix to something
that is not one, and the corollary's very first step would have nothing
to work with.

For any two density matrices $\rho,\sigma$ on a system, and any
completely positive trace-preserving (CPTP) map $\mathcal N$ (any
physical channel, in the Stinespring Dilation and Channel Purification
sense: a unitary on a larger space followed by discarding an ancilla):

<EquationReveal
  terms={[
    { id: "N", symbol: "𝒩", gloss: "Any physical (CPTP) channel, meaning a unitary on a larger space followed by discarding an ancilla." },
    { id: "lhs", symbol: "S(𝒩(ρ)‖𝒩(σ))", gloss: "Relative entropy between the two states after both have gone through the same channel." },
    { id: "rhs", symbol: "S(ρ‖σ)", gloss: "Relative entropy between the two original, unprocessed states." },
  ]}
>

$$
S\big(\mathcal N(\rho)\,\big\|\,\mathcal N(\sigma)\big) \;\leq\; S(\rho\|\sigma)
$$

</EquationReveal>

Since relative entropy measures how distinguishable $\sigma$ is from
the true state $\rho$, this says: **no physical operation can ever make
two states easier to tell apart than they already were.** Processing
can only destroy distinguishing information, never create it.

**Equality condition.** The inequality is saturated precisely when the
channel is *reversible on this particular pair*: there exists a CPTP map
$\mathcal R$ with $\mathcal R(\mathcal N(\rho))=\rho$ and
$\mathcal R(\mathcal N(\sigma))=\sigma$, and it can always be taken to be
the **Petz recovery map** built from $\sigma$ and $\mathcal N$ (Petz,
1986). Note what this does *not* say. It does not require $\mathcal N$
to be invertible as a map, only that nothing separating these two states
was destroyed. A channel can be badly lossy overall and still lose
nothing that distinguishes $\rho$ from $\sigma$.

</TheoremBox>

<Callout type="note">
**This proof is out of scope here, and that is stated
outright rather than glossed over.** Klein's inequality (Relative
Entropy and Mixed-State Entanglement) proved $S(\rho\|\sigma)\geq0$ for
a *fixed* pair of states using two applications of Jensen's inequality
on scalars. The monotonicity theorem above is a different, harder
statement: it compares $S(\rho\|\sigma)$ *before and after* a channel,
and its standard proofs (Lindblad, 1975; Uhlmann, 1977) go through
either **strong subadditivity** of von Neumann entropy (Lieb and Ruskai,
1973) or the joint convexity of relative entropy, both of which rest in
turn on **Lieb's concavity theorem** and the **operator convexity** of
$x\mapsto x\log x$ (a statement about matrix-valued, not scalar,
convexity), machinery this platform has not built. It is
stated here as a precisely-quoted theorem, not derived. See
Nielsen & Chuang, *Quantum Computation and Quantum Information*, §11.3,
or Wilde, *Quantum Information Theory*, Ch. 11, for the full proof.
</Callout>

**Why it has to be true, physically.** A channel $\mathcal N$ is not an
abstract map. It is *literally* something that can happen to a
system: append an ancilla, evolve unitarily, discard part of the
result. Suppose the inequality failed, so some channel existed that
*increased* $S(\mathcal N(\rho)\|\mathcal N(\sigma))$ above
$S(\rho\|\sigma)$. Chain enough copies of that channel together and the
gap between two states that started only slightly different could be
amplified without bound, until two non-orthogonal states could be told
apart with certainty using nothing but ordinary physical evolution and
no measurement postulate at all. That is exactly
the kind of thing linearity forbids: it is the same structural fact
behind no-cloning (no physical process can be built that reliably
distinguishes or copies arbitrary non-orthogonal states). Monotonicity
of relative entropy is the distinguishability-flavored statement of
"you cannot get something for nothing" that no-cloning is the
copying-flavored statement of.

<InsightBlock>
  Monotonicity is the same "no free lunch" structure that underlies
  no-cloning, restated in the currency of relative entropy rather than
  copying. A channel can spend distinguishability; it can never mint it.
</InsightBlock>

### The corollary: data processing for mutual information

Take a bipartite state $\rho_{AB}$ and a channel $\mathcal N$ acting on
$B$ alone, producing $B'=\mathcal N(B)$, a Markov chain
$A\to B\to B'$, since $B'$ is built from $B$ with no further access to
$A$. Claim: $I(A:B)\geq I(A:B')$.

<DerivationSteps>
  <DerivationStep annotation="For any bipartite state, compare rho_AB to the product of its own marginals rho_A ⊗ rho_B. Since log2(rho_A ⊗ rho_B) = log2(rho_A) ⊗ I + I ⊗ log2(rho_B) for operators on separate factors, the second trace term splits into -S(A)-S(B), while the first is -S(AB) by definition.">
    $$
    S(\rho_{AB}\,\|\,\rho_A\otimes\rho_B) = \text{Tr}(\rho_{AB}\log_2\rho_{AB}) - \text{Tr}\big(\rho_{AB}\log_2(\rho_A\otimes\rho_B)\big)
    $$

    $$
    S(\rho_{AB}\|\rho_A\otimes\rho_B) = S(A)+S(B)-S(AB) = I(A:B)
    $$

    Mutual information *is* the relative entropy between the true joint
    state and the (wrong, but marginal-matching) product state.
  </DerivationStep>
  <DerivationStep annotation="Apply id_A ⊗ N to both sides. Tracing a trace-preserving map out again reproduces the original trace, so rho_AB'’s marginal on A is still exactly rho_A; its marginal on B' is N(rho_B) = rho_B' by definition. So Step 1's identity applies again to the primed state without modification.">
    On the left, $(\text{id}_A\otimes\mathcal N)(\rho_{AB})=\rho_{AB'}$,
    the post-channel joint state. On the right,
    $(\text{id}_A\otimes\mathcal N)(\rho_A\otimes\rho_B)=\rho_A\otimes\mathcal N(\rho_B)=\rho_A\otimes\rho_{B'}$.

    $$
    S(\rho_{AB'}\|\rho_A\otimes\rho_{B'}) = I(A:B')
    $$
  </DerivationStep>
  <DerivationStep annotation="Monotonicity, applied to this pair of states and this channel, then substituting Steps 1 and 2 into the left and right sides directly.">
    $$
    S\big((\text{id}_A\otimes\mathcal N)(\rho_{AB})\,\big\|\,(\text{id}_A\otimes\mathcal N)(\rho_A\otimes\rho_B)\big) \leq S(\rho_{AB}\|\rho_A\otimes\rho_B)
    $$

    $$
    \boxed{I(A:B') \leq I(A:B)}
    $$
  </DerivationStep>
</DerivationSteps>

This is a corollary, not a re-assertion of the same theorem under a new
name: it required identifying the *specific* pair of states
($\rho_{AB}$ and $\rho_A\otimes\rho_B$) for which the abstract
monotonicity statement collapses exactly onto the mutual-information
identity.

## What B Can Never Recover Alone

- **LOCC cannot increase entanglement.** Any protocol built from local
  operations and classical communication is, from $B$'s side alone, a
  sequence of local channels applied to $B$'s share of an entangled
  pair (plus classical messages, which do not touch the quantum state
  at all). The <Term id="data-processing-inequality">data-processing inequality</Term> applied to each local step
  says $A$'s correlation with $B$'s (evolving) share can only fall or
  hold steady, never rise: the quantitative reason entanglement is a
  resource that LOCC can spend but never manufacture.
- **QKD security proofs are built directly on this inequality.** In a
  protocol like BB84, an eavesdropper's information about the final key
  is bounded by treating their interaction with the transmitted qubits
  as the channel $\mathcal N$ in the corollary above: whatever
  correlation Eve's measurement device ends up holding with Alice's
  bits is bounded by the correlation Alice and Bob's *un-eavesdropped*
  qubits would have had, precisely because Eve's device is $B'$, one
  more processing step downstream of $B$.
- **This is the direct quantum generalization of the classical Data
  Processing Inequality.** Classically, for a Markov chain
  $X\to Y\to Z$ (i.e. $Z=g(Y)$ or more generally $Z$ depends on $Y$
  alone), $I(X:Y)\geq I(X:Z)$: you cannot learn more about $X$ from
  any function or noisy version of $Y$ than from $Y$ itself. The
  derivation above is the same statement with classical
  distributions replaced by density matrices and Shannon entropy
  replaced by von Neumann entropy throughout.

## Worked Example: dephasing one half of a Bell pair

Start from $|\Phi^+\rangle=\tfrac1{\sqrt2}(|00\rangle+|11\rangle)$,
built with this platform's own `StateVector` and
`pureStateDensityMatrix`, the same state Quantum Entropy and
Information Measures used for its $I(A:B)=2$ bits maximum. Apply the
existing `dephasingChannel(lambda)` from Open Quantum Systems and
Kraus Operators to qubit $B$ **only**, via
`IDENTITY.tensor(K)` for each Kraus operator $K$, and
`applyKrausChannel`.

Because `dephasingChannel`'s Kraus operators are themselves diagonal in
the computational basis ($K_0\propto I$, $K_1\propto\sigma_z$),
$I\otimes K_0$ and $I\otimes K_1$ are diagonal too. Conjugating a matrix
by diagonal matrices, $(D\rho D^\dagger)_{ij}=D_{ii}\,\rho_{ij}\,\overline{D_{jj}}$,
can never move a zero entry off zero, so $\rho_{AB}'$ keeps the same
support as the original Bell state: nonzero only at the four
corners $\{|00\rangle,|11\rangle\}\times\{|00\rangle,|11\rangle\}$. That
is a real structural fact about diagonal channels, not a coincidence
specific to this state, and it is what makes the following
computation land back on `eigenvaluesHermitian2x2` (this platform's
$2\times2$-only closed-form eigensolver) despite the joint state living
on four dimensions, the same "block-diagonal, structurally special
case" pattern Relative Entropy and Mixed-State Entanglement used for
the Werner state.

Working it out (Klein-style diagonal conjugation, $\lambda\in[0,1]$):

$$
\rho_{AB}' = \begin{pmatrix} 0.5 & 0 & 0 & 0.5(1-\lambda) \\ 0 & 0 & 0 & 0 \\ 0 & 0 & 0 & 0 \\ 0.5(1-\lambda) & 0 & 0 & 0.5 \end{pmatrix}
$$

The middle $2\times2$ block (the $\{|01\rangle,|10\rangle\}$ subspace)
is identically zero, contributing two zero eigenvalues; the outer block
$\left(\begin{smallmatrix}0.5 & 0.5(1-\lambda)\\ 0.5(1-\lambda) & 0.5\end{smallmatrix}\right)$
has eigenvalues $1-\lambda/2$ and $\lambda/2$ by
`eigenvaluesHermitian2x2`. So $S(AB')=-[(1-\tfrac\lambda2)\log_2(1-\tfrac\lambda2)+\tfrac\lambda2\log_2\tfrac\lambda2]$.
Both reduced marginals stay maximally mixed for every
$\lambda$ (dephasing never touches populations, computed directly via
`partialTrace` and confirmed at $S_A=S_B=1$ bit throughout), so

$$
I(A:B') = S_A+S_B-S_{AB}' = 2 - S_{AB}'(\lambda)
$$

## Confusing Monotonicity With Entropy Increase

<Callout type="warning">
**Confusing "channels can't increase distinguishability" with "channels
can't increase entropy."** The theorem in this lesson is about
*relative* entropy between two states (or, via the corollary, mutual
information between two systems), not the entropy $S(\rho)$ of a
single state. $S(\rho)$ itself is **not** monotonic under a general
channel: amplitude damping applied to a maximally mixed qubit *lowers*
its entropy (it relaxes toward the pure ground state), and plenty of
channels raise a low-entropy state's entropy. What never increases is
the *relative* quantity: how distinguishable two states, or how
correlated two systems, remain.
</Callout>

<Callout type="warning">
**Applying the mutual-information corollary to a channel that touches
*both* $A$ and $B$.** The derivation above depends on
$(\text{id}_A\otimes\mathcal N)(\rho_A\otimes\rho_B)=\rho_A\otimes\mathcal N(\rho_B)$
in Step 2, true only because $\mathcal N$ leaves $A$'s factor alone.
If the channel entangles or otherwise acts across both shares (not
$\text{id}_A\otimes\mathcal N$ but some jointly-acting
$\mathcal N_{AB}$), $A$'s own marginal changes too, Step 1's identity no
longer reproduces $I(A:B')$ on the nose, and the clean corollary does
not apply; only the more general (and less immediately useful) raw
monotonicity statement does.
</Callout>

## Practice Questions

1. Confirm from the theorem's equality condition (the reversibility
   condition stated in the theorem box above) that a **unitary** channel leaves
   $S(\rho\|\sigma)$ exactly unchanged, and explain why this makes
   sense given that a unitary is reversible.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The equality condition asks for a CPTP map $\mathcal R$ that undoes
   $\mathcal N$ on both states, and for $\mathcal N(\cdot)=U\cdot U^\dagger$
   there is an obvious candidate: $\mathcal R(\cdot)=U^\dagger\cdot U$,
   which is itself a unitary channel, hence CPTP. It satisfies
   $\mathcal R(\mathcal N(\rho))=U^\dagger U\rho U^\dagger U=\rho$ and the
   same for $\sigma$. So the inequality is saturated and
   $S(U\rho U^\dagger\|U\sigma U^\dagger)=S(\rho\|\sigma)$.

   The same conclusion falls out of monotonicity alone, without invoking
   the equality condition at all, which is worth seeing because it needs no
   theory beyond the inequality itself. Apply the inequality once forwards,

   $$
   S(U\rho U^\dagger\|U\sigma U^\dagger)\leq S(\rho\|\sigma),
   $$

   and once with the channel $\mathcal R$ applied to the transformed pair,

   $$
   S(\rho\|\sigma)=S\big(U^\dagger(U\rho U^\dagger)U\,\big\|\,U^\dagger(U\sigma U^\dagger)U\big)\leq S(U\rho U^\dagger\|U\sigma U^\dagger).
   $$

   Two inequalities in opposite directions force equality. Any invertible
   channel whose inverse is also a channel is pinned this way.

   Direct computation agrees, and shows where the invariance lives.
   Functional calculus gives $\log_2(UAU^\dagger)=U(\log_2 A)U^\dagger$,
   because unitary conjugation carries the spectral decomposition of $A$ to
   that of $UAU^\dagger$ without touching the eigenvalues. Then cyclicity
   of the trace removes every $U$:

   $$
   \mathrm{Tr}\big(U\rho U^\dagger\log_2(U\sigma U^\dagger)\big)=\mathrm{Tr}\big(U\rho\log_2\sigma\,U^\dagger\big)=\mathrm{Tr}(\rho\log_2\sigma).
   $$

   The physical reading is the cleanest of the three. Distinguishability is
   a statement about what measurements can reveal, and a unitary just
   relabels the measurements: the statistics of measuring $U\rho U^\dagger$
   with a POVM $\{E_i\}$ are identical to measuring $\rho$ with
   $\{U^\dagger E_iU\}$, which is an equally valid POVM. No experiment can
   tell the two situations apart, so no measure of distinguishability may
   either.

   One thing not to over-read. The equality condition says "reversible on
   this pair", which is weaker than "unitary". A badly lossy channel can
   still saturate the inequality for a particular $\rho,\sigma$, provided
   nothing that separated *those two* states was discarded. Saturation is
   evidence about a pair, not a certificate that the channel is invertible.

   </details>

2. Using the worked example's formula $I(A:B')=2-S(AB')(\lambda)$,
   compute $I(A:B')$ at $\lambda=0.6$ and confirm it lies strictly
   between the $\lambda=0.4$ and $\lambda=0.8$ table values.

   <details className="answer-reveal">
   <summary>Answer</summary>

   $I(A:B')=1.118709$ bits, sitting between $1.278072$ at $\lambda=0.4$ and
   $1.029049$ at $\lambda=0.8$, as required.

   The outer block's eigenvalues are $1-\lambda/2$ and $\lambda/2$, so at
   $\lambda=0.6$ they are $0.7$ and $0.3$:

   $$
   S(AB')=-0.7\log_20.7-0.3\log_20.3=0.360201+0.521090=0.881291,
   $$

   $$
   I(A:B')=2-0.881291=1.118709\ \text{bits}.
   $$

   Betweenness is not luck here. $S(AB')=H(1-\lambda/2,\lambda/2)$ is a
   binary entropy of an argument moving monotonically from $0$ toward
   $1/2$ as $\lambda$ runs $0\to1$, and binary entropy increases
   monotonically on $[0,1/2]$. So $S(AB')$ increases and $I(A:B')$
   decreases, strictly, over the whole range. Data processing guarantees
   only $I(A:B')\leq2$; the monotone decrease in $\lambda$ is an extra fact
   about this particular family, coming from the entropy function's shape.

   The shape is the part worth taking away. Binary entropy has infinite
   slope at the endpoint, so the curve falls steeply at first and then
   flattens: the first fifth of the noise ($\lambda=0$ to $0.2$) destroys
   $0.469$ bits, while the last fifth ($0.8$ to $1.0$) destroys only
   $0.029$. Sixteen times as much damage per unit of noise at the start.
   Two practical readings follow. A nearly clean channel is fragile, so
   small imperfections cost far more than a linear estimate suggests. And a
   badly degraded channel is robust, so once the coherence is mostly gone,
   further noise takes very little.

   And the curve stops at $1$ bit rather than $0$, because the Bell pair's
   population correlation is invisible to dephasing. Half the ebit's two
   bits was classical all along and this channel cannot touch it.

   </details>

3. Explain, in your own words, why the Markov-chain structure
   $A\to B\to B'$ (not $A\to B'$ directly, and not a channel touching
   $A$ too) is exactly the condition the corollary's derivation needs.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because the derivation feeds monotonicity a very specific pair of
   states, "the joint state" and "the product of its own marginals", and it
   needs that description to survive the channel. Only a map of the form
   $\mathrm{id}_A\otimes\mathcal N$ preserves it.

   Two separate things have to hold, and the Markov condition supplies both.

   **$A$'s marginal must not change.** Step 1's identity
   $S(\rho_{AB}\|\rho_A\otimes\rho_B)=I(A:B)$ is applied again to the
   output, so the second argument must be the product of the *output*
   state's marginals. On the $A$ side that means $\rho_A$ has to still be
   $\rho_A$ afterwards. It is, because $\mathcal N$ acts only on $B$ and is
   trace-preserving, so $\mathrm{Tr}_{B'}(\mathrm{id}\otimes\mathcal N)(\rho_{AB})=\mathrm{Tr}_B\rho_{AB}=\rho_A$.

   **The product structure must be preserved.** Step 2 needs
   $(\mathrm{id}_A\otimes\mathcal N)(\rho_A\otimes\rho_B)=\rho_A\otimes\rho_{B'}$,
   which is true exactly because the map factors across the tensor product.
   A jointly-acting $\mathcal N_{AB}$ sends a product state to something
   correlated, and then the right-hand argument of the relative entropy is
   no longer a product of anything, so it stops computing a mutual
   information.

   That is what "no further access to $A$" buys, and it is the direct
   translation of the classical Markov condition $p(z|x,y)=p(z|y)$: $Z$ is
   manufactured from $Y$ alone, so whatever it knows about $X$ it learned
   through $Y$.

   The failure without it is not subtle, and a single example settles it.
   Take $\rho_A=|{+}\rangle\langle{+}|$ and $\rho_B=|0\rangle\langle0|$, a
   product state with $I(A:B)=0$. Apply a CNOT across both qubits, which is
   a perfectly legitimate CPTP map, and the output is $|\Phi^+\rangle$ with
   $I(A:B')=2$ bits. Correlation created from nothing, from zero to the
   two-qubit maximum, in one gate. Nothing about monotonicity was violated;
   the corollary simply does not apply to a channel that touches both
   halves.

   The distinction worth carrying is that the *theorem* survives a joint
   channel and the *corollary* does not. Monotonicity of relative entropy
   holds for every CPTP map without exception. What the locality hypothesis
   buys is the identification of both sides of that inequality with mutual
   informations, which is what makes the abstract statement usable. This is
   also why the LOCC and QKD applications insist so carefully that each
   step is local: every one of them is an invocation of the corollary, and
   a step that acted jointly would break the chain of reasoning rather than
   merely weakening it.

   </details>

## Summary

- Quantum relative entropy is monotonic under any physical (CPTP)
  channel, $S(\mathcal N(\rho)\|\mathcal N(\sigma))\leq S(\rho\|\sigma)$,
  stated precisely and motivated physically here, with the full
  proof explicitly cited (Nielsen & Chuang; Wilde) rather than
  re-derived, since it needs operator-convexity machinery beyond this
  platform's scope.
- Applied to $\rho_{AB}$ vs. $\rho_A\otimes\rho_B$ pushed through
  $\text{id}_A\otimes\mathcal N$, this yields the fully derived
  corollary $I(A:B)\geq I(A:B')$ for any Markov chain $A\to B\to B'$.
- Verified numerically: dephasing one half of a Bell pair
  ($I(A:B)=2$ bits) drives $I(A:B')$ down monotonically to $1$ bit as
  $\lambda\to1$, computed exactly via this platform's own
  `dephasingChannel`, `partialTrace`, and `eigenvaluesHermitian2x2`,
  never once violating the bound.
- The same inequality is the quantitative backbone of LOCC entanglement
  monotonicity, QKD eavesdropper-information bounds, and is the direct
  quantum lift of the classical Data Processing Inequality.
