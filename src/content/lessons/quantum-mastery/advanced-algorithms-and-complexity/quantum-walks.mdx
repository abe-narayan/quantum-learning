export function hadamardWalk(steps) {
  const size = 2 * steps + 1;
  const offset = steps;
  let up = new Array(size).fill(Complex.ZERO);
  let down = new Array(size).fill(Complex.ZERO);
  const s = Math.SQRT1_2;
  up[offset] = new Complex(s, 0);
  down[offset] = new Complex(0, s);

  for (let t = 0; t < steps; t++) {
    const newUp = new Array(size).fill(Complex.ZERO);
    const newDown = new Array(size).fill(Complex.ZERO);
    for (let x = 0; x < size; x++) {
      const a0 = up[x];
      const a1 = down[x];
      const coinUp = a0.add(a1).scale(s);
      const coinDown = a0.sub(a1).scale(s);
      if (x - 1 >= 0) newUp[x - 1] = newUp[x - 1].add(coinUp);
      if (x + 1 < size) newDown[x + 1] = newDown[x + 1].add(coinDown);
    }
    up = newUp;
    down = newDown;
  }

  const probs = new Array(size).fill(0);
  let variance = 0;
  for (let x = 0; x < size; x++) {
    const p = up[x].magnitudeSquared() + down[x].magnitudeSquared();
    probs[x] = p;
    const pos = x - offset;
    variance += pos * pos * p;
  }
  return { probs, variance, offset };
}

export function classicalWalk(steps) {
  const size = 2 * steps + 1;
  const offset = steps;
  let p = new Array(size).fill(0);
  p[offset] = 1;
  for (let t = 0; t < steps; t++) {
    const next = new Array(size).fill(0);
    for (let x = 0; x < size; x++) {
      if (p[x] === 0) continue;
      if (x - 1 >= 0) next[x - 1] += 0.5 * p[x];
      if (x + 1 < size) next[x + 1] += 0.5 * p[x];
    }
    p = next;
  }
  let variance = 0;
  for (let x = 0; x < size; x++) {
    const pos = x - offset;
    variance += pos * pos * p[x];
  }
  return { probs: p, variance, offset };
}

export function reachablePositions(offset) {
  const positions = [];
  for (let i = 0; i <= 2 * offset; i++) {
    if ((i - offset) % 2 === 0) positions.push(i);
  }
  return positions;
}

export function walkGraphNodes(result) {
  const idxs = reachablePositions(result.offset);
  const mean = 1 / idxs.length;
  return idxs.map((i, k) => ({
    id: String(i - result.offset),
    label: String(i - result.offset),
    x: 0.04 + (k / (idxs.length - 1)) * 0.92,
    y: 0.5,
    group: result.probs[i] > mean ? 1 : 0,
  }));
}

export function walkGraphEdges(nodes) {
  const edges = [];
  for (let k = 0; k < nodes.length - 1; k++) {
    edges.push({ from: nodes[k].id, to: nodes[k + 1].id });
  }
  return edges;
}

## Diffusive Against Ballistic

A classical random walker on a line diffuses: after $T$ steps its
typical displacement is $O(\sqrt T)$, the signature of a sum of
independent random steps (the central limit theorem). The quantum
walker's ballistic spread is not a vague claim about "quantum
speedup": it's a precise,
derivable fact about interference between paths that a classical walk's
independent, memoryless steps can never produce, and it's the mechanism
<Term id="quantum-walks">behind quantum walk search algorithms</Term> achieving the same quadratic
Grover-style speedup on graph search problems.

## The Coin, the Shift, and the Dispersion Relation

### The coined walk: coin operator and conditional shift

The walker's Hilbert space is $\mathcal{H}_{\text{position}}\otimes
\mathcal{H}_{\text{coin}}$: an unbounded position register (indexed by
integer $x$) tensored with a single qubit "coin," $\{|\uparrow\rangle,
|\downarrow\rangle\}$. One step is coin-flip-then-shift:

$$
W = S\cdot(I\otimes H), \qquad H=\frac1{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}
$$

$H$ is the ordinary Hadamard gate, now interpreted as mixing "move left"
and "move right" instead of $|0\rangle,|1\rangle$. $S$ is the
**conditional shift**: $S|x\rangle|\uparrow\rangle=|x-1\rangle
|\uparrow\rangle$, $S|x\rangle|\downarrow\rangle=|x+1\rangle
|\downarrow\rangle$, move left if the coin reads $\uparrow$, right if
$\downarrow$, entangling position with coin at every single step. Both
$H$ (unitary on the coin) and $S$ (a pure permutation of an orthonormal
basis, hence unitary) are unitary, so $W$ is unitary and the walk is
norm-preserving quantum evolution, not a classical Markov chain
dressed up in bra-ket notation.

Starting from $|0\rangle\otimes|\psi_c\rangle$ and applying $W$ exactly
$T$ times gives the walk's state after $T$ steps; measuring position
gives a probability distribution over $x$, like the classical
walk's distribution over final positions after $T$ coin flips, but built
from *interfering amplitudes* rather than summed probabilities.

**Initial coin state.** Starting in $|\uparrow\rangle$ produces an
asymmetric distribution (the Hadamard coin doesn't treat $\uparrow$ and
$\downarrow$ symmetrically). The standard fix (Konno 2002, cited here)
is the symmetric initial coin state
$|\psi_c\rangle=\frac1{\sqrt2}(|\uparrow\rangle+i|\downarrow\rangle)$,
which makes the resulting position distribution exactly symmetric under
$x\to-x$, the choice used throughout this lesson's numerics below.

### Why the spreading is ballistic: the dispersion relation

Because the walk is translation-invariant (every position behaves
identically), it's diagonalized by momentum eigenstates $|k\rangle$,
as in Momentum Space and the Fourier Transform: translation by
one unit acts on $|k\rangle$ as multiplication by a pure phase.

One piece of bookkeeping deserves to be said out loud, because the
finite-dimensional habit of "diagonalize the matrix" does not apply
here. The position register is $\ell^2(\mathbb Z)$, which is
infinite-dimensional, and $W$ acts on
$\ell^2(\mathbb Z)\otimes\mathbb C^2$. The states $|k\rangle$ are *not*
eigenvectors of $W$ in that space: they are not square-summable, exactly
as the plane waves $e^{ipx/\hbar}$ are not in $L^2(\mathbb R)$. What is
true is that the discrete-time Fourier transform is a unitary
$\ell^2(\mathbb Z)\cong L^2([-\pi,\pi))$ carrying $W$ to multiplication
by the $2\times2$ matrix family $W(k)$, so $W$ has purely *absolutely
continuous* spectrum, filling the two bands
$e^{i(\pi/2\pm\omega(k))}$ and containing no eigenvalues at all. That is
why "the eigenvalues of $W(k)$" below is a legitimate calculation while
"the eigenvectors of $W$" would not be, and it is the same
direct-integral decomposition the Hilbert space course makes precise. The
band structure is also what makes the whole argument work: an operator
with a pure point spectrum would give a walk that never spreads.

Shifting
by $-1$ (the $\uparrow$ branch) contributes phase $e^{ik}$, shifting by
$+1$ (the $\downarrow$ branch) contributes $e^{-ik}$, so in the
$2$-dimensional coin subspace at fixed momentum $k$, one step acts as
the $2\times2$ unitary

$$
W(k) = \begin{pmatrix}e^{ik}&0\\0&e^{-ik}\end{pmatrix}H = \frac1{\sqrt2}\begin{pmatrix}e^{ik}&e^{ik}\\e^{-ik}&-e^{-ik}\end{pmatrix}
$$

Its trace is $\frac{e^{ik}-e^{-ik}}{\sqrt2}=i\sqrt2\sin k$, and its
determinant is $(1)(-1)=-1$. Writing $W(k)$'s two eigenvalues as
$e^{i(\pi/2\pm\omega(k))}$ (a valid parametrization exactly when their
product is $-1$, matching the determinant), their sum is
$i\cdot2\cos\omega(k)$, so matching the trace:

$$
\boxed{\cos\omega(k) = \frac{\sin k}{\sqrt2}}
$$

a derived **dispersion relation**. Since $|\sin k|\leq1$,
$\cos\omega(k)\in[-\tfrac1{\sqrt2},\tfrac1{\sqrt2}]$ always; $\omega(k)$
never approaches $0$ or $\pi$, unlike a classical walk's trivial
"dispersion." Differentiating $\cos\omega=\sin(k)/\sqrt2$ implicitly:

$$
v(k) \equiv \frac{d\omega}{dk} = \frac{-\cos k}{\sqrt2\sin\omega(k)}, \qquad \sin\omega(k)=\sqrt{1-\tfrac{\sin^2k}2}
$$

so $v(k)^2=\dfrac{\cos^2k}{2-\sin^2k}=\dfrac{\cos^2k}{1+\cos^2k}$, an
increasing function of $u=\cos^2k\in[0,1]$, maximized at $u=1$ ($k=0$ or
$\pi$): $v_{\max}^2=\tfrac12$, i.e. $v_{\max}=\tfrac1{\sqrt2}$.

A wavepacket built from a superposition of momentum modes has each mode
$k$ moving at its own group velocity $v(k)$; after $T$ steps, mode $k$'s
contribution sits near $x\approx v(k)\,T$ (stationary-phase reasoning,
the same principle used for wave-packet spreading in Wave Mechanics).
Since **every** mode's speed is bounded by $v_{\max}=1/\sqrt2$, the
entire distribution stays confined to a "light cone" $|x|\lesssim T/
\sqrt2$ that grows *linearly* in $T$, which is what
**ballistic** spreading means. It follows from the dispersion relation's
bounded-but-nonzero group velocity, before any simulation is run.
The exact limiting probability density inside
this light cone, and the resulting exact variance prefactor
$(1-1/\sqrt2)$ used below, is a more technical stationary-phase integral
(Konno 2002; Nayak & Vishwanath 2000), cited here without re-derivation
in full; but the light cone's *linear* growth, the qualitative and
quantitative origin of ballistic-vs-diffusive scaling, is fully derived
above.

### Contrast: the classical walk is diffusive by the central limit theorem

A classical unbiased walk's position after $T$ steps is a sum of $T$
independent $\pm1$ steps, each with variance $1$; by linearity of
variance for independent random variables, $\text{Var}(x_T)=T$ exactly,
an $O(\sqrt T)$ typical displacement, growing strictly slower than the
quantum walk's $O(T)$. No dispersion relation or interference is
involved at all; this is pure independence.

## A Walker That Does Not Forget

The classical walk forgets its history at every step: each $\pm1$ move
is drawn independently, so the central limit theorem's $\sqrt T$
scaling is inevitable. The quantum walk never forgets: every path to a
given final position interferes with every other path reaching the same
position, and the dispersion relation derived above shows that
interference doesn't just perturb the classical answer, it changes the
power law entirely, from diffusive to ballistic. This is the same kind
of interference-driven speedup Grover's algorithm exploits (quadratic in
its own arena), here appearing as a literal quadratic difference in how
fast probability mass can move through space.

overall envelope shrinking against the classical curve's fixed center

## Assuming Quantum Always Means Faster

<Callout type="warning">
**Assuming any quantum evolution on a line automatically spreads
ballistically.** It's specifically the *bounded, nonzero* group velocity
from the dispersion relation that forces ballistic spreading. A trivial
"coin" (e.g. the identity instead of Hadamard) gives no shift alternation
at all, and other coin/shift constructions can behave differently; the
Hadamard walk's ballistic scaling is a derived consequence of
*this* dispersion relation, not a generic fact about "being quantum."
</Callout>

<Callout type="warning">
**Confusing the light cone's edge (at $|x|\approx T/\sqrt2$, from the
maximum group velocity) with the variance prefactor ($1-1/\sqrt2$, from
the full limiting density).** They're related but numerically distinct
quantities: the light cone bounds where probability *can* be, while the
variance integrates the actual (highly non-uniform, in fact peaked near
the edges, as the $T=4$ worked example already shows) density within it.
</Callout>

<Callout type="note">
**Expecting the horn peak to shrink *monotonically* at every step.**
This lesson's own explorer above shows otherwise: computed directly
with the same `hadamardWalk` function driving the frames, the peak
height across $T=0,4,8,16,24,32,40$ is $1.000$, $0.375$, $0.2266$,
$0.2105$, $0.1596$, $0.1156$, $0.1235$, a reproducible *increase*
from $T=32$ to $T=40$, not a mistake to hide. The overall $1/\sqrt T$-
style envelope (peak $\times$ light-cone width stays order-$1$, since
probability is conserved) does shrink on average, but the exact density
inside the light cone has interference fringes near its edges,
so the peak (which tracks whichever fringe happens to be tallest at a
given $T$) can tick up locally even while the envelope it rides on is
trending down. This is the discrete-walk analog of the fringes in a
diffraction pattern getting locally brighter or dimmer while the
envelope narrows.
</Callout>

## Practice Questions

1. Using $\text{Var}(x_T)=T$ for the classical walk (derived above),
   compute the classical walk's typical displacement $\sqrt{\text{Var}}$
   at $T=10000$, and compare it to the quantum walk's typical
   displacement $\sqrt{(1-1/\sqrt2)}\,T$ at the same $T$.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Classical: $\sqrt{10000}=100$ sites. Quantum:
   $\sqrt{1-1/\sqrt2}\times10000=0.541196\times10000=5411.96$ sites. The
   quantum walker is about $54$ times further out.

   The factor is worth writing symbolically, because it is the whole
   content of the comparison:

   $$
   \frac{\sqrt{(1-1/\sqrt2)}\,T}{\sqrt T}=\sqrt{1-\tfrac1{\sqrt2}}\;\sqrt T=0.5412\sqrt T.
   $$

   The advantage is not a constant factor, it grows as $\sqrt T$. At
   $T=100$ the ratio is only $5.4$; at $T=10^4$ it is $54$; at $T=10^6$ it
   would be $541$. There is no crossover point and no regime where the
   classical walk catches up, which is what "different power law" means as
   distinct from "better constant".

   Two calibrations worth keeping. The quantum figure $5412$ sits at
   $77\%$ of the light-cone edge $T/\sqrt2=7071$, which is the right
   relationship: no probability can be outside the cone, and the root mean
   square lands inside it but not far inside, because most of the mass
   piles up near the horns rather than spreading evenly. And the words
   "typical displacement" are doing more work on the quantum side than the
   classical one. The classical distribution is a single bell curve, so its
   standard deviation really is where a typical walker is found. The
   quantum distribution is bimodal, so a typical measurement returns
   something near $\pm7000$, not near $\pm5412$; $\sqrt{\langle x^2\rangle}$
   is the right thing to *compare* because it is the same statistic in both
   cases, not because it describes where the quantum walker usually is.

   </details>

2. From the dispersion relation $\cos\omega(k)=\sin(k)/\sqrt2$, verify
   directly that $k=\pi/2$ gives $\omega=\pi/4$ and (using the group
   velocity formula) $v(\pi/2)=0$, a "trapped," non-propagating mode.
   What feature of the $T=4$ worked example's quantum distribution (a
   local peak or dip at the center) is this mode responsible for?

   <details className="answer-reveal">
   <summary>Answer</summary>

   Both checks are immediate, and the feature is the center's persistent
   but *locally minimal* probability: $0.125$ at $x=0$, a dip between the
   horns yet twice the $0.0625$ sitting at the extreme edges $x=\pm4$.

   **The dispersion value.** $\sin(\pi/2)=1$, so
   $\cos\omega=1/\sqrt2$ and $\omega(\pi/2)=\pi/4$.

   **The group velocity.** From
   $v(k)=-\cos k/\big(\sqrt2\sin\omega(k)\big)$, the numerator is
   $\cos(\pi/2)=0$ while the denominator is
   $\sqrt2\sin(\pi/4)=\sqrt2\cdot\tfrac1{\sqrt2}=1$, safely nonzero. So
   $v(\pi/2)=0/1=0$ exactly. The mode is stationary: whatever amplitude the
   walker carries at $k=\pi/2$ stays where it started, forever. The same
   holds at $k=-\pi/2$, where $\cos\omega=-1/\sqrt2$ and $\omega=3\pi/4$.

   **What it produces.** Stationary-phase reasoning places mode $k$ near
   $x\approx v(k)T$, so the $k=\pm\pi/2$ modes deposit weight near the
   origin at every $T$. That is the origin of the center's stubborn
   refusal to empty out. The full distribution after four steps is

   $$
   P(-4)=0.0625,\quad P(-2)=0.375,\quad P(0)=0.125,\quad P(2)=0.375,\quad P(4)=0.0625,
   $$

   so the center is a local minimum relative to its neighbours and, at the
   same time, is carrying twice the weight of the light-cone edge. A naive
   reading of "ballistic spreading" would predict the middle empties out
   entirely as all the probability rushes to the edges; the stationary
   modes are exactly why it does not.

   This survives to the asymptotic limit rather than being a small-$T$
   artifact, which is the check worth doing. The limiting density inside
   the light cone is
   $f(y)=1/\big(\pi(1-y^2)\sqrt{1-2y^2}\big)$ for $y=x/T\in(-1/\sqrt2,1/\sqrt2)$,
   whose minimum is at $y=0$ with the finite value $1/\pi\approx0.3183$ and
   which diverges as $y\to\pm1/\sqrt2$. Simulating out to $T=400$ and
   smoothing over the interference fringes reproduces it: $0.3185$ at
   $y=0$, $0.3903$ at $y=0.3$, $0.9394$ at $y=0.6$, against $0.3183$,
   $0.3863$ and $0.9399$ from the formula. The center is the global minimum
   of the density and is never zero.

   The tempting wrong turn is to expect $v=0$ to produce a *peak* at the
   origin, on the reasoning that trapped modes accumulate. They do not
   accumulate: each mode carries a fixed share of the initial amplitude and
   deposits it once. The peaks appear where $dv/dk=0$ instead, at the
   extremes of the group velocity, which is why the horns sit at the
   light-cone edge rather than at the centre. Stationary *velocity* builds
   a peak; zero velocity merely refuses to move.

   </details>

3. Explain, using only the fact that classical steps are independent,
   why $\text{Var}(x_T)=T$ exactly for *any* number of classical steps
   $T$, with no large-$T$ approximation needed; contrast this with the
   quantum result, which is only an asymptotic ($T\to\infty$) statement.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because variance is additive over uncorrelated summands, and that is an
   algebraic identity rather than a limit theorem.

   Write $x_T=\sum_{i=1}^Ts_i$ with each $s_i=\pm1$ equally likely. Then
   $\mathbb E[s_i]=0$ and $\mathrm{Var}(s_i)=\mathbb E[s_i^2]=1$. Expanding
   the square,

   $$
   \mathrm{Var}(x_T)=\mathbb E\Big[\Big(\sum_i s_i\Big)^2\Big]=\sum_i\mathbb E[s_i^2]+\sum_{i\neq j}\mathbb E[s_is_j]=T+0=T,
   $$

   where the cross terms vanish because $\mathbb E[s_is_j]=\mathbb E[s_i]\mathbb E[s_j]=0$
   for $i\neq j$. Every step is exact. The result holds at $T=1$, at
   $T=7$, at any $T$, and the simulation's `classical/T` column pinned at
   exactly $1.0000$ for every row is that identity being reproduced rather
   than approached.

   Note how little was used: not the central limit theorem, not
   identically distributed steps, not even full independence, only that
   distinct steps are *uncorrelated* and have unit second moment. The CLT
   is a separate and genuinely asymptotic statement, about the *shape* of
   the distribution converging to a Gaussian. The variance was never the
   asymptotic part.

   The quantum side cannot run this argument, and the reason is structural
   rather than technical. The walker's displacement is not a sum of
   independent increments: the coin is entangled with the position, so
   whether step $i$ moved left or right is correlated with every earlier
   step through the coin state it inherited. There is nothing to
   decorrelate and no additivity to exploit. What replaces the argument is
   a stationary-phase evaluation of an oscillatory Fourier integral, which
   is by construction a leading-order-in-$1/T$ result with corrections from
   the interference fringes near the light-cone edge. That is why the table
   shows `quantum/T²` drifting from $0.2995$ at $T=10$ down to $0.2929$ at
   $T=160$ while `classical/T` never moves: one column is a theorem about
   every $T$, the other is a limit being approached.

   The practical moral for reading such a table: a column that is exactly
   constant is reporting an identity and a column that is converging is
   reporting an asymptotic, and confusing the two leads to treating
   finite-$T$ drift as a bug in the simulation.

   </details>

4. A continuous-time quantum walk on a graph with adjacency matrix $A$
   evolves by $i\,d|\psi\rangle/dt=A|\psi\rangle$. Explain precisely why
   this is *literally* an instance of Hamiltonian simulation from the
   previous lesson, with $H=A$, and why Trotterization becomes the
   practical tool for running it on a graph whose adjacency matrix is a
   sum of non-commuting pieces (e.g. edge sets from different graph
   colors).

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because $i\,d|\psi\rangle/dt=A|\psi\rangle$ *is* the Schrödinger
   equation in units $\hbar=1$, and $A$ satisfies the one hypothesis that
   makes it a Hamiltonian.

   That hypothesis is Hermiticity, and for an undirected simple graph it
   comes free: $A_{uv}=A_{vu}\in\{0,1\}$ makes $A$ real symmetric, hence
   self-adjoint, hence a legitimate $H$ with $e^{-iAt}$ unitary and
   probability conserved. Nothing is being analogized. Solving the walk and
   simulating $H=A$ are the same computational task, so every bound from
   the previous lesson transfers verbatim, with $\|[A_1,A_2]\|$ read off
   the graph rather than off a physical Hamiltonian. The hypothesis is also
   where a directed graph fails: a non-symmetric $A$ generates non-unitary
   evolution and the whole framework needs replacing, which is why
   continuous-time quantum walks on directed graphs are a genuinely
   separate subject.

   Now the practical part. The state space has one dimension per vertex, so
   an $N$-vertex graph needs $\lceil\log_2N\rceil$ qubits and $A$ is a
   $2^n\times2^n$ matrix. Exponentiating it directly is exactly the
   $O(N^3)$ classical computation the quantum computer was supposed to
   avoid, so $e^{-iAt}$ has to be *compiled* out of pieces whose
   exponentials are individually easy.

   The standard decomposition is an edge colouring. Split
   $A=\sum_{c=1}^{C}A_c$, where colour class $c$ is a set of edges no two
   of which share a vertex. Each $A_c$ is then a perfect or partial
   matching, so as a matrix it is a direct sum of $2\times2$ blocks
   $\big(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\big)$, and

   $$
   e^{-iA_c t}=\bigoplus_{\text{edges}}\begin{pmatrix}\cos t&-i\sin t\\-i\sin t&\cos t\end{pmatrix},
   $$

   a single rotation applied independently on disjoint vertex pairs, all in
   parallel. Vizing's theorem guarantees $C\leq\Delta+1$ colours for
   maximum degree $\Delta$, so a bounded-degree graph splits into a
   constant number of easy pieces.

   The catch is that two colour classes generally share vertices, and
   $[A_c,A_{c'}]\neq0$ whenever they do. Sharing a vertex is precisely what
   makes the walk interesting, since it is how amplitude moves from one
   edge to the next, so the non-commutativity cannot be engineered away. So

   $$
   e^{-iAt}\approx\left(\prod_{c=1}^{C}e^{-iA_c t/n}\right)^{n},
   $$

   with the error controlled by the previous lesson's commutator bound and
   the step count set by $n=O(t^2\sum_{c<c'}\|[A_c,A_{c'}]\|/\epsilon)$, or
   $O(t^{3/2}/\sqrt\epsilon)$ with the symmetric splitting. This is the
   textbook route to sparse-Hamiltonian simulation, and continuous-time
   quantum walk search algorithms are compiled exactly this way.

   One caveat, so the tool is not over-applied. Trotterization is what you
   reach for when the graph has *no* exploitable structure. A
   translation-invariant graph such as a cycle is diagonalized by the
   quantum Fourier transform, so $e^{-iAt}$ can be implemented exactly as
   QFT, a diagonal phase, then inverse QFT, with no Trotter error at all.
   That is the continuous-time counterpart of the momentum-space
   diagonalization this lesson used on the coined walk, and it is worth
   checking for before paying for $n$ steps.

   </details>

## Summary

- The coined quantum walk is built from a coin operator (Hadamard, here)
  and a conditional shift entangling position with coin at every step,
  both unitary, so the whole walk is unitary evolution.
- Diagonalizing in momentum space gives an exact dispersion relation
  $\cos\omega(k)=\sin(k)/\sqrt2$, whose bounded, nonzero group velocity
  (maximum $1/\sqrt2$, from the group-velocity calculation above) forces
  ballistic ($\propto T$, so $\langle x^2\rangle\propto T^2$) spreading.
- The classical random walk's $\text{Var}(x_T)=T$ follows directly from
  independence (central limit theorem territory), diffusive,
  confirmed by direct simulation to be exactly $T$ at every $T$ tested.
- A real coined-walk simulation (using this platform's `Complex`
  arithmetic) confirms $\langle x^2\rangle/T^2\to1-1/\sqrt2\approx0.2929$
  as $T$ grows, matching the cited Konno constant to four decimal
  places.
- $W$ acts on the infinite-dimensional $\ell^2(\mathbb Z)\otimes\mathbb C^2$
  and has purely absolutely continuous, two-band spectrum with no
  eigenvectors; the momentum labels $|k\rangle$ are a direct-integral
  decomposition, not eigenvectors of $W$.
- Continuous-time quantum walks ($i\,d|\psi\rangle/dt=A|\psi\rangle$ for
  graph adjacency matrix $A$) are literally Hamiltonian simulation with
  $H=A$, directly connecting to the previous lesson's Trotterization
  machinery for graphs whose adjacency matrix doesn't split into
  commuting pieces.
