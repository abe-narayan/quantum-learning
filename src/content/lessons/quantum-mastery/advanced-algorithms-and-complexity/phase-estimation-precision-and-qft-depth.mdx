export function closedFormProb(phi, m, t) {
  const N = 2 ** t;
  const eps = phi - m / N;
  if (Math.abs(eps) < 1e-12) return 1;
  const num = Math.sin(Math.PI * eps * N);
  const den = Math.sin(Math.PI * eps);
  return (1 / (N * N)) * (num * num) / (den * den);
}

export function matrixFromCircuit(n, apply) {
  const dim = 2 ** n;
  const cols = [];
  for (let j = 0; j < dim; j++) {
    const out = apply(StateVector.basis(n, j));
    cols.push(out.amplitudes.slice());
  }
  const data = Array.from({ length: dim }, (_, r) => Array.from({ length: dim }, (_, c) => cols[c][r]));
  return new Matrix(data);
}

export function approxQFTCircuit(state, cutoff) {
  const n = state.numQubits;
  let s = state;
  for (let q = 0; q < n; q++) {
    s = applySingleQubitGate(s, HADAMARD, q);
    for (let k = 2; k <= n - q; k++) {
      if (k > cutoff) continue;
      const control = q + k - 1;
      s = applyControlledGate(s, phaseGate((2 * Math.PI) / 2 ** k), control, q);
    }
  }
  for (let i = 0; i < Math.floor(n / 2); i++) s = applySwap(s, i, n - 1 - i);
  return s;
}

export function frobeniusDistance(M1, M2) {
  let sum = 0;
  for (let r = 0; r < M1.rows; r++) {
    for (let c = 0; c < M1.cols; c++) {
      const d = M1.get(r, c).sub(M2.get(r, c));
      sum += d.magnitudeSquared();
    }
  }
  return Math.sqrt(sum);
}

## Motivation

Quantum Phase Estimation was derived, in Quantum Algorithms I, only for
phases $\varphi$ exactly representable in $t$ bits, a clean but
special case where the precision register lands on a single basis state
with certainty. Every real phase encountered in practice (an
eigenphase of a physically realistic Hamiltonian, say) is essentially
never exactly representable in any finite register. This lesson derives
what actually happens then, exactly, and separately asks the QFT's own
circuit-engineering question: how much does the QFT actually cost to
build, and what does an engineer get to trade away to build a cheaper
approximation?

## Mathematical Development

### The exact closed-form measurement probability

Following the earlier lesson's derivation up to the point just before
measurement, the precision register's state (for *any* $\varphi$, exact
or not) is $\frac1{\sqrt N}\sum_{x=0}^{N-1}e^{2\pi i\varphi x}|x\rangle$,
$N=2^t$. Applying the inverse QFT and reading off the amplitude on
outcome $m$ (using $\text{QFT}^\dagger|x\rangle=\frac1{\sqrt N}\sum_m
e^{-2\pi imx/N}|m\rangle$):

<DerivationSteps>
  <DerivationStep annotation="Read off the amplitude on outcome m by applying the inverse QFT to the pre-measurement state; the resulting sum is a finite geometric series in x with ratio e^(2πiε).">
    $$
    \text{amp}(m) = \frac1N\sum_{x=0}^{N-1}e^{2\pi ix(\varphi-m/N)} = \frac1N\sum_{x=0}^{N-1}e^{2\pi i\varepsilon x}, \qquad \varepsilon\equiv\varphi-\frac mN
    $$
  </DerivationStep>
  <DerivationStep annotation="Evaluate the geometric series in closed form, then apply the identity 1 − e^(iθ) = −2ie^(iθ/2)sin(θ/2) to both the numerator and denominator.">
    $$
    \text{amp}(m) = \frac1N\cdot\frac{1-e^{2\pi i\varepsilon N}}{1-e^{2\pi i\varepsilon}} = \frac1N\,e^{i\pi\varepsilon(N-1)}\,\frac{\sin(\pi\varepsilon N)}{\sin(\pi\varepsilon)}
    $$
  </DerivationStep>
  <DerivationStep annotation="Square the amplitude's magnitude to get the measurement probability; the phase factor e^(iπε(N−1)) drops out.">
    $$
    P(m) = \frac1{N^2}\,\frac{\sin^2(\pi\varepsilon N)}{\sin^2(\pi\varepsilon)}, \qquad \varepsilon=\varphi-\frac mN
    $$
  </DerivationStep>
</DerivationSteps>

This is a fully derived closed form, valid for *every* $\varphi$, exact or not
(when $\varepsilon=0$ exactly, this reduces to $P=1$ by direct limit,
recovering the earlier lesson's exact case). Checked directly against
`phaseEstimation`, this platform's real engine, for $\varphi=1/3$ (not
exactly representable in any finite number of bits) at $t=3,5,8$: the
formula and the engine agree to within $10^{-15}$ at *every* outcome,
floating-point roundoff, not approximation error.

### The 4/π² worst-case success guarantee, derived

Let $b=\text{round}(\varphi N)$ (the best $t$-bit estimate) and
$\delta=\varphi N-b\in[-\tfrac12,\tfrac12]$ (so $\varepsilon=\delta/N$
for $m=b$). Bound $P(b)$ from below using two elementary inequalities:
$\sin x\leq x$ for the denominator (so $\sin^2(\pi\delta/N)\leq
\pi^2\delta^2/N^2$):

<DerivationSteps>
  <DerivationStep annotation="Apply sin x ≤ x to the denominator sin²(πδ/N) ≤ π²δ²/N², which bounds P(b) below by the sinc function evaluated at δ.">
    $$
    P(b) = \frac1{N^2}\frac{\sin^2(\pi\delta)}{\sin^2(\pi\delta/N)} \geq \frac{\sin^2(\pi\delta)}{\pi^2\delta^2} = \left(\frac{\sin(\pi\delta)}{\pi\delta}\right)^2
    $$
  </DerivationStep>
  <DerivationStep annotation="sinc(δ) = sin(πδ)/(πδ) is even and decreases monotonically on δ ∈ [0, 1/2] (a standard elementary-calculus fact, cited rather than re-derived), so its minimum on δ ∈ [−1/2, 1/2] occurs at |δ| = 1/2, where sinc(1/2) = sin(π/2)/(π/2) = 2/π.">
    $$
    P(b) \geq \left(\frac2\pi\right)^2 = \frac4{\pi^2} \approx 0.4053
    $$
  </DerivationStep>
</DerivationSteps>

**for every possible $\varphi$ and every $t$**, a genuine, derived
worst-case guarantee, not an average-case or typical-case statement.

### A per-outcome tail-probability bound, derived

For $j=m-b\neq0$ an integer offset from the best estimate,
$\varepsilon=(\delta-j)/N$, and $\sin(\pi(\delta-j))=\sin(\pi\delta)
\cos(\pi j)-\cos(\pi\delta)\sin(\pi j)=(-1)^j\sin(\pi\delta)$ (since
$\sin(\pi j)=0,\cos(\pi j)=(-1)^j$ for integer $j$), so the numerator
satisfies $\sin^2(\pi(\delta-j))=\sin^2(\pi\delta)\leq1$. For the
denominator, using $\sin x\geq\tfrac2\pi x$ for $x\in[0,\tfrac\pi2]$ (the
chord from $(0,0)$ to $(\pi/2,1)$ lying below the concave function
$\sin$ on that interval):

$$
\sin^2\!\left(\frac{\pi|\delta-j|}N\right) \geq \frac{4(\delta-j)^2}{N^2}
$$

so

$$
P(m) = \frac1{N^2}\frac{\sin^2(\pi(\delta-j))}{\sin^2(\pi(\delta-j)/N)} \leq \frac1{N^2}\cdot\frac{N^2}{4(\delta-j)^2} = \frac1{4(\delta-j)^2}
$$

and since $|\delta-j|\geq|j|-|\delta|\geq|j|-\tfrac12$ (triangle
inequality, valid for $|j|\geq1$):

$$
\boxed{P(m) \leq \frac1{4(|j|-\tfrac12)^2}, \qquad j=m-b\neq0}
$$

a genuine, fully derived per-outcome tail bound. (The standard textbook
corollary, that choosing $t=n+\lceil\log_2(2+\tfrac1{2\epsilon})
\rceil$ ancilla qubits bounds the *total* failure probability of
recovering an $n$-bit estimate by $\epsilon$, sums this bound over all
$|j|\geq2^{t-n-1}$ and is cited here from Nielsen & Chuang rather than
re-derived, since the summation itself is routine but lengthy; the
per-outcome inequality driving it is fully derived above.)

Scrub $\delta$ from $0$ to $\tfrac12$ above (outcome $b=11$ held fixed,
$N=32$): at $\delta=0$, $\varphi$ is exactly representable and the
distribution is a single certain spike, $P(b)=1$. As $\delta$ grows the
spike spreads probability into neighboring outcomes and $P(b)$ falls
monotonically, exactly as $\text{sinc}(\delta)$ predicts, bottoming out
at $\delta=\tfrac12$ with $P(b)\approx0.406$, matching the derived floor
$4/\pi^2\approx0.4053$ to within the finite-$N$ gap between $\sin x$ and
$x$ (the inequality used in the derivation, which only becomes an
equality as $N\to\infty$). This is the direct, interactive confirmation
of the boxed inequality above: every value the slider ever shows stays
$\geq4/\pi^2$, and the worst case really is achieved at the worst offset
$\delta=\pm\tfrac12$, not merely asserted.

For comparison, at $\varphi=1/3,t=5$ ($N=32$): the best estimate is
$b=11$, with $\delta\approx-0.333$, and the engine's actual success
probability at $m=11$ is $P(b)\approx0.684$, comfortably above the
$4/\pi^2\approx0.405$ worst-case *guarantee* (this $\varphi$ isn't the
adversarial $\delta=\tfrac12$ case, so it does better than the floor,
exactly as the derivation predicts a floor should behave). The closed
form above matches this engine output to within $10^{-15}$ at every
single one of the 32 outcomes, confirmed directly, not asserted.

### Exact QFT gate count

`quantumFourierTransform`'s own source (Quantum Algorithms I) applies,
for $t$ precision qubits: one Hadamard per qubit ($t$ total), one
controlled-phase gate for every pair of qubits ($\binom t2=\frac{t(t-1)}
2$ total, summing $t-q-1$ controlled-phase gates at each of the $t$
Hadamard "rows" $q=0,\dots,t-1$), and $\lfloor t/2\rfloor$ final swaps.
Exact counts, computed directly from this formula:

| $t$ | Hadamards | controlled-phase | swaps |
|---|---|---|---|
| $5$ | $5$ | $10$ | $2$ |
| $10$ | $10$ | $45$ | $5$ |
| $20$ | $20$ | $190$ | $10$ |

The dominant $\binom t2=O(t^2)$ controlled-phase count is the QFT's
real engineering cost: for $t=20$, $190$ two-qubit gates, each an
actual physical operation with its own error rate on real hardware.

### An approximate QFT: dropping small-angle gates, with a proved error bound

Each controlled-phase gate at "distance" $k$ applies angle $\theta_k=
2\pi/2^k$, exponentially small for $k$ much larger than a cutoff $m$.
The **approximate QFT (AQFT)** simply omits every controlled-phase gate
with $k>m$, keeping only the $m$ largest-angle neighbors at each row.
Bound the resulting error by reusing the previous lesson's
submultiplicativity lemma directly: replacing a single controlled-phase
gate $\text{phaseGate}(\theta_k)$ with the identity changes that one
step by operator norm $\|\text{phaseGate}(\theta_k)-I\|=|e^{i\theta_k}-1|
=2|\sin(\theta_k/2)|\leq\theta_k$ (using $|\sin x|\leq|x|$). Summing
over every dropped gate (at most one per row per $k$, $t$ rows, $k$
ranging over $m+1,\dots,t$) via the lemma:

<EquationReveal
  terms={[
    { id: "norm", symbol: "‖QFT−AQFT_m‖", gloss: "The operator-norm distance between the exact QFT circuit and the approximate one that drops gates below the cutoff m." },
    { id: "theta", symbol: "θ_k", gloss: "The rotation angle of the controlled-phase gate at distance k, 2π/2^k — exponentially small for large k." },
    { id: "t", symbol: "t", gloss: "The number of precision qubits (rows) in the QFT circuit." },
    { id: "m", symbol: "m", gloss: "The cutoff: every controlled-phase gate with k > m is dropped." },
  ]}
>

$$
\|\text{QFT}-\text{AQFT}_m\| \leq \sum_{\text{dropped gates}}\theta_k \leq t\sum_{k=m+1}^\infty\frac{2\pi}{2^k} = \frac{2\pi t}{2^m}
$$

</EquationReveal>

This is a genuine derived bound, exponentially small in the cutoff $m$, so
$m=O(\log(t/\epsilon))$ suffices for total error $\leq\epsilon$, while
the *gate count* drops from $O(t^2)$ to $O(tm)=O(t\log(t/\epsilon))$, a
real, quantified engineering trade.

## Physical Interpretation

<InsightBlock>
  Both halves of this lesson are the same idea in different clothes:
  finite resources always leave a controlled, quantifiable residue
  rather than either "working perfectly" or "failing arbitrarily."
</InsightBlock>

Both halves of this lesson are the same idea in different clothes:
finite resources (finite precision qubits; finite gate budgets) always
leave a controlled, quantifiable residue rather than either "working
perfectly" or "failing arbitrarily." Phase estimation's tail bound says
precisely how unlikely a large misread is; the AQFT bound says precisely
how small a controlled-phase gate has to get before dropping it is
provably safe. Neither is a hand-wave: both come from the same kind of
elementary inequality chased all the way to a clean, checkable number.

Real factoring demonstrations (Shor's algorithm run on small
instances — $N=15$ or $N=21$ on photonic and superconducting hardware)
live entirely inside these two bounds: the precision register has to be
wide enough that the $4/\pi^2$-style guarantee resolves the right
period with workable odds, and the QFT circuit driving that register
has to fit within whatever coherence time and gate-error budget the
device actually has. Neither bound is theoretical decoration; they are
the two numbers an experimentalist actually checks before running the
circuit.

## Worked Example

**For $t=8$ precision qubits, $\varphi=1/3$: find $b$, $\delta$, and
verify $P(b)$ against the $4/\pi^2$ guarantee and the closed form.**

$N=256$, $\varphi N=85.33\overline3$, so $b=85$, $\delta\approx0.333$.
The closed form gives

$$
P(85)=\frac1{256^2}\frac{\sin^2(\pi\cdot0.333)}{\sin^2(\pi\cdot0.333/256)}\approx0.6839
$$

matching `phaseEstimation`'s actual engine output to within $10^{-15}$,
and comfortably above the $4/\pi^2\approx0.4053$ floor, exactly as
guaranteed.

## Common Mistakes

<Callout type="warning">
**Treating $P(b)\geq4/\pi^2$ as the *typical* success probability rather
than a worst-case floor.** As the $\varphi=1/3$ examples above show
(actual $P(b)\approx0.68$, well above $0.405$), most phases do
considerably better than the guarantee; $4/\pi^2$ is specifically the
value at the single worst case $\delta=\pm\tfrac12$, derived as a
guaranteed minimum, not a typical outcome.
</Callout>

<Callout type="warning">
**Assuming AQFT's error bound requires $m$ to scale with the *number of
qubits being estimated* ($n$) rather than the *total register size*
($t$).** The derived bound is $2\pi t/2^m$: it depends on $t$ (through
how many rows can each drop up to one gate) and shrinks exponentially in
$m$ regardless of what $t$ or $n$ individually are; doubling $t$ only
requires a few more units of $m$ (an additive $O(\log t)$ increase, not
a doubling) to maintain the same error bound.
</Callout>

## Summary

- QPE's exact measurement probability for *any* phase $\varphi$ is
  $P(m)=\frac1{N^2}\frac{\sin^2(\pi\varepsilon N)}{\sin^2(\pi\varepsilon)}$,
  $\varepsilon=\varphi-m/N$, derived from elementary geometric-series
  algebra, matching this platform's real `phaseEstimation` engine to
  within $10^{-15}$.
- From that closed form, $P(\text{best estimate})\geq4/\pi^2\approx
  0.405$ (a genuine worst-case guarantee) and
  $P(m)\leq\frac1{4(|j|-1/2)^2}$ for any outcome $j$ steps from the best
  estimate, both fully derived, not asserted.
- The exact QFT costs $\binom t2=O(t^2)$ controlled-phase gates; an
  approximate QFT dropping gates below cutoff $m$ has a provable error
  bound $2\pi t/2^m$ (derived by reusing the previous lesson's
  submultiplicativity lemma), cutting gate count to $O(tm)$ while
  keeping error exponentially small in $m$, verified directly on a
  real $6$-qubit circuit built gate-by-gate against the exact one.
