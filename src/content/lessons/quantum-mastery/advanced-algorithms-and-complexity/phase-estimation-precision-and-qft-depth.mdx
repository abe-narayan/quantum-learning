export function closedFormProb(phi, m, t) {
  const N = 2 ** t;
  const eps = phi - m / N;
  if (Math.abs(eps) < 1e-12) return 1;
  const num = Math.sin(Math.PI * eps * N);
  const den = Math.sin(Math.PI * eps);
  return (1 / (N * N)) * (num * num) / (den * den);
}

export function matrixFromCircuit(n, apply) {
  const dim = 2 ** n;
  const cols = [];
  for (let j = 0; j < dim; j++) {
    const out = apply(StateVector.basis(n, j));
    cols.push(out.amplitudes.slice());
  }
  const data = Array.from({ length: dim }, (_, r) => Array.from({ length: dim }, (_, c) => cols[c][r]));
  return new Matrix(data);
}

export function approxQFTCircuit(state, cutoff) {
  const n = state.numQubits;
  let s = state;
  for (let q = 0; q < n; q++) {
    s = applySingleQubitGate(s, HADAMARD, q);
    for (let k = 2; k <= n - q; k++) {
      if (k > cutoff) continue;
      const control = q + k - 1;
      s = applyControlledGate(s, phaseGate((2 * Math.PI) / 2 ** k), control, q);
    }
  }
  for (let i = 0; i < Math.floor(n / 2); i++) s = applySwap(s, i, n - 1 - i);
  return s;
}

export function matrixDifference(M1, M2) {
  return M1.add(M2.scale(-1));
}

export function frobeniusNorm(D) {
  let sum = 0;
  for (let r = 0; r < D.rows; r++) {
    for (let c = 0; c < D.cols; c++) sum += D.get(r, c).magnitudeSquared();
  }
  return Math.sqrt(sum);
}

export function operatorNorm(D) {
  const G = D.dagger().mul(D);
  const n = G.rows;
  let v = Array.from({ length: n }, (_, i) => new Complex(Math.cos(1.7 * i) + 1.3, Math.sin(0.9 * i)));
  let lambda = 0;
  for (let iter = 0; iter < 200; iter++) {
    const w = Array.from({ length: n }, (_, r) => {
      let acc = Complex.ZERO;
      for (let c = 0; c < n; c++) acc = acc.add(G.get(r, c).mul(v[c]));
      return acc;
    });
    const norm = Math.sqrt(w.reduce((a, z) => a + z.magnitudeSquared(), 0));
    if (norm < 1e-280) return 0;
    lambda = norm;
    v = w.map((z) => z.scale(1 / norm));
  }
  return Math.sqrt(lambda);
}

## The Case the Earlier Derivation Skipped

Quantum Phase Estimation was derived, in Quantum Algorithms I, only for
phases $\varphi$ exactly representable in $t$ bits, a clean but
special case where the precision register lands on a single basis state
with certainty. Every real phase encountered in practice (an
eigenphase of a physically realistic Hamiltonian, say) is almost
never exactly representable in any finite register. This lesson derives
what happens then, exactly, and separately asks the QFT's own
circuit-engineering question: how much does the QFT cost to
build, and what does an engineer get to trade away to build a cheaper
approximation?

It is worth naming what rides on this. Shor's factoring algorithm is,
underneath its number-theoretic dressing, an application of the
phase-estimation machinery analyzed below: the QFT reads a periodicity
off as a phase, and everything that determines whether factoring is
practical (how many ancilla qubits, how deep the QFT, how many rotations
survive truncation) is a consequence of <Term id="quantum-phase-estimation-precision">the precision and depth bounds
derived here</Term>. The bounds are not preliminaries to the interesting part.
They are the resource cost of the interesting part.

## A Worst-Case Guarantee and an Exact Gate Count

### The exact closed-form measurement probability

Following the earlier lesson's derivation up to the point just before
measurement, the precision register's state (for *any* $\varphi$, exact
or not) is $\frac1{\sqrt N}\sum_{x=0}^{N-1}e^{2\pi i\varphi x}|x\rangle$,
$N=2^t$. Applying the inverse QFT and reading off the amplitude on
outcome $m$ (using $\text{QFT}^\dagger|x\rangle=\frac1{\sqrt N}\sum_m
e^{-2\pi imx/N}|m\rangle$):

<DerivationSteps>
  <DerivationStep annotation="Read off the amplitude on outcome m by applying the inverse QFT to the pre-measurement state; the resulting sum is a finite geometric series in x with ratio e^(2πiε).">
    $$
    \text{amp}(m) = \frac1N\sum_{x=0}^{N-1}e^{2\pi ix(\varphi-m/N)} = \frac1N\sum_{x=0}^{N-1}e^{2\pi i\varepsilon x}, \qquad \varepsilon\equiv\varphi-\frac mN
    $$
  </DerivationStep>
  <DerivationStep annotation="Evaluate the geometric series in closed form, then apply the identity 1 − e^(iθ) = −2ie^(iθ/2)sin(θ/2) to both the numerator and denominator.">
    $$
    \text{amp}(m) = \frac1N\cdot\frac{1-e^{2\pi i\varepsilon N}}{1-e^{2\pi i\varepsilon}} = \frac1N\,e^{i\pi\varepsilon(N-1)}\,\frac{\sin(\pi\varepsilon N)}{\sin(\pi\varepsilon)}
    $$
  </DerivationStep>
  <DerivationStep annotation="Square the amplitude's magnitude to get the measurement probability; the phase factor e^(iπε(N−1)) drops out.">
    $$
    P(m) = \frac1{N^2}\,\frac{\sin^2(\pi\varepsilon N)}{\sin^2(\pi\varepsilon)}, \qquad \varepsilon=\varphi-\frac mN
    $$
  </DerivationStep>
</DerivationSteps>

This is a fully derived closed form, valid for *every* $\varphi$, exact or not
(when $\varepsilon=0$ exactly, this reduces to $P=1$ by direct limit,
recovering the earlier lesson's exact case). Checked directly against
`phaseEstimation`, this platform's real engine, for $\varphi=1/3$ (not
exactly representable in any finite number of bits) at $t=3,5,8$: the
formula and the engine agree to within $10^{-15}$ at *every* outcome,
floating-point roundoff, not approximation error.

### The 4/π² worst-case success guarantee, derived

Let $b=\text{round}(\varphi N)$ (the best $t$-bit estimate) and
$\delta=\varphi N-b\in[-\tfrac12,\tfrac12]$ (so $\varepsilon=\delta/N$
for $m=b$). Bound $P(b)$ from below using two elementary inequalities:
$\sin x\leq x$ for the denominator (so $\sin^2(\pi\delta/N)\leq
\pi^2\delta^2/N^2$):

<DerivationSteps>
  <DerivationStep annotation="Apply sin x ≤ x to the denominator sin²(πδ/N) ≤ π²δ²/N², which bounds P(b) below by the sinc function evaluated at δ.">
    $$
    P(b) = \frac1{N^2}\frac{\sin^2(\pi\delta)}{\sin^2(\pi\delta/N)} \geq \frac{\sin^2(\pi\delta)}{\pi^2\delta^2} = \left(\frac{\sin(\pi\delta)}{\pi\delta}\right)^2
    $$
  </DerivationStep>
  <DerivationStep annotation="sinc(δ) = sin(πδ)/(πδ) is even and decreases monotonically on δ ∈ [0, 1/2] (a standard elementary-calculus fact, cited here), so its minimum on δ ∈ [−1/2, 1/2] occurs at |δ| = 1/2, where sinc(1/2) = sin(π/2)/(π/2) = 2/π.">
    $$
    P(b) \geq \left(\frac2\pi\right)^2 = \frac4{\pi^2} \approx 0.4053
    $$
  </DerivationStep>
</DerivationSteps>

**for every possible $\varphi$ and every $t$**, a derived
worst-case guarantee, not an average-case or typical-case statement.

### A per-outcome tail-probability bound, derived

For $j=m-b\neq0$ an integer offset from the best estimate,
$\varepsilon=(\delta-j)/N$, and $\sin(\pi(\delta-j))=\sin(\pi\delta)
\cos(\pi j)-\cos(\pi\delta)\sin(\pi j)=(-1)^j\sin(\pi\delta)$ (since
$\sin(\pi j)=0,\cos(\pi j)=(-1)^j$ for integer $j$), so the numerator
satisfies $\sin^2(\pi(\delta-j))=\sin^2(\pi\delta)\leq1$. For the
denominator, using $\sin x\geq\tfrac2\pi x$ for $x\in[0,\tfrac\pi2]$ (the
chord from $(0,0)$ to $(\pi/2,1)$ lying below the concave function
$\sin$ on that interval):

$$
\sin^2\!\left(\frac{\pi|\delta-j|}N\right) \geq \frac{4(\delta-j)^2}{N^2}
$$

so

$$
P(m) = \frac1{N^2}\frac{\sin^2(\pi(\delta-j))}{\sin^2(\pi(\delta-j)/N)} \leq \frac1{N^2}\cdot\frac{N^2}{4(\delta-j)^2} = \frac1{4(\delta-j)^2}
$$

and since $|\delta-j|\geq|j|-|\delta|\geq|j|-\tfrac12$ (triangle
inequality, valid for $|j|\geq1$):

$$
\boxed{P(m) \leq \frac1{4(|j|-\tfrac12)^2}, \qquad j=m-b\neq0}
$$

a fully derived per-outcome tail bound. (The standard textbook
corollary, that choosing $t=n+\lceil\log_2(2+\tfrac1{2\epsilon})
\rceil$ ancilla qubits bounds the *total* failure probability of
recovering an $n$-bit estimate by $\epsilon$, sums this bound over all
$|j|\geq2^{t-n-1}$ and is cited here from Nielsen & Chuang rather than
re-derived, since the summation itself is routine but lengthy; the
per-outcome inequality driving it is fully derived above.)

For comparison, at $\varphi=1/3,t=5$ ($N=32$): the best estimate is

### Exact QFT gate count

`quantumFourierTransform`'s own source (Quantum Algorithms I) applies,
for $t$ precision qubits: one Hadamard per qubit ($t$ total), one
controlled-phase gate for every pair of qubits ($\binom t2=\frac{t(t-1)}
2$ total, summing $t-q-1$ controlled-phase gates at each of the $t$
Hadamard "rows" $q=0,\dots,t-1$), and $\lfloor t/2\rfloor$ final swaps.
Exact counts, computed directly from this formula:

| $t$ | Hadamards | controlled-phase | swaps |
|---|---|---|---|
| $5$ | $5$ | $10$ | $2$ |
| $10$ | $10$ | $45$ | $5$ |
| $20$ | $20$ | $190$ | $10$ |

The dominant $\binom t2=O(t^2)$ controlled-phase count is the QFT's
real engineering cost: for $t=20$, $190$ two-qubit gates, each an
actual physical operation with its own error rate on real hardware.

### An approximate QFT: dropping small-angle gates, with a proved error bound

Each controlled-phase gate at "distance" $k$ applies angle $\theta_k=
2\pi/2^k$, exponentially small for $k$ much larger than a cutoff $m$.
The **approximate QFT (AQFT)** omits every controlled-phase gate
with $k>m$, keeping only the largest-angle neighbors at each row (the
gates run from $k=2$ up to $k=t-q$ on row $q$, so a cutoff $m$ leaves at
most $m-1$ of them per row).
Bound the resulting error by reusing the previous lesson's
submultiplicativity lemma directly: replacing a single controlled-phase
gate $\text{phaseGate}(\theta_k)$ with the identity changes that one
step by operator norm $\|\text{phaseGate}(\theta_k)-I\|=|e^{i\theta_k}-1|
=2|\sin(\theta_k/2)|\leq\theta_k$ (using $|\sin x|\leq|x|$). Summing
over every dropped gate (at most one per row per $k$, $t$ rows, $k$
ranging over $m+1,\dots,t$) via the lemma:

<EquationReveal
  terms={[
    { id: "norm", symbol: "‖QFT−AQFT_m‖", gloss: "The operator-norm distance between the exact QFT circuit and the approximate one that drops gates below the cutoff m." },
    { id: "theta", symbol: "θ_k", gloss: "The rotation angle of the controlled-phase gate at distance k, equal to 2π/2^k and so exponentially small for large k." },
    { id: "t", symbol: "t", gloss: "The number of precision qubits (rows) in the QFT circuit." },
    { id: "m", symbol: "m", gloss: "The cutoff: every controlled-phase gate with k > m is dropped." },
  ]}
>

$$
\|\text{QFT}-\text{AQFT}_m\| \leq \sum_{\text{dropped gates}}\theta_k \leq t\sum_{k=m+1}^\infty\frac{2\pi}{2^k} = \frac{2\pi t}{2^m}
$$

</EquationReveal>

This is a derived bound, exponentially small in the cutoff $m$, so
$m=O(\log(t/\epsilon))$ suffices for total error $\leq\epsilon$, while
the *gate count* drops from $O(t^2)$ to $O(tm)=O(t\log(t/\epsilon))$, a
quantified engineering trade.

The operator-norm error respects the derived bound at every cutoff, and
at $m=t=6$ (nothing dropped) it is exactly $0$, which is a correctness
check on this lesson's own AQFT implementation as much as on the bound.
Read the Frobenius column and you would reach the opposite conclusion at
$m=2$, where $9.482$ sits just above the bound's $9.425$. That is not a
counterexample. For a $d\times d$ matrix the two norms satisfy
$\|M\|\leq\|M\|_F\leq\sqrt d\,\|M\|$, and $d=2^6=64$ here, so a Frobenius
figure may run up to $8\times$ the operator norm before anything is
wrong. It does: $9.482/1.999\approx4.7$. A bound proved in one norm is
only tested by measuring in that norm, and the sibling Trotter lesson
gets away with the substitution in the other direction, where Frobenius
overestimates and therefore only ever makes the bound harder to satisfy.

The two operator-norm rows at $m=1$ and $m=2$ are also worth a look: the
error is pinned near $2$, which is the largest two unitaries can ever be
apart, since $\|U-V\|\leq\|U\|+\|V\|=2$. At those cutoffs the AQFT has
thrown away enough of the transform that some input vector is mapped to
something close to the *negative* of where the exact QFT sends it, and no
bound can say anything useful. Only from $m=3$ does the measured error
leave that ceiling and start falling geometrically, roughly a factor of
$4$ per unit of $m$ over the last three rows, against the bound's factor
of $2$.

## A Finite Register Does Not Succeed or Fail

<InsightBlock>
  An algorithm with a finite register does not "work" or "fail." It
  leaves a residue, and the useful question is always how big the residue
  is and how fast it shrinks.
</InsightBlock>

Both halves of this lesson are that observation applied twice. Finite
precision leaves a tail: the $4/\pi^2$ bound says how unlikely a large
misread is, not that misreads cannot happen. A finite gate budget leaves
a truncation error: the AQFT bound says how small a controlled-phase
rotation has to be before dropping it is provably safe, not that small
rotations do nothing. In both cases the residue is bounded by an
elementary inequality carried through to a number, which is what
separates a resource estimate from an expectation.

Real factoring demonstrations (Shor's algorithm run on small
instances: $N=15$ or $N=21$ on photonic and superconducting hardware)
live entirely inside these two bounds: the precision register has to be
wide enough that the $4/\pi^2$-style guarantee resolves the right
period with workable odds, and the QFT circuit driving that register
has to fit within whatever coherence time and gate-error budget the
device has. Neither bound is theoretical decoration; they are
the two numbers an experimentalist checks before running the
circuit.

## Checking the Bound Against a Stubborn Phase

**For $t=8$ precision qubits, $\varphi=1/3$: find $b$, $\delta$, and
verify $P(b)$ against the $4/\pi^2$ guarantee and the closed form.**

$N=256$, $\varphi N=85.33\overline3$, so $b=85$, $\delta\approx0.333$.
The closed form gives

$$
P(85)=\frac1{256^2}\frac{\sin^2(\pi\cdot0.333)}{\sin^2(\pi\cdot0.333/256)}\approx0.6839
$$

matching `phaseEstimation`'s actual engine output to within $10^{-15}$,
and comfortably above the $4/\pi^2\approx0.4053$ floor, exactly as
guaranteed.

## Treating a Worst-Case Floor as Typical

<Callout type="warning">
**Treating $P(b)\geq4/\pi^2$ as the *typical* success probability rather
than a worst-case floor.** As the $\varphi=1/3$ examples above show
(actual $P(b)\approx0.68$, well above $0.405$), most phases do
considerably better than the guarantee; $4/\pi^2$ is specifically the
value at the single worst case $\delta=\pm\tfrac12$, derived as a
guaranteed minimum, not a typical outcome.
</Callout>

<Callout type="warning">
**Assuming AQFT's error bound requires $m$ to scale with the *number of
qubits being estimated* ($n$) rather than the *total register size*
($t$).** The derived bound is $2\pi t/2^m$: it depends on $t$ (through
how many rows can each drop up to one gate) and shrinks exponentially in
$m$ regardless of what $t$ or $n$ individually are; doubling $t$ only
requires a few more units of $m$ (an additive $O(\log t)$ increase, not
a doubling) to maintain the same error bound.
</Callout>

## Practice Questions

1. For $\varphi=1/5$ and $t=4$ ($N=16$), compute $b=\text{round}(16/5)$
   and $\delta$, then use the closed form to compute $P(b)$ by hand and
   check it exceeds $4/\pi^2$.

   <details className="answer-reveal">
   <summary>Answer</summary>

   $b=3$, $\delta=0.2$, and $P(3)=0.8756$, comfortably above the
   $4/\pi^2\approx0.4053$ floor.

   $\varphi N=16/5=3.2$, so $b=\mathrm{round}(3.2)=3$ and
   $\delta=3.2-3=0.2$. Feeding those into the closed form with
   $\varepsilon=\delta/N$:

   $$
   P(b)=\frac{1}{N^2}\,\frac{\sin^2(\pi\delta)}{\sin^2(\pi\delta/N)}
   =\frac{1}{256}\cdot\frac{\sin^2(0.2\pi)}{\sin^2(0.2\pi/16)}
   =\frac{1}{256}\cdot\frac{(0.5877853)^2}{(0.0392598)^2},
   $$

   $$
   P(b)=\frac{1}{256}\cdot\frac{0.3454915}{0.00154133}=\frac{224.148}{256}=0.87559.
   $$

   Comparing with the guarantee, $0.8756>0.4053$, so the bound holds with
   a wide margin. That margin is exactly what the derivation predicts:
   $4/\pi^2$ is the value at the *worst* offset $|\delta|=1/2$, and
   $\delta=0.2$ is nowhere near it.

   The tighter intermediate bound is worth evaluating too, because it
   shows how little the register size costs here. The derivation's first
   step gave $P(b)\geq\mathrm{sinc}^2(\delta)=\big(\sin(\pi\delta)/(\pi\delta)\big)^2$,
   which at $\delta=0.2$ is $(0.935489)^2=0.87514$. The true value
   $0.87559$ exceeds it by $0.0005$, the entire gap contributed by the
   $\sin x\leq x$ substitution at $x=\pi\delta/N$ with $N=16$. Even at
   four qubits that approximation is already nearly exact, which is why
   the $4/\pi^2$ floor is a good bound and not a lazy one.

   One thing not to conclude from a success probability of $0.88$: that
   the estimate is accurate to $0.88$ of something. $P(b)$ is the
   probability of landing on the single best four-bit outcome
   $b=3$, meaning $\hat\varphi=3/16=0.1875$ against the true $0.2$. The
   estimate's *accuracy* is set by $N$, and here it is only $1/16$; the
   probability is about how reliably that resolution is achieved. Widening
   the register improves the first and leaves the second alone, which is
   the trade the whole lesson is about.

   </details>

2. Using the derived tail bound $P(m)\leq\frac1{4(|j|-1/2)^2}$, compute
   an upper bound on the total probability of landing *more than* $3$
   outcomes away from the best estimate ($\sum_{|j|\geq4}$), by bounding
   the sum with an integral or a few explicit terms.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The bound gives $0.2$ by the integral estimate, and $0.1652$ if the sum
   is evaluated exactly.

   Fold the two tails together first, since the bound depends only on
   $|j|$:

   $$
   \sum_{|j|\geq4}P(m)\;\leq\;2\sum_{j=4}^{\infty}\frac{1}{4\left(j-\tfrac12\right)^2}
   =\frac12\sum_{j=4}^{\infty}\frac{1}{\left(j-\tfrac12\right)^2}.
   $$

   Now bound the sum by an integral. Each term $1/(j-\tfrac12)^2$ is at
   most $\int_{j-1}^{j}dx/(x-\tfrac12)^2$, because the integrand is
   decreasing and exceeds the term's value throughout that unit interval.
   Summing from $j=4$,

   $$
   \sum_{j=4}^{\infty}\frac{1}{\left(j-\tfrac12\right)^2}\leq\int_3^\infty\frac{dx}{\left(x-\tfrac12\right)^2}=\left[\frac{-1}{x-\tfrac12}\right]_3^\infty=\frac{1}{2.5}=0.4,
   $$

   so the total is at most $\tfrac12(0.4)=0.2$. Summing the series exactly
   instead gives $\psi'(3.5)=0.33036$ (the trigamma function, reachable by
   hand from $\psi'(\tfrac12)=\pi^2/2$ and $\psi'(x{+}1)=\psi'(x)-1/x^2$),
   hence $0.16518$, so the integral step costs about $21\%$ of looseness.

   Two things worth extracting.

   The bound is conservative by a clean factor. The true tail, in the
   worst case $\delta=\tfrac12$ and large $N$, behaves like
   $P\approx1/\big(\pi^2(j-\tfrac12)^2\big)$, so the actual probability of
   landing beyond three outcomes is about
   $(4/\pi^2)(0.16518)=0.0669$. The bound overshoots by exactly
   $\pi^2/4\approx2.47$, which is the price of having replaced $\sin$ by
   its chord.

   The bound is useless close in, and knowing where it turns on matters.
   At $|j|=1$ it reads $1/(4\cdot\tfrac14)=1$, a statement that a
   probability is at most one. At $|j|=2$ it gives $0.111$ and starts
   being informative. This is why the textbook corollary quoted above does
   not simply sum over all $j\neq0$, which would give something larger
   than $1$; it sums from $|j|\geq2^{t-n-1}$, choosing the extra ancillas
   precisely so that the sum starts far enough out for the bound to be
   worth having.

   </details>

3. For $t=10$ precision qubits, using the derived AQFT bound
   $2\pi t/2^m$, find the smallest cutoff $m$ that guarantees error
   below $0.1$.

   <details className="answer-reveal">
   <summary>Answer</summary>

   $m=10$, which at $t=10$ means keeping the entire exact QFT. The bound
   certifies no saving at all here.

   $$
   \frac{2\pi t}{2^m}\leq0.1
   \;\Longleftrightarrow\;
   2^m\geq\frac{2\pi(10)}{0.1}=628.32
   \;\Longleftrightarrow\;
   m\geq\log_2 628.32=9.30,
   $$

   so $m=10$. Checking the neighbours: $m=9$ gives $62.83/512=0.1227$,
   over target, and $m=10$ gives $0.0614$, under.

   Now read what $m=10$ means for the circuit. On row $q$ the
   controlled-phase gates run over $k=2,\dots,t-q$, so the largest $k$
   anywhere in a ten-qubit QFT is $10$. A cutoff of $m=10$ therefore drops
   nothing: all $\binom{10}{2}=45$ gates are kept and the "approximation"
   is the exact transform.

   That is the honest answer, and it is more useful than a number that
   pretends otherwise. The bound is $2\pi t/2^m$, with a factor of $t$
   sitting in front of the exponential, so at small $t$ the exponential has
   not had room to work. Compare $t=20$, where $m=11$ suffices and keeps
   $145$ of $190$ gates, and the asymptotic $O(t\log(t/\epsilon))$ against
   $O(t^2)$ only becomes a real saving at register sizes well beyond
   anything simulated in this lesson.

   The distinction to hold on to is between what is true and what is
   certified. The lesson's own measured table at $t=6$ shows an operator
   norm error of $0.098$ at cutoff $m=5$, while the bound at that cutoff
   reads $1.178$, more than ten times larger. So a cutoff far below what
   the bound demands very often does work. It just is not *proved* to
   work, and a resource estimate that has to hold for every input has to
   quote the bound. If you want a smaller $m$ with confidence, the route is
   a tighter bound, not a measurement at one register size.

   </details>

4. Explain why the exact QFT's controlled-phase gate count is
   $\binom t2$, not $t^2$, directly from `quantumFourierTransform`'s row
   structure (row $q$ contributes $t-q-1$ controlled-phase gates).

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because the rows contribute a decreasing sequence rather than a
   constant one, and summing an arithmetic run gives a triangle:

   $$
   \sum_{q=0}^{t-1}(t-q-1)=(t-1)+(t-2)+\cdots+1+0=\sum_{j=0}^{t-1}j=\frac{t(t-1)}{2}=\binom t2.
   $$

   The structural reason the sequence decreases is the useful part. After
   the Hadamard on qubit $q$, that qubit needs a phase correction
   conditioned on each qubit *later* in the register, and on none of the
   earlier ones, because those corrections were already applied when their
   own rows were processed. Row $0$ therefore has $t-1$ partners, row $1$
   has $t-2$, and the last row has none.

   Equivalently, and this is the version worth remembering: each
   *unordered pair* of qubits $\{q,q'\}$ receives exactly one
   controlled-phase gate, so the count is the number of pairs,
   $\binom t2$. A count of $t^2$ would be counting ordered pairs and
   self-pairs, which corresponds to applying every correction twice and
   each qubit to itself. The handshake argument gives the same answer from
   the other side: every qubit participates in $t-1$ gates, and
   $t(t-1)$ counts each gate from both ends, so divide by two.

   The factor of two is not asymptotically interesting, since
   $\binom t2\sim t^2/2$ is still $\Theta(t^2)$, but it is entirely real on
   hardware. At $t=20$ the difference is $190$ two-qubit gates against
   $400$, and each of those is a physical operation with its own error
   rate and its own contribution to circuit depth. The scaling determines
   whether the algorithm is viable in principle; the constant determines
   whether it fits inside a coherence time.

   </details>

## Summary

- QPE's exact measurement probability for *any* phase $\varphi$ is
  $P(m)=\frac1{N^2}\frac{\sin^2(\pi\varepsilon N)}{\sin^2(\pi\varepsilon)}$,
  $\varepsilon=\varphi-m/N$, derived from elementary geometric-series
  algebra, matching this platform's real `phaseEstimation` engine to
  within $10^{-15}$.
- From that closed form, $P(\text{best estimate})\geq4/\pi^2\approx
  0.405$ (a worst-case guarantee) and
  $P(m)\leq\frac1{4(|j|-1/2)^2}$ for any outcome $j$ steps from the best
  estimate, both derived here from the closed form.
- The exact QFT costs $\binom t2=O(t^2)$ controlled-phase gates; an
  approximate QFT dropping gates below cutoff $m$ has a provable error
  bound $2\pi t/2^m$ (derived by reusing the previous lesson's
  submultiplicativity lemma), cutting gate count to $O(tm)$ while
  keeping error exponentially small in $m$, verified in the operator
  norm the bound was proved in (by power iteration on $D^\dagger D$) on a
  real $6$-qubit circuit built gate-by-gate against the exact one.
