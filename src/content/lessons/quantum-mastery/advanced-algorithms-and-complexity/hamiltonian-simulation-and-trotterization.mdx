export function matrixExponential(H, t, terms = 40) {
  const n = H.rows;
  let result = Matrix.identity(n);
  let term = Matrix.identity(n);
  for (let k = 1; k <= terms; k++) {
    term = term.mul(H).scale(new Complex(0, -t / k));
    result = result.add(term);
  }
  return result;
}

export function frobeniusNorm(M) {
  let sum = 0;
  for (let r = 0; r < M.rows; r++) {
    for (let c = 0; c < M.cols; c++) {
      sum += M.get(r, c).magnitudeSquared();
    }
  }
  return Math.sqrt(sum);
}

export function frobeniusDistance(M1, M2) {
  return frobeniusNorm(M1.add(M2.scale(-1)));
}

export const hamA = PAULI_Z.tensor(PAULI_Z);
export const hamB = PAULI_X.tensor(IDENTITY).add(IDENTITY.tensor(PAULI_X));
export const hamH = hamA.add(hamB);
export const hamCommutator = commutator(hamA, hamB);
export const commNorm = frobeniusNorm(hamCommutator);

export const trotterT = 1.0;
export const trotterExact = matrixExponential(hamH, trotterT);
export const trotterNValues = [1, 2, 4, 8, 16, 32];
export const trotterResults = trotterNValues.map((n) => {
  const delta = trotterT / n;
  const stepA = matrixExponential(hamA, delta);
  const stepB = matrixExponential(hamB, delta);
  const step = stepA.mul(stepB);
  let approx = Matrix.identity(4);
  for (let i = 0; i < n; i++) approx = approx.mul(step);
  const error = frobeniusDistance(trotterExact, approx);
  const bound = (trotterT * delta / 2) * commNorm;
  return { n, delta, error, bound, errorTimesN: error * n };
});

  A real Hamiltonian almost never lets its pieces be simulated one at a

  derives exactly how good the fix is, not just that it exists.

## Motivation

Simulating $e^{-iHt}$ is the whole point of a quantum computer, in the
sense Feynman originally proposed it: a real physical Hamiltonian $H$
generally isn't a single gate this platform's engine already knows how to
apply. But $H$ almost always decomposes as a sum of *local* pieces,
$H=\sum_iH_i$, each individually easy to simulate; the trouble is that
$e^{-iHt}\neq\prod_ie^{-iH_it}$ unless every $H_i$ commutes with every
other, which is essentially never true for anything physically
interesting.

## Mathematical Development

### The product formula

For $H=A+B$ (WLOG two terms; more terms follow by the same argument
applied pairwise), <Term id="hamiltonian-simulation-trotterization">the first-order Trotter-Suzuki formula</Term> approximates

$$
e^{-i(A+B)t} \approx \left(e^{-iA\delta}e^{-iB\delta}\right)^n, \qquad \delta=\frac tn
$$

using $n$ repetitions of a "step" that's easy to implement (since $A$
and $B$ are each simulated separately, gate by gate) even though the
exact joint evolution generally isn't.

### The single-step error, derived by direct Taylor expansion

Expand both sides to second order in $\delta$:

$$
e^{-iA\delta} = I - iA\delta - \tfrac12A^2\delta^2 + O(\delta^3), \qquad e^{-iB\delta} = I - iB\delta - \tfrac12B^2\delta^2 + O(\delta^3)
$$

Multiplying:

$$
e^{-iA\delta}e^{-iB\delta} = I - i(A+B)\delta - \tfrac12(A^2+B^2)\delta^2 - AB\,\delta^2 + O(\delta^3)
$$

while directly expanding the exact exponential:

$$
e^{-i(A+B)\delta} = I - i(A+B)\delta - \tfrac12(A+B)^2\delta^2 + O(\delta^3) = I - i(A+B)\delta - \tfrac12(A^2+AB+BA+B^2)\delta^2 + O(\delta^3)
$$

Subtracting term by term, every piece cancels except the asymmetric
cross term:

<TheoremBox title="First-order Trotter single-step error" provenance="derived">

$$
\boxed{e^{-iA\delta}e^{-iB\delta} - e^{-i(A+B)\delta} = -\frac{\delta^2}{2}[A,B] + O(\delta^3)}
$$

</TheoremBox>

This is the entire mechanism in one line: the single-step Trotter error
is governed *exactly* by how much $A$ and $B$ fail to commute, vanishing
identically whenever $[A,B]=0$ (in which case the product formula is
exact at every order, as it should be). Taking operator norms, the
leading-order per-step error is $\frac{\delta^2}{2}\|[A,B]\|$, with the
$O(\delta^3)$ remainder bounded by a standard (cited, not re-derived)
Taylor-remainder estimate for bounded operators.

### From one step to n: a submultiplicativity lemma

To bound the error after $n$ repeated steps, not just one, use a short,
fully general lemma:

<TheoremBox title="Submultiplicativity lemma" provenance="derived">

If $U_1,\dots,U_n$ and $V_1,\dots,V_n$ are unitary with
$\|U_k-V_k\|\leq\varepsilon$ for every $k$, then $\|U_n\cdots
U_1-V_n\cdots V_1\|\leq n\varepsilon$.

</TheoremBox>

**Proof.** Telescope the difference:

$$
U_n\cdots U_1 - V_n\cdots V_1 = \sum_{k=1}^n V_n\cdots V_{k+1}(U_k-V_k)U_{k-1}\cdots U_1
$$

(each consecutive pair of terms in the sum differs by swapping exactly
one $U_k$ for $V_k$, so the whole telescoping sum reconstructs the full
difference). Every factor $V_n\cdots V_{k+1}$ and $U_{k-1}\cdots U_1$ is
unitary, hence norm-preserving, so each summand has norm exactly
$\|U_k-V_k\|\leq\varepsilon$. The triangle inequality over $n$ terms
gives $n\varepsilon$. $\blacksquare$

Applying this with $U_k=e^{-iH\delta}$ (so that $U_n\cdots U_1=e^{-iHt}$
exactly, since $H$ is time-independent) and $V_k=e^{-iA\delta}e^{-iB\delta}$
for every $k$, and $\varepsilon=\frac{\delta^2}2\|[A,B]\|$ from above:

$$
\boxed{\left\|e^{-iHt}-\left(e^{-iA\delta}e^{-iB\delta}\right)^n\right\| \;\leq\; n\cdot\frac{\delta^2}2\|[A,B]\| \;=\; \frac{t\delta}2\|[A,B]\| \;=\; \frac{t^2}{2n}\|[A,B]\|}
$$

a derived total-error bound, not an asserted one: it shrinks
as $O(1/n)$ for fixed simulation time $t$, the defining signature of a
*first-order* method, and the number of Trotter steps needed for a
target error $\epsilon$ scales as $n=O(t^2\|[A,B]\|/\epsilon)$.

### Second order for almost nothing: the Strang splitting

One small change buys a whole extra order of accuracy: make the step
symmetric. Instead of "all of $A$, then all of $B$", sandwich the $B$
step between two half-steps of $A$:

$$
S_2(\delta) \equiv e^{-iA\delta/2}\,e^{-iB\delta}\,e^{-iA\delta/2}
$$

The same Taylor expansion that exposed the first-order error also shows
why this one is better. Expand each factor to second order and multiply
the right pair first:

$$
e^{-iB\delta}e^{-iA\delta/2} = I - i\Big(\tfrac A2+B\Big)\delta - \Big(\tfrac{A^2}8 + \tfrac{BA}2 + \tfrac{B^2}2\Big)\delta^2 + O(\delta^3)
$$

then apply the remaining left factor $I - i\tfrac A2\delta - \tfrac{A^2}8\delta^2 + O(\delta^3)$
and collect powers of $\delta$. The $\delta$ terms assemble to
$-i(A+B)\delta$. The $\delta^2$ terms are the interesting part: the
$A^2$ pieces add up as $\tfrac18+\tfrac18+\tfrac14=\tfrac12$, the $B^2$
piece is already $\tfrac12$, and the cross terms arrive as
$\tfrac{BA}2$ from the right pair and $\tfrac{AB}2$ from the left
factor, symmetrically:

$$
S_2(\delta) = I - i(A+B)\delta - \tfrac12\big(A^2+AB+BA+B^2\big)\delta^2 + O(\delta^3)
$$

<TheoremBox title="Second-order (Strang) single-step error" provenance="derived">

$$
\boxed{S_2(\delta) - e^{-i(A+B)\delta} = O(\delta^3)}
$$

Every term through $\delta^2$ matches the exact exponential's expansion
term for term. The asymmetric $AB$ cross term that produced the
first-order formula's $-\tfrac{\delta^2}2[A,B]$ error is replaced by the
symmetric combination $\tfrac12(AB+BA)$, which is what the exact
exponential wants.

</TheoremBox>

The submultiplicativity lemma applies unchanged, so $n$ steps give a
total error of $n\cdot O(\delta^3)=O(t^3/n^2)$: doubling the step count
now cuts the error by a factor of four, and the step count for target
error $\epsilon$ scales as $n=O(t^{3/2}/\sqrt\epsilon)$ instead of
$O(t^2/\epsilon)$. The leading $\delta^3$ coefficient itself is
cited, not re-derived here: the tight form (Childs, Su, Tran, Wiebe,
and Zhu, "Theory of Trotter Error with Commutator Scaling", Phys. Rev.
X 11, 011020 (2021)) is

$$
\big\|S_2(\delta) - e^{-i(A+B)\delta}\big\| \leq \frac{\delta^3}{12}\big\|[B,[B,A]]\big\| + \frac{\delta^3}{24}\big\|[A,[A,B]]\big\|
$$

with nested commutators playing the role $[A,B]$ played at first order.

<ResearchConnection
  title="Theory of Trotter error with commutator scaling"
  source="Childs, Su, Tran, Wiebe & Zhu, Phys. Rev. X 11, 011020 (2021) (arXiv:1912.08854)"
  url="https://arxiv.org/abs/1912.08854"
>
  The pattern this lesson found by hand generalizes all the way up.
  Childs and coauthors prove that the $2k$-th-order Suzuki formula's
  error is controlled by nested commutators $2k+1$ layers deep, in the
  same way first order is controlled by one commutator and second order
  by two. Because deeply nested commutators of local Hamiltonian terms
  are often small or zero, these bounds can beat naive
  norm-counting estimates by orders of magnitude, and they made
  Trotterization competitive again for chemistry and lattice
  simulations that fancier algorithms had appeared to own.
</ResearchConnection>

<ResearchConnection
  title="qDRIFT: a random compiler for Hamiltonian simulation"
  source="Campbell, Phys. Rev. Lett. 123, 070503 (2019) (arXiv:1811.08017)"
  url="https://arxiv.org/abs/1811.08017"
>
  Deterministic ordering is not the only option. Campbell's qDRIFT
  protocol builds each step by sampling a single term $H_i$ at random,
  with probability proportional to its strength, and applying it alone.
  The resulting evolution matches $e^{-iHt}$ on average, and the gate
  count depends on $\lambda=\sum_i\|H_i\|$ (the total interaction
  strength) rather than on the number of terms. For molecular
  Hamiltonians with thousands of tiny terms, that trade is a large win:
  Campbell reports circuit-size reductions of two to three orders of
  magnitude over standard Trotter-Suzuki at chemistry-relevant
  precision.
</ResearchConnection>

## Physical Interpretation

Every non-commuting pair of Hamiltonian terms is a place where "do $A$,
then do $B$" differs from "do both at once". The same
noncommutativity that gives quantum mechanics its structure is what
Trotterization has to pay a price for approximating. Splitting into
smaller steps doesn't remove the noncommutativity; it just makes each
individual step's exposure to it smaller, at the cost of needing more
steps: a real, quantified tradeoff, not a free lunch.

This isn't only a textbook exercise: IBM's 127-qubit Eagle processor ran
Trotterized time-evolution circuits, with up to 60 layers of two-qubit
gates, of a 2D transverse-field ("kicked") Ising Hamiltonian in its
widely cited 2023 Nature paper on quantum utility before fault
tolerance, checking the results against state-of-the-art classical
approximation methods. That's the same family of Hamiltonian, coupling
term plus transverse field, this lesson's own worked example
Trotterizes, just at a scale of 127 qubits instead of 2.

Their commutator has Frobenius norm $\|[A,B]\|_F\approx5.656854$,

largest singular value, is never larger than the Frobenius norm, the
square root of the sum of *all* singular values squared.)

**First versus second order: the step-count crossover.** How much does
the Strang splitting actually save on this same Hamiltonian? Both bounds
are computable by hand. The nested commutators follow from the same
Pauli algebra that gave $[A,B]=2i(Y\otimes Z+Z\otimes Y)$:

$$
[B,[B,A]] = 8\,(Z\otimes Z - Y\otimes Y), \qquad [A,[A,B]] = 4B = 4\,(X\otimes I + I\otimes X)
$$

with Frobenius norms $\|[B,[B,A]]\|_F=16\sqrt2\approx22.63$ and
$\|[A,[A,B]]\|_F=8\sqrt2\approx11.31$ (the same conservative norm choice
used throughout this lesson, applied to both methods alike). At $t=1$
with $\delta=1/n$, the two total-error bounds are

$$
\text{first order: } \frac{\|[A,B]\|_F}{2n}=\frac{2\sqrt2}{n}\approx\frac{2.828}{n}, \qquad \text{second order: } \frac1{n^2}\Big(\frac{16\sqrt2}{12}+\frac{8\sqrt2}{24}\Big)=\frac{5\sqrt2}{3n^2}\approx\frac{2.357}{n^2}
$$

Now fix the target $\epsilon=0.01$ (the same target as Practice
Question 1). First order needs $2.828/n\leq0.01$, so $n=283$ steps
($n=282$ gives $0.01003$, just over). Second order needs
$2.357/n^2\leq0.01$, so $n=16$ steps ($15^2=225$ gives $0.01048$, just
over). In exponentials applied: $2\times283=566$ for first order
against $2\times16+1=33$ for Strang (adjacent $A$ half-steps merge, so
$n$ symmetric steps cost $2n+1$ exponentials, not $3n$). A factor of
about 17 fewer gates, from one symmetrization.

Where is the actual crossover? Setting the two step counts equal and
solving shows first order is only competitive when
$\epsilon\gtrsim1$, an error target so loose the "approximation" would
be meaningless for a unitary of norm 1. For any target you would
actually use, the symmetric splitting wins, and its advantage grows
like $1/\sqrt\epsilon$ as the target tightens.

## Common Mistakes

<Callout type="warning">
**Assuming the Trotter error bound requires $A$ and $B$ to be small.**
It doesn't: it requires $\delta=t/n$ (the *step size*) to be small. A
large Hamiltonian norm just means more steps ($n$) are needed to make
$\delta$ small enough for a given target accuracy; the derivation places
no restriction on $\|A\|,\|B\|$ themselves, only on $\|[A,B]\|$ and how
many pieces $t$ gets chopped into.
</Callout>

<Callout type="note">
**Expecting the operator-norm bound and the Frobenius-norm-based
estimate used here to match exactly.** They don't have to: the Frobenius
norm only ever *overestimates* the operator norm, so every bound in this
lesson computed with $\|\cdot\|_F$ remains a valid, if slightly loose,
bound on the true operator-norm error. The observed ratios above
(actual error below the bound at every $n$) are exactly this
looseness in action, not a sign of an error in the derivation.
</Callout>

## Summary

- The first-order Trotter product formula's single-step error is
  derived exactly, via direct Taylor expansion, as
  $-\frac{\delta^2}2[A,B]+O(\delta^3)$: noncommutativity is the entire
  source of the error.
- A general submultiplicativity lemma for products of unitaries (proved
  here via a telescoping sum) converts this single-step bound into a
  total-error bound, $\frac{t^2}{2n}\|[A,B]\|$, over $n$ steps.
- The symmetric Strang splitting $e^{-iA\delta/2}e^{-iB\delta}e^{-iA\delta/2}$
  cancels the entire $\delta^2$ error term (derived by the same Taylor
  expansion), giving $O(t^3/n^2)$ total error; on this lesson's
  Hamiltonian at target error $0.01$, that is 16 steps instead of 283.
  Higher-order commutator bounds (Childs et al. 2021) and randomized
  compilation (qDRIFT, Campbell 2019) extend the same story, and are
  cited rather than re-derived.
- Verified numerically on a real 2-qubit Ising Hamiltonian, using this
  platform's actual `Matrix`/`Complex`/gate primitives plus a
  from-scratch Taylor-series matrix exponential: the single-step error
  ratio converges to exactly $1$ as $\delta\to0$, and the $n$-step error
  scales as $O(1/n)$, both confirmed directly against exact matrix
  exponentiation, not merely asserted.
