export function matrixExponential(H, t, terms = 40) {
  const n = H.rows;
  let result = Matrix.identity(n);
  let term = Matrix.identity(n);
  for (let k = 1; k <= terms; k++) {
    term = term.mul(H).scale(new Complex(0, -t / k));
    result = result.add(term);
  }
  return result;
}

export function frobeniusNorm(M) {
  let sum = 0;
  for (let r = 0; r < M.rows; r++) {
    for (let c = 0; c < M.cols; c++) {
      sum += M.get(r, c).magnitudeSquared();
    }
  }
  return Math.sqrt(sum);
}

export function frobeniusDistance(M1, M2) {
  return frobeniusNorm(M1.add(M2.scale(-1)));
}

export const hamA = PAULI_Z.tensor(PAULI_Z);
export const hamB = PAULI_X.tensor(IDENTITY).add(IDENTITY.tensor(PAULI_X));
export const hamH = hamA.add(hamB);
export const hamCommutator = commutator(hamA, hamB);
export const commNorm = frobeniusNorm(hamCommutator);

export const trotterT = 1.0;
export const trotterExact = matrixExponential(hamH, trotterT);
export const trotterNValues = [1, 2, 4, 8, 16, 32];
export const trotterResults = trotterNValues.map((n) => {
  const delta = trotterT / n;
  const stepA = matrixExponential(hamA, delta);
  const stepB = matrixExponential(hamB, delta);
  const step = stepA.mul(stepB);
  let approx = Matrix.identity(4);
  for (let i = 0; i < n; i++) approx = approx.mul(step);
  const error = frobeniusDistance(trotterExact, approx);
  const bound = (trotterT * delta / 2) * commNorm;
  return { n, delta, error, bound, errorTimesN: error * n };
});

## The Exponential Everyone Wants to Compute

Simulating $e^{-iHt}$ is the whole point of a quantum computer, in the
sense Feynman originally proposed it: a real physical Hamiltonian $H$
generally isn't a single gate this platform's engine already knows how to
apply. But $H$ almost always decomposes as a sum of *local* pieces,
$H=\sum_iH_i$, each individually easy to simulate; the trouble is that
$e^{-iHt}\neq\prod_ie^{-iH_it}$ unless every $H_i$ commutes with every
other, which almost never holds for anything physically interesting.

## Product Formulas and Their Error, by Taylor Expansion

### The product formula

For $H=A+B$ (WLOG two terms; more terms follow by the same argument
applied pairwise), <Term id="hamiltonian-simulation-trotterization">the first-order Trotter-Suzuki formula</Term> approximates

$$
e^{-i(A+B)t} \approx \left(e^{-iA\delta}e^{-iB\delta}\right)^n, \qquad \delta=\frac tn
$$

using $n$ repetitions of a "step" that's easy to implement (since $A$
and $B$ are each simulated separately, gate by gate) even though the
exact joint evolution generally isn't.

### The single-step error, derived by direct Taylor expansion

Expand both sides to second order in $\delta$:

$$
e^{-iA\delta} = I - iA\delta - \tfrac12A^2\delta^2 + O(\delta^3), \qquad e^{-iB\delta} = I - iB\delta - \tfrac12B^2\delta^2 + O(\delta^3)
$$

Multiplying:

$$
e^{-iA\delta}e^{-iB\delta} = I - i(A+B)\delta - \tfrac12(A^2+B^2)\delta^2 - AB\,\delta^2 + O(\delta^3)
$$

while directly expanding the exact exponential:

$$
e^{-i(A+B)\delta} = I - i(A+B)\delta - \tfrac12(A+B)^2\delta^2 + O(\delta^3) = I - i(A+B)\delta - \tfrac12(A^2+AB+BA+B^2)\delta^2 + O(\delta^3)
$$

Subtracting term by term, every piece cancels except the asymmetric
cross term:

<TheoremBox title="First-order Trotter single-step error" provenance="derived">

**Hypotheses.** $A$ and $B$ are *bounded* self-adjoint operators on a
Hilbert space (in particular, any two finite Hermitian matrices), and
$\delta\in\mathbb R$. Boundedness is what makes both exponential series
converge absolutely in operator norm, so the two expansions may be
multiplied and subtracted term by term.

$$
\boxed{e^{-iA\delta}e^{-iB\delta} - e^{-i(A+B)\delta} = -\frac{\delta^2}{2}[A,B] + O(\delta^3)}
$$

The implied constant in $O(\delta^3)$ depends only on $\|A\|$ and
$\|B\|$, so the estimate is uniform in $\delta$ on any bounded interval.

</TheoremBox>

This is the entire mechanism in one line: the single-step Trotter error
is governed *exactly* by how much $A$ and $B$ fail to commute, vanishing
identically whenever $[A,B]=0$ (in which case the product formula is
exact at every order, as it should be). Taking operator norms, the
leading-order per-step error is $\frac{\delta^2}{2}\|[A,B]\|$, with the
$O(\delta^3)$ remainder bounded by a standard (cited, not re-derived)
Taylor-remainder estimate for bounded operators.

The boundedness hypothesis is not decoration, and it is where
matrix intuition and operator theory part company. Every $H$ in this
lesson is a finite Hermitian matrix, so $\|A\|,\|B\|<\infty$ and the
argument above is complete as written. The Hamiltonians of continuum
quantum mechanics are not: for $H=-\tfrac{\hbar^2}{2m}\Delta+V$ on
$L^2(\mathbb R^3)$, neither the kinetic nor the potential term is
bounded, the exponential series do not converge in norm, and
$\|[A,B]\|=\infty$ makes the bound above vacuous. The product formula
itself survives, but in a weaker form: the **Trotter–Kato theorem**
gives $\left(e^{-iA t/n}e^{-iB t/n}\right)^n\to e^{-i(A+B)t}$ in the
*strong* operator topology, vector by vector, whenever $A$, $B$, and
$\overline{A+B}$ are each self-adjoint. Strong convergence with no rate
is exactly what a gate-count argument cannot use, which is why
rigorous continuum simulation bounds are always proved after
discretizing onto a lattice, where the operators are matrices again and
this lesson's finite-dimensional estimate applies.

### From one step to n: a submultiplicativity lemma

To bound the error after $n$ repeated steps, not just one, use a short,
fully general lemma:

<TheoremBox title="Submultiplicativity lemma" provenance="derived">

**Hypotheses.** $U_1,\dots,U_n$ and $V_1,\dots,V_n$ are unitary
operators on one Hilbert space, and $\|\cdot\|$ is any unitarily
invariant norm ($\|WM\|=\|MW\|=\|M\|$ for unitary $W$), which covers
both the operator norm used in the bound and the Frobenius norm used in
this lesson's numerics.

If $\|U_k-V_k\|\leq\varepsilon$ for every $k$, then $\|U_n\cdots
U_1-V_n\cdots V_1\|\leq n\varepsilon$.

Nothing here is finite-dimensional: the lemma holds verbatim for unitary
operators on an infinite-dimensional Hilbert space. It is only the
per-step $\varepsilon$ fed into it that needed $A$ and $B$ bounded.

</TheoremBox>

**Proof.** Telescope the difference:

$$
U_n\cdots U_1 - V_n\cdots V_1 = \sum_{k=1}^n V_n\cdots V_{k+1}(U_k-V_k)U_{k-1}\cdots U_1
$$

(each consecutive pair of terms in the sum differs by swapping exactly
one $U_k$ for $V_k$, so the whole telescoping sum reconstructs the full
difference). Every factor $V_n\cdots V_{k+1}$ and $U_{k-1}\cdots U_1$ is
unitary, hence norm-preserving, so each summand has norm exactly
$\|U_k-V_k\|\leq\varepsilon$. The triangle inequality over $n$ terms
gives $n\varepsilon$. $\blacksquare$

Applying this with $U_k=e^{-iH\delta}$ (so that $U_n\cdots U_1=e^{-iHt}$
exactly, since $H$ is time-independent) and $V_k=e^{-iA\delta}e^{-iB\delta}$
for every $k$, and $\varepsilon=\frac{\delta^2}2\|[A,B]\|$ from above:

$$
\boxed{\left\|e^{-iHt}-\left(e^{-iA\delta}e^{-iB\delta}\right)^n\right\| \;\leq\; n\cdot\frac{\delta^2}2\|[A,B]\| \;=\; \frac{t\delta}2\|[A,B]\| \;=\; \frac{t^2}{2n}\|[A,B]\|}
$$

This total-error bound is derived, not quoted: it shrinks
as $O(1/n)$ for fixed simulation time $t$, the defining signature of a
*first-order* method, and the number of Trotter steps needed for a
target error $\epsilon$ scales as $n=O(t^2\|[A,B]\|/\epsilon)$.

### Second order for almost nothing: the Strang splitting

One small change buys a whole extra order of accuracy: make the step
symmetric. Instead of "all of $A$, then all of $B$", sandwich the $B$
step between two half-steps of $A$:

$$
S_2(\delta) \equiv e^{-iA\delta/2}\,e^{-iB\delta}\,e^{-iA\delta/2}
$$

The same Taylor expansion that exposed the first-order error also shows
why this one is better. Expand each factor to second order and multiply
the right pair first:

$$
e^{-iB\delta}e^{-iA\delta/2} = I - i\Big(\tfrac A2+B\Big)\delta - \Big(\tfrac{A^2}8 + \tfrac{BA}2 + \tfrac{B^2}2\Big)\delta^2 + O(\delta^3)
$$

then apply the remaining left factor $I - i\tfrac A2\delta - \tfrac{A^2}8\delta^2 + O(\delta^3)$
and collect powers of $\delta$. The $\delta$ terms assemble to
$-i(A+B)\delta$. The $\delta^2$ terms are the interesting part: the
$A^2$ pieces add up as $\tfrac18+\tfrac18+\tfrac14=\tfrac12$, the $B^2$
piece is already $\tfrac12$, and the cross terms arrive as
$\tfrac{BA}2$ from the right pair and $\tfrac{AB}2$ from the left
factor, symmetrically:

$$
S_2(\delta) = I - i(A+B)\delta - \tfrac12\big(A^2+AB+BA+B^2\big)\delta^2 + O(\delta^3)
$$

<TheoremBox title="Second-order (Strang) single-step error" provenance="derived">

**Hypotheses.** The same as at first order: $A$, $B$ bounded and
self-adjoint, $\delta$ real. No commutation, positivity, or
smallness assumption is added.

$$
\boxed{S_2(\delta) - e^{-i(A+B)\delta} = O(\delta^3)}
$$

Every term through $\delta^2$ matches the exact exponential's expansion
term for term. The asymmetric $AB$ cross term that produced the
first-order formula's $-\tfrac{\delta^2}2[A,B]$ error is replaced by the
symmetric combination $\tfrac12(AB+BA)$, which is what the exact
exponential wants.

</TheoremBox>

The submultiplicativity lemma applies unchanged, so $n$ steps give a
total error of $n\cdot O(\delta^3)=O(t^3/n^2)$: doubling the step count
now cuts the error by a factor of four, and the step count for target
error $\epsilon$ scales as $n=O(t^{3/2}/\sqrt\epsilon)$ instead of
$O(t^2/\epsilon)$. The leading $\delta^3$ coefficient itself is
cited, not re-derived here: the tight form (Childs, Su, Tran, Wiebe,
and Zhu, "Theory of Trotter Error with Commutator Scaling", Phys. Rev.
X 11, 011020 (2021)) is

$$
\big\|S_2(\delta) - e^{-i(A+B)\delta}\big\| \leq \frac{\delta^3}{12}\big\|[B,[B,A]]\big\| + \frac{\delta^3}{24}\big\|[A,[A,B]]\big\|
$$

with nested commutators playing the role $[A,B]$ played at first order.

## Non-Commutation as the Source of Error

Every non-commuting pair of Hamiltonian terms is a place where "do $A$,
then do $B$" differs from "do both at once". The same
noncommutativity that gives quantum mechanics its structure is what
Trotterization has to pay a price for approximating. Splitting into
smaller steps doesn't remove the noncommutativity; it just makes each
individual step's exposure to it smaller, at the cost of needing more
steps. The tradeoff is quantified, and it is not a free lunch.

This isn't only a textbook exercise: IBM's 127-qubit Eagle processor ran
Trotterized time-evolution circuits, with up to 60 layers of two-qubit
gates, of a 2D transverse-field ("kicked") Ising Hamiltonian in its
widely cited 2023 Nature paper on quantum utility before fault
tolerance, checking the results against state-of-the-art classical
approximation methods. That's the same family of Hamiltonian, coupling
term plus transverse field, this lesson's own worked example
Trotterizes, just at a scale of 127 qubits instead of 2.

**First versus second order: the step-count crossover.** How much does
the Strang splitting save on this same Hamiltonian? Both bounds
are computable by hand. The nested commutators follow from the same
Pauli algebra that gave $[A,B]=2i(Y\otimes Z+Z\otimes Y)$:

$$
[B,[B,A]] = 8\,(Z\otimes Z - Y\otimes Y), \qquad [A,[A,B]] = 4B = 4\,(X\otimes I + I\otimes X)
$$

with Frobenius norms $\|[B,[B,A]]\|_F=16\sqrt2\approx22.63$ and
$\|[A,[A,B]]\|_F=8\sqrt2\approx11.31$ (the same conservative norm choice
used throughout this lesson, applied to both methods alike). At $t=1$
with $\delta=1/n$, the two total-error bounds are

$$
\text{first order: } \frac{\|[A,B]\|_F}{2n}=\frac{2\sqrt2}{n}\approx\frac{2.828}{n}, \qquad \text{second order: } \frac1{n^2}\Big(\frac{16\sqrt2}{12}+\frac{8\sqrt2}{24}\Big)=\frac{5\sqrt2}{3n^2}\approx\frac{2.357}{n^2}
$$

Now fix the target $\epsilon=0.01$ (the same target as Practice
Question 1). First order needs $2.828/n\leq0.01$, so $n=283$ steps
($n=282$ gives $0.01003$, just over). Second order needs
$2.357/n^2\leq0.01$, so $n=16$ steps ($15^2=225$ gives $0.01048$, just
over). In exponentials applied: $2\times283=566$ for first order
against $2\times16+1=33$ for Strang (adjacent $A$ half-steps merge, so
$n$ symmetric steps cost $2n+1$ exponentials, not $3n$). A factor of
about 17 fewer gates, from one symmetrization.

Where is the crossover? Setting the two step counts equal,
$\tfrac{2\sqrt2}\epsilon=\sqrt{\tfrac{5\sqrt2}{3\epsilon}}$, gives
$\epsilon=\tfrac{8}{5\sqrt2/3}=\tfrac{24}{5\sqrt2}\approx3.39$. First
order is cheaper only above that, at an error target three times the
norm of the unitary being approximated, where both formulas call for
fewer than one step and the word "approximation" has stopped meaning
anything. For any target you would use in practice the symmetric
splitting wins, and its margin widens like $1/\sqrt\epsilon$ as the
target tightens.

## Confusing Total Time With Step Size

<Callout type="warning">
**Assuming the Trotter error bound requires $A$ and $B$ to be small.**
It doesn't: it requires $\delta=t/n$ (the *step size*) to be small. A
large Hamiltonian norm just means more steps ($n$) are needed to make
$\delta$ small enough for a given target accuracy; the derivation places
no restriction on $\|A\|,\|B\|$ themselves, only on $\|[A,B]\|$ and how
many pieces $t$ gets chopped into.
</Callout>

<Callout type="note">
**Expecting the operator-norm bound and the Frobenius-norm-based
estimate used here to match exactly.** They don't have to: the Frobenius
norm only ever *overestimates* the operator norm, so every bound in this
lesson computed with $\|\cdot\|_F$ remains a valid, if slightly loose,
bound on the true operator-norm error. The observed ratios above
(actual error below the bound at every $n$) are exactly this
looseness in action, not a sign of an error in the derivation.
</Callout>

   \frac{t^2}{2n}\|[A,B]\|\leq\epsilon
   \;\Longleftrightarrow\;
   n\geq\frac{t^2\|[A,B]\|}{2\epsilon}=\frac{1\cdot4\sqrt2}{2(0.01)}=\frac{5.656854}{0.02}=282.84,
   $$

   and $n$ must be a whole number, so $n=283$. The boundary is worth
   confirming because $282.84$ is uncomfortably close to $282$: at $n=282$
   the bound reads $0.010030$, over target, and at $n=283$ it reads
   $0.0099944$, under. Rounding down would have failed the specification.

   The more useful observation is how much slack that number carries.
   The measured errors in the table above satisfy
   $\text{error}\times n\to0.996$, so the *actual* error is about
   $0.996/n$ and reaches $0.01$ at roughly $n=100$. The certified bound
   asks for nearly three times as many steps as the job needs, and the
   overshoot has two identifiable sources, neither of which is a mistake.

   About a factor of $\sqrt2$ comes from using the Frobenius norm in place
   of the operator norm. For this Hamiltonian $[A,B]=2i(Y\otimes Z+Z\otimes Y)$,
   and $(Y\otimes Z+Z\otimes Y)^2=2I+2X\otimes X$ has eigenvalues $4$ and
   $0$, so $\|[A,B]\|=4$ exactly while $\|[A,B]\|_F=4\sqrt2$.

   The remaining factor of about two comes from the triangle inequality in
   the submultiplicativity lemma, which adds the $n$ per-step errors as
   though they all point the same way. They do not; successive steps
   partially cancel.

   This is the normal condition of a rigorous resource estimate. The bound
   is a guarantee, so it has to hold in the worst case over everything it
   declines to track, and a factor of three in step count is a cheap price
   for a number you can put in a proof. It is also why papers report both
   a proved bound and a measured error, and why the two are never expected
   to coincide.

   </details>

2. Explain, from the single-step Taylor derivation, exactly why
   $[A,B]=0$ makes the product formula *exact* at every Trotter step,
   not merely small-error.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because when $A$ and $B$ commute the two expansions agree term by term
   at *every* order, not only at the $\delta^2$ order the boxed result
   examines.

   It is worth being clear that the boxed result alone does not establish
   this. It says the difference is $-\tfrac{\delta^2}2[A,B]+O(\delta^3)$,
   so setting $[A,B]=0$ kills the leading term and leaves an $O(\delta^3)$
   remainder that, for all the boxed statement knows, might be nonzero.
   Exactness needs the same comparison run at general order $k$.

   Do that. Collect the $\delta^k$ coefficient on each side. The product
   formula gives the Cauchy product of the two series,

   $$
   \left[e^{-iA\delta}e^{-iB\delta}\right]_k=(-i)^k\sum_{m+n=k}\frac{A^mB^n}{m!\,n!},
   $$

   while the exact exponential gives

   $$
   \left[e^{-i(A+B)\delta}\right]_k=\frac{(-i)^k}{k!}(A+B)^k
   =\frac{(-i)^k}{k!}\sum_{\text{words } w}w,
   $$

   the sum running over all $2^k$ ordered words in $A$ and $B$ of length
   $k$. With $[A,B]=0$ every word with $m$ letters $A$ and $n$ letters $B$
   collapses to $A^mB^n$, and there are $\binom km$ such words, so the
   second expression becomes
   $(-i)^k\sum_{m+n=k}\binom km A^mB^n/k!=(-i)^k\sum_{m+n=k}A^mB^n/(m!\,n!)$.
   The two coefficients are identical, for every $k$. Hence
   $e^{-iA\delta}e^{-iB\delta}=e^{-i(A+B)\delta}$ exactly, with no
   remainder at all.

   The commutativity is used in exactly one place: reordering the letters
   of each word so the binomial theorem applies. That single step is the
   whole content of the failure in the general case, and it is why the
   error at order $\delta^2$ came out as a commutator rather than as some
   other combination.

   Physically the statement is unremarkable once seen this way. Commuting
   terms can be evolved independently because they generate independent
   one-parameter groups; "do all of $A$, then all of $B$" and "do both at
   once" are the same operation, not an approximation to it. A pure Ising
   coupling with no transverse field is the case in point: every term is
   diagonal, everything commutes, and Trotterization of it is exact at any
   step size, which is the sanity check any implementation should be run
   against first.

   </details>

3. The submultiplicativity lemma's proof telescopes a difference of
   products into a sum. Explain, in your own words, why each term in
   that sum has norm exactly $\|U_k-V_k\|$, using the fact that
   multiplying by a unitary preserves operator norm.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because each summand is $(U_k-V_k)$ with a unitary glued on each side,
   and the hypothesis on the norm is that gluing a unitary on either side
   changes nothing.

   The $k$-th summand is

   $$
   \underbrace{V_n\cdots V_{k+1}}_{W_L}\,(U_k-V_k)\,\underbrace{U_{k-1}\cdots U_1}_{W_R}.
   $$

   A product of unitaries is unitary, so $W_L$ and $W_R$ are unitary. Then
   $\|W_L M W_R\|=\|MW_R\|=\|M\|$ by two applications of unitary
   invariance, giving $\|W_L(U_k-V_k)W_R\|=\|U_k-V_k\|$. The word
   "exactly" in the statement is doing real work: this is an equality, not
   the inequality $\|W_LMW_R\|\leq\|W_L\|\|M\|\|W_R\|$ that general
   submultiplicativity would give.

   Both norms this lesson uses have that property, for different-looking
   reasons that are the same reason. The operator norm is the largest
   singular value, and multiplying by a unitary permutes nothing in the
   singular value list. The Frobenius norm is $\sqrt{\mathrm{Tr}(M^\dagger M)}$,
   and $\mathrm{Tr}(W^\dagger M^\dagger MW)=\mathrm{Tr}(M^\dagger M)$ by
   cyclicity. Every Schatten norm behaves the same way, which is why the
   lemma is stated for unitarily invariant norms rather than for one
   specific choice.

   Now see what would go wrong without unitarity. If the factors were
   merely bounded with $\|U_k\|,\|V_k\|\leq C$ for some $C>1$, each
   summand would only be bounded by $C^{n-1}\|U_k-V_k\|$, and the total
   would grow like $nC^{n-1}\varepsilon$: exponential in the number of
   steps, which for $n=283$ is not a bound anybody could use. The linear
   $n\varepsilon$ result, and with it the whole $O(t^2/n)$ scaling and
   every gate count derived from it, rests entirely on the fact that both
   the exact evolution and its Trotter approximation are unitary. Errors in
   a quantum circuit accumulate additively rather than multiplicatively,
   and this lemma is where that fact is proved.

   </details>

4. Rerun the Strang-splitting Taylor multiplication for the reversed
   ordering $e^{-iB\delta/2}e^{-iA\delta}e^{-iB\delta/2}$ and confirm
   the $\delta^2$ cancellation survives swapping the roles of $A$ and
   $B$. Then, using the cited Childs et al. bound with the roles
   swapped, compute this ordering's per-step error coefficient for the
   lesson's Ising Hamiltonian. Which ordering has the smaller bound?

   <details className="answer-reveal">
   <summary>Answer</summary>

   The cancellation survives, and the reversed ordering has the *smaller*
   bound: coefficient $\tfrac{4\sqrt2}{3}\approx1.886$ against
   $\tfrac{5\sqrt2}{3}\approx2.357$, a $20\%$ improvement for free.

   **The cancellation.** There is nothing to rerun, and seeing why is
   better than grinding through the multiplication again. The derivation
   above produced

   $$
   S_2(\delta)=I-i(A+B)\delta-\tfrac12\big(A^2+AB+BA+B^2\big)\delta^2+O(\delta^3)
   =I-i(A+B)\delta-\tfrac12(A+B)^2\delta^2+O(\delta^3),
   $$

   and $(A+B)^2$ is symmetric under swapping $A$ and $B$. Every step of
   the multiplication treats the outer operator and the inner one by the
   same rules, so relabelling gives the same expansion. Both orderings are
   second order.

   The structural reason is worth having, because it explains why every
   symmetric splitting behaves this way. Both products are palindromic, so
   $S_2(-\delta)=S_2(\delta)^{-1}$, and the exact exponential satisfies the
   same identity. A difference of two functions that both invert under
   $\delta\to-\delta$ can carry only odd powers of $\delta$ in its error,
   so the $\delta^2$ term has no choice but to vanish. Symmetrizing buys
   the extra order; which operator sits in the middle does not affect
   whether it is bought.

   **The coefficient.** It does affect how much the third order costs. In
   the cited bound the $1/12$ weight attaches to the *inner* operator
   nested twice against the outer one, and $1/24$ to the reverse. For the
   lesson's ordering (outer $A$, inner $B$),

   $$
   \frac{1}{12}\|[B,[B,A]]\|_F+\frac{1}{24}\|[A,[A,B]]\|_F=\frac{16\sqrt2}{12}+\frac{8\sqrt2}{24}=\frac{5\sqrt2}{3}\approx2.357.
   $$

   Swapping the roles puts $B$ outside and $A$ inside, so the two weights
   trade places:

   $$
   \frac{1}{12}\|[A,[A,B]]\|_F+\frac{1}{24}\|[B,[B,A]]\|_F=\frac{8\sqrt2}{12}+\frac{16\sqrt2}{24}=\frac{4\sqrt2}{3}\approx1.886.
   $$

   The reversed ordering wins by a factor of $4/5$. At the lesson's target
   $\epsilon=0.01$ it needs $n^2\geq1.886/0.01=188.6$, so $n=14$ steps
   ($n=13$ gives $0.01116$, over target) against the $16$ the original
   ordering needs.

   **The rule that generalizes.** The larger of the two nested-commutator
   norms should be the one multiplied by $1/24$, so the operator whose
   *self*-nested commutator against the other is larger belongs on the
   outside. Here $\|[B,[B,A]]\|_F=16\sqrt2$ exceeds
   $\|[A,[A,B]]\|_F=8\sqrt2$, so the transverse field $B$ goes in the half
   steps and the coupling $A=Z\otimes Z$ sits in the middle. That is a real
   compiler decision with a real gate cost attached, and it is invisible
   to any analysis that stops at "the method is second order". It also
   comes with a caveat: the ranking is a statement about this bound and
   this Hamiltonian, so it should be recomputed rather than assumed for a
   different term splitting.

   </details>

## Summary

- The first-order Trotter product formula's single-step error is
  derived exactly, via direct Taylor expansion, as
  $-\frac{\delta^2}2[A,B]+O(\delta^3)$: noncommutativity is the entire
  source of the error.
- A general submultiplicativity lemma for products of unitaries (proved
  here via a telescoping sum) converts this single-step bound into a
  total-error bound, $\frac{t^2}{2n}\|[A,B]\|$, over $n$ steps.
- The symmetric Strang splitting $e^{-iA\delta/2}e^{-iB\delta}e^{-iA\delta/2}$
  cancels the entire $\delta^2$ error term (derived by the same Taylor
  expansion), giving $O(t^3/n^2)$ total error; on this lesson's
  Hamiltonian at target error $0.01$, that is 16 steps instead of 283.
  Higher-order commutator bounds (Childs et al. 2021) and randomized
  compilation (qDRIFT, Campbell 2019) extend the same story, and are
  cited, not re-derived.
- Verified numerically on a real 2-qubit Ising Hamiltonian, using this
  platform's actual `Matrix`/`Complex`/gate primitives plus a
  from-scratch Taylor-series matrix exponential: the single-step error
  ratio converges to exactly $1$ as $\delta\to0$, and the $n$-step error
  scales as $O(1/n)$, with the measured log-log slope reaching $-1.00$.
- The whole quantitative story assumes $A$ and $B$ are *bounded*. For the
  unbounded Hamiltonians of continuum quantum mechanics, Trotter–Kato
  still gives strong convergence but no rate, which is why rigorous
  simulation bounds discretize first.
