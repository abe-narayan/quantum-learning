export const gamma = 0.3;
export const lambda = 0.3;

export const basisMatrix = (i, j) => {
  const data = [
    [i === 0 && j === 0 ? Complex.ONE : Complex.ZERO, i === 0 && j === 1 ? Complex.ONE : Complex.ZERO],
    [i === 1 && j === 0 ? Complex.ONE : Complex.ZERO, i === 1 && j === 1 ? Complex.ONE : Complex.ZERO],
  ];
  return new Matrix(data);
}

export const choiMatrix = (krausOps) => {
  const pairs = [0, 1].flatMap((i) => [0, 1].map((j) => [i, j]));
  return pairs.reduce((J, [i, j]) => {
    const eij = basisMatrix(i, j);
    const Eeij = applyKrausChannel(eij, krausOps);
    return J.add(eij.tensor(Eeij));
  }, Matrix.zeros(4, 4));
}

## Complete Positivity, Finally Defined

Open Quantum Systems & Kraus Operators stated the
<Term id="kraus-operators-cptp-maps">Kraus sum representation</Term>
$\mathcal E(\rho)=\sum_kK_k\rho K_k^\dagger$ as *the* general form of a
physically valid channel, without proving that every completely positive,
trace-preserving map has one. This lesson supplies that proof, via a tool
that turns an entire *map* (an operator on operators) into a single
ordinary matrix that can be diagonalized with machinery this platform
already has: the **Choi–Jamiołkowski isomorphism**.

Before the algebra, it is worth seeing what a CPTP map *does*, because the
constraint has a shape. A channel maps the Bloch ball into itself, and
"into itself" is the whole of complete positivity plus trace preservation
made visible. The figure below takes the $x$–$z$ cross-section of the ball
and pushes every point through `amplitudeDampingChannel` at three
strengths, using this platform's own `applyKrausChannel` and
`densityMatrixToBlochVector` to place each point.

statement that this containment survives even when the qubit being
squeezed is entangled with a spectator the channel never touches, and
that extra clause is what the Choi matrix is built to test.

## The Choi Matrix as a Positivity Test

### Complete positivity, precisely

<DefinitionBox title="Complete positivity">

A linear map $\mathcal E$ on $d\times d$ matrices is **positive** if
$\rho\geq0\Rightarrow\mathcal E(\rho)\geq0$. It is **completely positive**
(CP) if $\mathbb 1_n\otimes\mathcal E$ is positive for every $n$: acting
on an arbitrary larger system while leaving an $n$-dimensional
"spectator" subsystem alone must *still* produce a valid state.

</DefinitionBox>

This is a
strictly stronger requirement than positivity (there exist positive maps,
like transposition, that are not completely positive), and it's the
correct physical requirement: a subsystem's evolution must remain valid
even when it's entangled with something else, the situation this
platform's `partialTrace`-based reduced states are built to describe.

### The Choi matrix

<EquationReveal
  terms={[
    { id: "J", symbol: "J(ℰ)", gloss: "The Choi matrix, a single d²×d² matrix that encodes the entire channel ℰ." },
    { id: "ij", symbol: "|i⟩⟨j|", gloss: "Every basis matrix, including non-positive-semi-definite ones (i≠j); ℰ is still a well-defined linear map on them." },
    { id: "Eij", symbol: "ℰ(|i⟩⟨j|)", gloss: "The channel's output when fed that basis matrix." },
  ]}
>

$$
J(\mathcal E) \equiv \sum_{i,j=0}^{d-1} |i\rangle\langle j|\otimes\mathcal E\big(|i\rangle\langle j|\big)
$$

</EquationReveal>

a single $d^2\times d^2$ matrix built by feeding $\mathcal E$ every basis
matrix $|i\rangle\langle j|$ (not just valid density matrices: $|i\rangle\langle j|$
for $i\neq j$ isn't positive semi-definite, but $\mathcal E$ is still a
well-defined *linear* map on it) and stacking the results. Equivalently,
$J(\mathcal E)=d\,(\mathbb 1\otimes\mathcal E)(|\Omega^+\rangle\langle\Omega^+|)$
for $|\Omega^+\rangle=\frac{1}{\sqrt d}\sum_i|i\rangle|i\rangle$, Schmidt
Decomposition and Purification's maximally entangled purification of
$I/d$, sent halfway through the channel. This is the isomorphism's
physical content: $J(\mathcal E)$ is exactly what comes out of sending
one half of a maximally entangled pair through $\mathcal E$ and leaving
the other half alone.

### Complete positivity $\Longleftrightarrow$ $J(\mathcal E)\geq0$

<TheoremBox title="Choi's theorem" provenance="derived">

**Hypotheses.** $\mathcal E$ is a linear map on the $d\times d$ complex
matrices, with $d$ **finite**. Nothing is assumed about positivity,
trace, or the existence of any Kraus form.

**Conclusion.** $\mathcal E$ is completely positive if and only if
$J(\mathcal E)\geq0$, and in that case the eigendecomposition of
$J(\mathcal E)$ *constructs* a Kraus family $\{K_k\}$ with
$\mathcal E(\rho)=\sum_kK_k\rho K_k^\dagger$. The number of nonzero
eigenvalues is the minimal Kraus rank, so $r\leq d^2$ always.

The finiteness of $d$ is load-bearing and is the reason this proof is
short. In infinite dimensions the sum defining $J$ need not converge, the
spectral decomposition of $J$ can have continuous parts, and the
corresponding statement requires normality assumptions on $\mathcal E$
and a different argument (Stinespring's, which the Shannon-theory course
takes up). Every claim below is a finite-dimensional claim.

Choi (1975); the equivalent state-channel correspondence is due to
Jamiołkowski (1972).

</TheoremBox>

**Easy direction.** If $\mathcal E$ has a Kraus form
$\mathcal E(\rho)=\sum_kK_k\rho K_k^\dagger$, first check
$\mathbb1_n\otimes\mathcal E$ is positive for any $n$ (i.e. $\mathcal E$
is CP, not just positive): $(\mathbb1_n\otimes\mathcal E)(\sigma)=\sum_k(\mathbb1_n\otimes K_k)\sigma(\mathbb1_n\otimes K_k)^\dagger$
is manifestly a sum of terms of the form $A\sigma A^\dagger$, each
positive semi-definite whenever $\sigma$ is (for any vector $|\phi\rangle$,
$\langle\phi|A\sigma A^\dagger|\phi\rangle=\langle A^\dagger\phi|\sigma|A^\dagger\phi\rangle\geq0$
since $\sigma\geq0$), so the whole sum is too. Then $J(\mathcal E)=d(\mathbb1\otimes\mathcal E)(|\Omega^+\rangle\langle\Omega^+|)$
is the image of the positive operator $|\Omega^+\rangle\langle\Omega^+|$
under the now-established-positive map $\mathbb1\otimes\mathcal E$,
hence $J(\mathcal E)\geq0$.

**Hard direction, and the substance of the theorem.** Suppose
$J(\mathcal E)\geq0$.

<DerivationSteps>
  <DerivationStep annotation="The spectral theorem, general finite dimensions. Each eigenvector is indexed by the same (i,ℓ) pair the definition of J used.">
    $J(\mathcal E)=\sum_k\mu_k|v_k\rangle\langle v_k|$, $\mu_k\geq0$, with
    each $|v_k\rangle=\sum_{i,\ell}(v_k)_{i\ell}|i\rangle|\ell\rangle$ an
    eigenvector of the $d^2$-dimensional Choi matrix.
  </DerivationStep>
  <DerivationStep annotation="Output index ℓ becomes the matrix row, input index i the column, which is the same index that labelled which |i⟩⟨j| was fed into E when J was built. This reshaping directly inverts the 'vectorize K_k' map used in the easy direction.">
    Define, for each $k$, the $d\times d$ matrix $K_k$ by
    **reshaping** $|v_k\rangle$:

    $$
    (K_k)_{\ell i} \equiv \sqrt{\mu_k}\,(v_k)_{i\ell}
    $$
  </DerivationStep>
  <DerivationStep annotation="Checked term by term (the worked example below verifies this identity numerically rather than leaving it purely symbolic).">
    $\sum_{ij}|i\rangle\langle j|\otimes K_k|i\rangle\langle j|K_k^\dagger=\big(\sqrt{\mu_k}\big)^2|v_k\rangle\langle v_k|=\mu_k|v_k\rangle\langle v_k|$
    (the two factors of $\sqrt{\mu_k}$ in the reshaping definition, one
    from $K_k$ and one from $K_k^\dagger$, multiply to $\mu_k$)
    reproduces exactly the $k$-th term of the eigendecomposition.
  </DerivationStep>
  <DerivationStep annotation="Matching term-by-term against the definition J(E) = Σ_ij |i⟩⟨j| ⊗ E(|i⟩⟨j|) forces E(|i⟩⟨j|) = Σ_k K_k|i⟩⟨j|K_k† for every basis matrix. Since these span the full space of matrices, this extends to every ρ by linearity.">
    Summing over $k$:
    $\sum_k\sum_{ij}|i\rangle\langle j|\otimes K_k|i\rangle\langle j|K_k^\dagger=J(\mathcal E)$,
    so $\mathcal E(\rho)=\sum_kK_k\rho K_k^\dagger$ for *every* $\rho$.
    $\mathcal E$ has a Kraus form. $\blacksquare$
  </DerivationStep>
</DerivationSteps>

### Trace-preservation, restated on the Choi matrix

<TheoremBox title="Trace-preservation on the Choi matrix" provenance="derived">

**Hypotheses.** The same as Choi's theorem: $\mathcal E$ linear on the
$d\times d$ matrices, $d$ finite. Positivity is *not* assumed, and this
is a separate condition, not a restatement: the two boxes constrain different
things about $J(\mathcal E)$ and neither implies the other.

$\mathcal E$ is trace-preserving if and only if
$\text{Tr}_{\text{out}}\big(J(\mathcal E)\big)=I$ (tracing out the
*second* tensor factor, the output copy).

</TheoremBox>

**Proof.** $\text{Tr}_{\text{out}}(J(\mathcal E))=\sum_{ij}|i\rangle\langle j|\,\text{Tr}\big(\mathcal E(|i\rangle\langle j|)\big)$.
If $\mathcal E$ preserves trace, $\text{Tr}(\mathcal E(|i\rangle\langle j|))=\text{Tr}(|i\rangle\langle j|)=\delta_{ij}$,
so the sum collapses to $\sum_i|i\rangle\langle i|=I$. Conversely, if
$\text{Tr}_{\text{out}}(J(\mathcal E))=I$, matching coefficients of
$|i\rangle\langle j|$ forces $\text{Tr}(\mathcal E(|i\rangle\langle j|))=\delta_{ij}=\text{Tr}(|i\rangle\langle j|)$
on the whole spanning set, hence on every $\rho$ by linearity.
$\blacksquare$

The presets above freeze $\gamma=\lambda=0.3$, which hides a fact the
same `choiMatrix` construction reveals once it's swept over every
strength $s\in[0,1]$: amplitude damping's *bottom* block eigenvalue
$\mu_2$ isn't small because $\gamma=0.3$ happens to be small. It is
$\equiv0$ for **every** $\gamma$, while the top one is the exact line
$\mu_1(\gamma)=2-\gamma$. What carries $\gamma$-dependence is
the *isolated* diagonal entry $J(2,2)=\gamma$, climbing linearly from
$0$ to $1$. Since amplitude damping's minimal Kraus rank is the count
of nonzero values among $\{\mu_1,\mu_2,J(2,2),J(1,1){=}0\}$, that makes
the channel rank $1$ (the trivial identity map, no Kraus operator
besides $K_0=I$ needed) only exactly at $\gamma=0$, and rank $2$ for
*every* $\gamma\in(0,1]$, all the way through total decay at
$\gamma=1$. The rank never drops back down at that endpoint. Dephasing
looks structurally different: its two isolated entries $J(1,1)$ and
$J(2,2)$ stay pinned at exactly $0$ for every $\lambda$, so its rank is
governed entirely by its *block*, whose own eigenvalues
$\mu_1(\lambda)=2-\lambda$ and $\mu_2(\lambda)=\lambda$ are both
nonzero throughout $(0,1)$; dephasing never has a trivial isolated
component to track, unlike amplitude damping.

## A Quantifier Over Every Spectator System

<InsightBlock>
  Complete positivity is defined by a quantifier over every spectator
  system of every dimension. The Choi matrix eliminates that quantifier.
  One finite matrix, one eigenvalue check, and the infinite family of
  conditions is discharged.
</InsightBlock>

The <Term id="choi-jamiolkowski-isomorphism">Choi–Jamiołkowski isomorphism</Term>
says a channel and a bipartite quantum state carry the same information,
related by "send half of a maximally entangled pair through it." The
practical consequence is the one worth dwelling on. Complete positivity's
definition quantifies over *every* possible input state and *every*
possible larger system the input might be entangled with, which is not a
condition anyone can check by inspection. Choi's theorem replaces it with
the positive semi-definiteness of a single $d^2\times d^2$ matrix: an
eigenvalue computation, finite and mechanical.

The geometric reading connects to the figure this lesson opened with. The
Bloch ball is the state space of one qubit; the Choi matrix is a state on
*two*. Asking whether a channel is completely positive is asking whether
that two-qubit object is a legal state, and the reason the one-qubit
picture is not enough is the same reason the transpose map passes
the ball test and fails the Choi test.

## Positivity Mistaken for Complete Positivity

<Callout type="mistake">
**Checking only that $\mathcal E$ is positive, not completely positive.**
Positivity alone permits maps (like matrix transposition) that fail
badly once the input is entangled with an untouched spectator system;
the Choi matrix test given here checks *complete* positivity directly,
which is the physically required condition.
</Callout>

<Callout type="warning">
**Forgetting the $\text{Tr}_{\text{out}}(J(\mathcal E))=I$ condition.**
Positive semi-definiteness of $J(\mathcal E)$ alone only guarantees
*complete positivity*; a completely positive map that shrinks or grows
total probability (not trace-preserving) still has $J(\mathcal E)\geq0$
but fails this second, independent condition. Both must hold for
$\mathcal E$ to be a physically valid channel.
</Callout>

## Practice Questions

1. Verify by direct computation that $\text{Tr}(J(\mathcal E))=2$ for
   both the amplitude-damping and dephasing Choi matrices above, and
   explain why this number must always equal $d$ for any single-qubit
   trace-preserving channel.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Write both matrices out in the ordered basis
   $\{|00\rangle,|01\rangle,|10\rangle,|11\rangle\}$, where the first
   index is the input label $i$ and the second the output label. For
   amplitude damping at $\gamma=0.3$, the four blocks are
   $\mathcal E(|0\rangle\langle0|)=|0\rangle\langle0|$,
   $\mathcal E(|1\rangle\langle1|)=\mathrm{diag}(\gamma,1-\gamma)$, and
   $\mathcal E(|0\rangle\langle1|)=\sqrt{1-\gamma}\,|0\rangle\langle1|$,
   giving

   $$
   J_{AD}=\begin{pmatrix}1&0&0&0.83666\\0&0&0&0\\0&0&0.3&0\\0.83666&0&0&0.7\end{pmatrix},
   \qquad
   J_{DP}=\begin{pmatrix}1&0&0&0.7\\0&0&0&0\\0&0&0&0\\0.7&0&0&1\end{pmatrix}.
   $$

   The diagonals sum to $1+0+0.3+0.7=2$ and $1+0+0+1=2$. Both are $d=2$,
   and both agree with the spectra in the table, since
   $1.7+0.3+0+0=2$ in each row.

   The reason it must equal $d$ is a two-line consequence of the
   definition, using $\mathrm{Tr}(A\otimes B)=\mathrm{Tr}A\,\mathrm{Tr}B$:

   $$
   \mathrm{Tr}\,J(\mathcal E)=\sum_{i,j}\mathrm{Tr}\big(|i\rangle\langle j|\big)\,\mathrm{Tr}\big(\mathcal E(|i\rangle\langle j|)\big)
   =\sum_{i,j}\delta_{ij}\,\delta_{ij}=\sum_i1=d,
   $$

   where the second $\delta_{ij}$ is exactly where trace preservation
   enters: $\mathrm{Tr}\,\mathcal E(|i\rangle\langle j|)=\mathrm{Tr}|i\rangle\langle j|=\delta_{ij}$.
   Equivalently, and more memorably, $J/d$ is the state you get by sending
   half of a maximally entangled pair through the channel, so it is a
   density matrix and its trace is $1$.

   The trap here is treating $\mathrm{Tr}\,J=d$ as a *test* for trace
   preservation. It is one scalar equation; trace preservation is the
   $d^2$ equations $\mathrm{Tr}_{\rm out}J=I$. A CP map with a single Kraus
   operator $A=\mathrm{diag}(\sqrt2,0)$ has
   $\mathrm{Tr}\,J=\mathrm{Tr}(A^\dagger A)=2=d$ but
   $\mathrm{Tr}_{\rm out}J=\mathrm{diag}(2,0)\neq I$, and it maps
   $|1\rangle\langle1|$ to $0$ while doubling the trace of
   $|0\rangle\langle0|$. Passing the trace check means only that the map
   preserves trace *on average over the maximally mixed input*.

   </details>

2. The dephasing channel's Choi block has eigenvalues $\{1.7,0.3\}$,
   *both* nonzero (unlike amplitude damping's $\{1.7,0\}$). What does
   this say about dephasing's minimal Kraus rank compared to amplitude
   damping's?

   <details className="answer-reveal">
   <summary>Answer</summary>

   Nothing, and that is the point of the question. Both channels have
   minimal Kraus rank exactly $2$.

   The minimal Kraus rank is the rank of the *whole* Choi matrix, not of
   one block of it. Reading the full spectra from the table:

   Amplitude damping at $\gamma=0.3$: $\{1.7,\;0.3,\;0,\;0\}$, where the
   $1.7$ comes from the block and the $0.3$ is the isolated entry
   $J(2,2)=\gamma$. Two nonzero eigenvalues, rank $2$.

   Dephasing at $\lambda=0.3$: $\{1.7,\;0.3,\;0,\;0\}$, where both nonzero
   values come from the block and both isolated entries are $0$. Two
   nonzero eigenvalues, rank $2$.

   Identical rank, identical spectrum in fact, arranged differently inside
   the matrix. What the block structure tells you is *where* each Kraus
   operator's support sits, not how many there are. Amplitude damping's
   two Kraus operators are $K_0=\mathrm{diag}(1,\sqrt{1-\gamma})$, which is
   diagonal and therefore lives in the $\{|00\rangle,|11\rangle\}$ block,
   and $K_1=\sqrt\gamma\,|0\rangle\langle1|$, which is purely off-diagonal
   and shows up as the isolated entry. Dephasing's are
   $\sqrt{1-\lambda/2}\,I$ and $\sqrt{\lambda/2}\,Z$, both diagonal, so both
   land in the same block.

   Reading the question the tempting way, "dephasing has two nonzero block
   eigenvalues and damping has one, so dephasing needs more Kraus
   operators", gets the right count for dephasing and the wrong one for
   damping by ignoring the isolated entry. The lesson's own reconstruction
   makes the correction concrete: it builds $K_0$ from the block
   eigenvector and $K_1$ from the isolated entry, and needs both.

   Worth adding the endpoints, since they are where rank actually varies.
   The full amplitude-damping spectrum is $\{2-\gamma,\,0,\,\gamma,\,0\}$
   and the full dephasing spectrum is $\{2-\lambda,\,\lambda,\,0,\,0\}$.
   Each has rank $1$ only at strength $0$, where the channel is the
   identity, and rank $2$ for every strength in $(0,1]$. Neither ever
   reaches the theoretical maximum $d^2=4$, which means both admit a
   Stinespring dilation with a single environment qubit rather than the
   two qubits a generic channel would need.

   </details>

3. A single unitary channel $\mathcal E(\rho)=U\rho U^\dagger$ has Choi
   matrix $J(\mathcal E)=|v\rangle\langle v|$ for
   $|v\rangle=\sum_i|i\rangle\otimes U|i\rangle$, rank exactly $1$.
   Explain why this matches the fact that a unitary channel needs only
   one Kraus operator.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because the reconstruction in Choi's theorem produces exactly one Kraus
   operator per nonzero eigenvalue, and a rank-1 matrix has exactly one.
   The correspondence is not an analogy; the count is the same count.

   Run the machine and watch it hand back $U$. First,
   $\langle v|v\rangle=\sum_{i,j}\langle i|j\rangle\langle Ui|Uj\rangle=\sum_i1=d$,
   so $|v\rangle$ is not normalized and $J=|v\rangle\langle v|$ has the
   single nonzero eigenvalue $\mu=d$ with normalized eigenvector
   $|\hat v\rangle=|v\rangle/\sqrt d$, whose components are
   $(\hat v)_{i\ell}=U_{\ell i}/\sqrt d$. Reshaping as the theorem
   prescribes,

   $$
   (K)_{\ell i}=\sqrt\mu\,(\hat v)_{i\ell}=\sqrt d\cdot\frac{U_{\ell i}}{\sqrt d}=U_{\ell i},
   $$

   so $K=U$ exactly, and $\mathcal E(\rho)=U\rho U^\dagger$ is recovered.
   The $\sqrt{\mu}$ in the reshaping is what restores the normalization the
   eigenvector convention removed.

   The converse is the sharper statement and is worth having. Kraus rank
   $1$ means $\mathcal E(\rho)=K\rho K^\dagger$ for a single $K$; adding
   trace preservation, $\mathrm{Tr}_{\rm out}J=I$ becomes $K^\dagger K=I$,
   which for a square $K$ makes it unitary. So

   $$
   \text{Kraus rank }1 \text{ and trace preserving} \iff \text{the channel is unitary},
   $$

   and neither half can be dropped: rank $1$ without trace preservation
   allows any $K$ at all, and trace preservation without rank $1$ is every
   noisy channel in this lesson.

   The physical reading ties it to the isomorphism. $J/d$ is the state of
   the maximally entangled pair after one half passes through the channel,
   and rank $1$ means that state is *pure*. A pure output means the
   channel deposited no information anywhere else: nothing became
   entangled with an environment, nothing was lost, and the map is
   reversible. Every eigenvalue of $J$ beyond the first is a measure of how
   much the channel has mixed the reference pair, which is why Kraus rank
   is a reasonable first count of "how many ways this channel can go
   wrong."

   </details>

4. Using the trace-preservation identity, explain why a channel with
   $J(\mathcal E)\geq0$ but $\text{Tr}_{\text{out}}(J(\mathcal E))\neq I$
   could still be a valid *sub-normalized* quantum operation (used to
   describe one branch of a measurement) even though it isn't a complete
   channel.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because a measurement branch is not supposed to preserve trace. The
   trace it produces is the probability that the branch happened, and a
   probability below $1$ is exactly what "this outcome did not always
   occur" looks like.

   Make it quantitative. $J\geq0$ gives a Kraus form
   $\mathcal E(\rho)=\sum_kK_k\rho K_k^\dagger$, and

   $$
   \mathrm{Tr}\,\mathcal E(\rho)=\mathrm{Tr}\Big(\rho\sum_kK_k^\dagger K_k\Big)=\mathrm{Tr}(\rho\,Q),\qquad Q\equiv\sum_kK_k^\dagger K_k,
   $$

   while $\mathrm{Tr}_{\rm out}J$ is $Q$ up to a transpose, which leaves
   its spectrum alone. So $\mathrm{Tr}_{\rm out}J=I$ says $Q=I$ and every
   input keeps its trace, and $\mathrm{Tr}_{\rm out}J\neq I$ says some
   input does not.

   The condition that makes the map physically meaningful anyway is
   sharper than "not equal to $I$", and this is the part the question's
   phrasing invites you to skip:

   $$
   0\leq \mathrm{Tr}_{\rm out}J(\mathcal E)\leq I.
   $$

   That is **trace non-increasing**, and it is exactly the requirement that
   $\mathrm{Tr}(\rho Q)\in[0,1]$ for every state $\rho$, since the extreme
   values of $\mathrm{Tr}(\rho Q)$ over states are $Q$'s smallest and
   largest eigenvalues. A CP map whose $Q$ has an eigenvalue above $1$ is
   not a sub-normalized operation at all; fed the corresponding
   eigenstate it reports an outcome probability greater than one, which is
   not a description of anything. The earlier $A=\mathrm{diag}(\sqrt2,0)$
   example is precisely such a map, so having the right trace is no defence.

   Given trace non-increase, the standard measurement dictionary reads:
   $\mathrm{Tr}\,\mathcal E_m(\rho)=\mathrm{Tr}(\rho\,Q_m)$ is the
   probability of outcome $m$, and the post-measurement state is the
   renormalized $\mathcal E_m(\rho)/\mathrm{Tr}\,\mathcal E_m(\rho)$,
   defined whenever that probability is nonzero. The individual branches
   are sub-normalized; the collection is not. Summing over outcomes,
   $\sum_mQ_m=I$ is the completeness relation, so
   $\sum_m\mathrm{Tr}_{\rm out}J(\mathcal E_m)=I$ and the total map
   $\sum_m\mathcal E_m$ is a genuine channel: exactly the channel you get
   by performing the measurement and then throwing the outcome away.

   Those $Q_m$ are POVM elements, which is where this thread is picked up
   in POVMs and Generalized Measurement. The structure to carry forward is
   that the two Choi conditions are genuinely independent: positivity of
   $J$ is what makes a map physical at all, and the constraint on
   $\mathrm{Tr}_{\rm out}J$ is a separate dial running from "deterministic
   channel" at $=I$ through "one branch of a measurement" at $\leq I$ to
   "not a description of anything" past it.

   </details>

## Summary

- The Choi matrix $J(\mathcal E)=\sum_{ij}|i\rangle\langle j|\otimes\mathcal E(|i\rangle\langle j|)$
  turns a channel into a single ordinary matrix.
- $\mathcal E$ is completely positive if and only if $J(\mathcal E)\geq0$,
  proved in both directions, with the hard direction's reshaping
  argument reconstructing explicit Kraus operators from $J$'s
  eigendecomposition.
- $\mathcal E$ is trace-preserving if and only if
  $\text{Tr}_{\text{out}}(J(\mathcal E))=I$.
- Reconstructing amplitude damping's own $K_0,K_1$ from nothing but its
  Choi matrix's eigenvectors, verified to reproduce
  Trace Distance and Fidelity's exact numerical output, is this lesson's
  concrete proof that the theorem isn't just symbolic bookkeeping.
