export const gamma = 0.3;
export const lambda = 0.3;

export const plus = applySingleQubitGate(StateVector.zero(1), HADAMARD, 0);
export const rho0 = pureStateDensityMatrix(plus);

export const rhoAD = applyKrausChannel(rho0, amplitudeDampingChannel(gamma));
export const rhoDP = applyKrausChannel(rho0, dephasingChannel(lambda));

export const traceDistance2x2 = (rhoMat, sigmaMat) => {
  const diff = rhoMat.add(sigmaMat.scale(-1));
  const [mu1, mu2] = eigenvaluesHermitian2x2(diff);
  return 0.5 * (Math.abs(mu1) + Math.abs(mu2));
}

export const fidelityPureVsMixed = (state, sigmaMat) => {
  const amps = state.amplitudes;
  const value = amps.reduce(
    (sum, ai, i) => sum.add(amps.reduce((rowSum, aj, j) => rowSum.add(ai.conjugate().mul(sigmaMat.get(i, j)).mul(aj)), Complex.ZERO)),
    Complex.ZERO
  );
  return Math.sqrt(value.re);
}

## Motivation

Ask "how close are two quantum states?" and it sounds like a single
question, but this platform's engine has quietly needed two different
answers to it all along. <Term id="trace-distance-fidelity">Trace distance and fidelity are those two</Term>
answers: standard, non-equivalent, each carrying its own operational
meaning. A precise pair of inequalities pins down exactly how they
relate, a provable quantitative sandwich, well beyond the loose
observation that both vanish together. Run them on channels
already sitting in this codebase, and "amplitude damping disturbs a
state" stops being a qualitative claim and becomes an exact, computed
number.

This is also, unglamorously, the actual vocabulary of a hardware
datasheet. When a lab reports a two-qubit gate at "99.5% fidelity," that
number comes from randomized benchmarking: running long random Clifford
sequences and fitting how a survival probability decays, which is an
estimate of an average gate fidelity, a close relative of the $F$
defined below. Google's 2019 "quantum supremacy" claim rested on
cross-entropy benchmarking, which compares a chip's actual output
distribution against the ideal circuit's predicted one. Neither of those
results means anything without the two objects this lesson derives from
first principles.

## Mathematical Development

### Trace distance: definition and variational form

<EquationReveal
  terms={[
    { id: "D", symbol: "D(ρ,σ)", gloss: "Trace distance — half the trace norm of the difference between two states." },
    { id: "mu", symbol: "μ_i", gloss: "Eigenvalues of the Hermitian, traceless operator Δ ≡ ρ − σ." },
  ]}
>

$$
D(\rho,\sigma) \equiv \frac12\text{Tr}|\rho-\sigma| = \frac12\sum_i|\mu_i|
$$

</EquationReveal>

where $\mu_i$ are the eigenvalues of the Hermitian, traceless operator
$\Delta\equiv\rho-\sigma$ (traceless since $\text{Tr}\rho=\text{Tr}\sigma=1$).
Because $\Delta$ is Hermitian it has a spectral decomposition into a
positive part $\Delta_+$ (projecting onto its non-negative eigenspace)
and negative part $-\Delta_-$, with $\Delta=\Delta_+-\Delta_-$ and
$|\Delta|=\Delta_++\Delta_-$. Tracelessness forces
$\text{Tr}\,\Delta_+=\text{Tr}\,\Delta_-$, so
$D(\rho,\sigma)=\text{Tr}\,\Delta_+$.

**Claim (Helstrom's variational formula).**
$D(\rho,\sigma)=\max_{0\leq P\leq I}\text{Tr}\big[P(\rho-\sigma)\big]$,
the maximum taken over all measurement operators $P$ (Hermitian,
eigenvalues in $[0,1]$).

**Proof.** For any such $P$, decompose using the projector $\Pi_+$ onto
$\Delta$'s non-negative eigenspace.

<DerivationSteps>
  <DerivationStep annotation="The first inequality drops a non-negative term Tr[PΔ₋] ≥ 0, since P, Δ₋ ≥ 0; the second uses P ≤ I applied to the positive operator Δ₊.">
    $\text{Tr}[P\Delta]=\text{Tr}[P\Delta_+]-\text{Tr}[P\Delta_-]\leq\text{Tr}[P\Delta_+]\leq\text{Tr}[\Delta_+]$
  </DerivationStep>
  <DerivationStep annotation="Δ₋ lives entirely in Δ's negative eigenspace, orthogonal to Π₊'s range, so Tr[PΔ₋]=0 there; and Δ₊ already lives entirely inside Π₊'s range, so Tr[Π₊Δ₊]=Tr[Δ₊].">
    Equality is achieved exactly at $P=\Pi_+$.
  </DerivationStep>
  <DerivationStep annotation="Combining the bound and the equality case identifies the maximum exactly.">
    So the maximum is exactly $\text{Tr}[\Delta_+]=D(\rho,\sigma)$. $\blacksquare$
  </DerivationStep>
</DerivationSteps>

That result hands trace distance an operational meaning it wouldn't have
as a bare matrix norm: it is exactly twice the largest bias any single
measurement can achieve when distinguishing $\rho$ from $\sigma$ (the
**Holevo–Helstrom bound**).

### The qubit closed form, and what it is geometrically

For a single qubit, $\Delta=\rho-\sigma$ is a Hermitian $2\times2$
matrix, so $D(\rho,\sigma)=\frac12(|\mu_1|+|\mu_2|)$ is computed directly
by this platform's own `eigenvaluesHermitian2x2` applied to $\Delta$: no
new numerical machinery beyond what "Pure States and Mixed States"
already built.

In one qubit the answer also has a shape. Writing
$\rho=\tfrac12(I+\vec r_\rho\cdot\vec\sigma)$ and likewise for $\sigma$,
the difference is $\Delta=\tfrac12(\vec r_\rho-\vec r_\sigma)\cdot\vec\sigma$,
a traceless Hermitian matrix whose eigenvalues are
$\pm\tfrac12|\vec r_\rho-\vec r_\sigma|$. Summing their magnitudes and
halving:

$$
D(\rho,\sigma) = \tfrac12\big|\vec r_\rho - \vec r_\sigma\big|
$$

**Trace distance on a qubit is half the ordinary Euclidean distance
between two points of the Bloch ball.** The abstract trace norm, the
Helstrom measurement bias, and a ruler laid across the ball are three
descriptions of one number.

This is a qubit fact, not a general one. For $d\geq3$ the state space is
not a ball, its geometry is not Euclidean, and no comparable shortcut
survives; the trace norm is then irreducibly a spectral computation. Enjoy
the picture, but do not carry it up in dimension.

### Uhlmann fidelity

<EquationReveal
  terms={[
    { id: "F", symbol: "F(ρ,σ)", gloss: "Uhlmann fidelity — how much two states overlap, in general (possibly mixed) form." },
    { id: "sqrtrho", symbol: "√ρ", gloss: "The matrix square root of ρ." },
  ]}
>

$$
F(\rho,\sigma) \equiv \text{Tr}\sqrt{\sqrt\rho\,\sigma\,\sqrt\rho}
$$

</EquationReveal>

This looks opaque in general, but reduces immediately when $\rho=|\psi\rangle\langle\psi|$
is pure: $\sqrt\rho=\rho$ (a rank-1 projector is its own square root), so
$\sqrt\rho\,\sigma\,\sqrt\rho=|\psi\rangle\langle\psi|\sigma|\psi\rangle\langle\psi|=\big(\langle\psi|\sigma|\psi\rangle\big)|\psi\rangle\langle\psi|$,
a positive multiple of a rank-1 projector, whose square root is
$\sqrt{\langle\psi|\sigma|\psi\rangle}\,|\psi\rangle\langle\psi|$. Taking
the trace:

$$
\boxed{F(|\psi\rangle,\sigma) = \sqrt{\langle\psi|\sigma|\psi\rangle}}
$$

a fully derived shortcut (not cited), and the quantity this
lesson's own worked example below computes directly from the engine. As
a sanity check on the general definition: if $\sigma=|\phi\rangle\langle\phi|$
is also pure, this further reduces to $F=|\langle\psi|\phi\rangle|$, the
ordinary state-overlap fidelity used informally throughout this
platform's earlier courses.

**Uhlmann's theorem**, stated here rather than re-derived, since a full
proof means optimizing over the space of every possible purifying system
in general dimension, machinery well beyond what this lesson builds
elsewhere, says $F(\rho,\sigma)=\max_{|\psi\rangle,|\phi\rangle}|\langle\psi|\phi\rangle|$,
the maximum taken over every purification $|\psi\rangle_{AB}$ of $\rho$
and every purification $|\phi\rangle_{AB}$ of $\sigma$ on a common
extension $B$. Schmidt Decomposition and Purification proved the
freedom this maximization ranges over: every purification of a fixed
$\rho$ differs from any other only by a unitary on $B$, so Uhlmann's
theorem is precisely "maximize the overlap over that unitary freedom."
This lesson uses Uhlmann's theorem only as a stated tool (for the proof
below); the pure-state shortcut boxed above is the form actually used in
every numerical computation that follows.

### The Fuchs–van de Graaf inequalities

**Claim.** $1-F(\rho,\sigma) \leq D(\rho,\sigma) \leq \sqrt{1-F(\rho,\sigma)^2}$.

**Upper bound, full proof.** First, a pure-state identity: for
normalized $|\psi\rangle,|\phi\rangle$,
$D(|\psi\rangle,|\phi\rangle)=\sqrt{1-|\langle\psi|\phi\rangle|^2}$. Proof:
$\text{Tr}\big[(|\psi\rangle\langle\psi|-|\phi\rangle\langle\phi|)^2\big]=\text{Tr}|\psi\rangle\langle\psi|+\text{Tr}|\phi\rangle\langle\phi|-2\text{Tr}(|\psi\rangle\langle\psi|\phi\rangle\langle\phi|)=2-2|\langle\psi|\phi\rangle|^2$
(using $\text{Tr}(AB)=\text{Tr}(BA)$ and $\langle\psi|\psi\rangle=1$). The
difference of two rank-1 projectors has eigenvalues $\{\mu,-\mu,0,0,\ldots\}$
(traceless, rank $\leq2$), so $\text{Tr}[(\cdot)^2]=2\mu^2$, giving
$\mu=\sqrt{1-|\langle\psi|\phi\rangle|^2}$ and
$D=\frac12(\mu+\mu)=\mu$. Second, **contractivity**: for any
completely-positive trace-preserving map $\Lambda$ (partial trace is one
such map), $D(\Lambda(\rho),\Lambda(\sigma))\leq D(\rho,\sigma)$. Proof:
for any measurement operator $P$ on $\Lambda$'s output, its Heisenberg
dual $Q\equiv\Lambda^\dagger(P)$ satisfies $0\leq Q\leq I$ (complete
positivity of $\Lambda$ makes $\Lambda^\dagger$ positive and
order-preserving; trace-preservation of $\Lambda$ makes $\Lambda^\dagger(I)=I$,
so $0\leq P\leq I$ maps to $0\leq Q\leq I$). Then
$\text{Tr}[P\,\Lambda(\rho-\sigma)]=\text{Tr}[Q(\rho-\sigma)]\leq D(\rho,\sigma)$
by Helstrom's formula; maximizing the left side over $P$ gives
$D(\Lambda(\rho),\Lambda(\sigma))\leq D(\rho,\sigma)$. Now take Uhlmann-optimal
purifications $|\psi\rangle_{AB},|\phi\rangle_{AB}$ with
$|\langle\psi|\phi\rangle|=F(\rho,\sigma)$, and apply contractivity to
$\Lambda=\text{Tr}_B$:

$$
D(\rho,\sigma) = D\big(\text{Tr}_B|\psi\rangle\langle\psi|,\,\text{Tr}_B|\phi\rangle\langle\phi|\big) \leq D(|\psi\rangle,|\phi\rangle) = \sqrt{1-F(\rho,\sigma)^2} \qquad\blacksquare
$$

**Lower bound: classical case proved in full; quantum case cites one
lemma.** First, the fully elementary *classical* version: for
probability distributions $p,q$, define
$D_{cl}(p,q)=\frac12\sum_i|p_i-q_i|$ and $F_{cl}(p,q)=\sum_i\sqrt{p_iq_i}$.
Since $\sqrt{p_iq_i}\geq\min(p_i,q_i)$ always (as
$p_iq_i=\max(p_i,q_i)\min(p_i,q_i)\geq\min(p_i,q_i)^2$), summing gives
$F_{cl}(p,q)\geq\sum_i\min(p_i,q_i)$. And
$\sum_i\min(p_i,q_i)=1-D_{cl}(p,q)$ (from
$\sum_i\max+\sum_i\min=\sum_i(p_i+q_i)=2$ and
$\sum_i\max-\sum_i\min=\sum_i|p_i-q_i|=2D_{cl}$, solved together). So
$F_{cl}(p,q)\geq1-D_{cl}(p,q)$, i.e. $1-F_{cl}(p,q)\leq D_{cl}(p,q)$,
proved outright with no unproved steps. To lift this to the quantum
case: measure both $\rho$ and $\sigma$ with the *same* optimal
projective measurement $\{\Pi_+,I-\Pi_+\}$ from Helstrom's formula above,
giving classical distributions $p=(\text{Tr}\,\Pi_+\rho,\,\text{Tr}(I-\Pi_+)\rho)$,
$q=(\text{Tr}\,\Pi_+\sigma,\,\text{Tr}(I-\Pi_+)\sigma)$ with
$D_{cl}(p,q)=D(\rho,\sigma)$ exactly, by construction. The one remaining
step, that quantum fidelity never falls below the classical fidelity
induced by *any* shared measurement, $F(\rho,\sigma)\geq F_{cl}(p,q)$,
is a theorem (provable via Uhlmann's theorem plus a
Cauchy–Schwarz argument on the measurement's Kraus operators) that is
**cited here, not re-derived**: proving it would require developing POVM
formalism this platform's engine doesn't otherwise use. Granting it:
$1-F(\rho,\sigma)\leq1-F_{cl}(p,q)\leq D_{cl}(p,q)=D(\rho,\sigma)$.
$\blacksquare$

## Physical Interpretation

<InsightBlock>
  Fuchs–van de Graaf is a sandwich, not an identity, and the width of the
  sandwich is the point. Two states can be equally hard to tell apart in
  one shot and differ substantially in how well a reference system stayed
  entangled with them.
</InsightBlock>

Trace distance answers "how well can a single measurement tell these two
states apart?", and Helstrom's formula makes that literal rather than
metaphorical. Fidelity answers something else: "how much do these two
states overlap?", or, through Uhlmann's theorem, "how well could a
purifying reference system have stayed entangled with both?" Both vanish
together and both saturate together, which is why they are often used
interchangeably; in between they are only loosely tied, which is what the
inequalities quantify.

The worked example makes the gap concrete. Amplitude damping at
$\gamma={gamma}$ sits at $D={D_AD.toFixed(4)}$ with the bounds
{(1 - F_AD).toFixed(4)} and {Math.sqrt(1 - F_AD ** 2).toFixed(4)} on
either side, so knowing $F$ alone pins $D$ only to within a factor of
about {(Math.sqrt(1 - F_AD ** 2) / (1 - F_AD)).toFixed(1)}. A datasheet
that reports one number has reported less than it appears to.

## Common Mistakes

<Callout type="warning">
**Using $F(\rho,\sigma)=\sqrt{\langle\psi|\sigma|\psi\rangle}$ when
*neither* state is pure.** The boxed shortcut requires $\rho$ (or by
symmetry $\sigma$) to be pure; for two mixed states, the full
definition $\text{Tr}\sqrt{\sqrt\rho\,\sigma\,\sqrt\rho}$ is needed, which
this platform's engine cannot evaluate for a general mixed qubit pair
(it would require a matrix square root the platform doesn't implement).
</Callout>

<Callout type="warning">
**Treating Fuchs–van de Graaf as an equality.** It's a two-sided bound,
not an identity: the worked example's own numbers ($D\approx0.1708$
strictly between $0.0417$ and $0.2857$ for amplitude damping) show real
daylight on both sides for a generic channel; equality on the upper
bound is only exact when both states are pure (proved above), and on the
lower bound only in special cases.
</Callout>

## Summary

- Trace distance $D(\rho,\sigma)=\max_{0\leq P\leq I}\text{Tr}[P(\rho-\sigma)]$
  (Helstrom's formula, proved from the spectral decomposition of
  $\rho-\sigma$) is exactly twice the best possible measurement bias for
  telling $\rho$ from $\sigma$ apart.
- Fidelity $F(\rho,\sigma)=\text{Tr}\sqrt{\sqrt\rho\,\sigma\,\sqrt\rho}$
  reduces to $\sqrt{\langle\psi|\sigma|\psi\rangle}$ when $\rho$ is pure
  (derived, not cited) and is characterized in general by Uhlmann's
  theorem as the maximum overlap between purifications.
- $1-F\leq D\leq\sqrt{1-F^2}$ (Fuchs–van de Graaf): the upper bound is
  proved in full via purification and contractivity; the lower bound's
  classical version is proved in full, with only one measurement-monotonicity
  lemma cited to lift it to the quantum case.
- Applied to this platform's real channels: amplitude damping at
  $\gamma=0.3$ gives $D\approx0.1708$, $F\approx0.9583$; dephasing at
  $\lambda=0.3$ gives $D\approx0.1500$, $F\approx0.9220$; both satisfy
  the derived inequalities, checked numerically and across the
  full range of $\gamma$.
