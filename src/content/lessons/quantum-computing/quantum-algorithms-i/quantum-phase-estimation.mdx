<LessonHook eyebrow="Reading a phase off a qubit register">
A single real number can encode everything a unitary does to one of its eigenstates. Quantum phase estimation reads that number out, bit by bit, using nothing but controlled-U applications and the inverse QFT.
</LessonHook>

## One real number, and how to read it

Every <Term id="eigenvalue-eigenvector">eigenstate</Term> of a unitary $U$ satisfies $U|\psi\rangle=e^{2\pi i\varphi}|\psi\rangle$
for some phase $\varphi\in[0,1)$, a single real number encoding everything
$U$ does to that eigenstate. **<Term id="quantum-phase-estimation">Quantum phase estimation (QPE)</Term>** reads
$\varphi$ out into an ordinary qubit register, as a binary fraction, using
nothing but controlled-$U$ applications and the inverse QFT.

This is the most reused subroutine in the subject. Shor's algorithm is
phase estimation applied to a modular-multiplication unitary; quantum
chemistry's energy estimates are phase estimation applied to a
time-evolution unitary. Learning it once buys both.

## Deriving the pre-measurement state exactly

### The circuit, register by register

Use two registers: $t$ "precision" qubits, initialized to
$|0\rangle^{\otimes t}$, and an "eigenstate" register holding
$|\psi\rangle$ (a $U$-eigenstate). Apply $H$ to every precision qubit.
Apply $U^{2^{t-1-q}}$ to the eigenstate register, controlled by precision
qubit $q$, for each $q=0,\dots,t-1$ (qubit 0 controls the *largest* power,
matching this platform's qubit-0-is-MSB convention). Apply the inverse QFT
to the precision register. Measure it.

### Deriving the pre-measurement state

After the Hadamards, the precision register is
$\frac{1}{\sqrt{2^t}}\sum_{x=0}^{2^t-1}|x\rangle$, with $x$'s bits the
precision qubits. Each controlled-$U^{2^{t-1-q}}$, conditioned on
precision qubit $q$ being $1$, multiplies the eigenstate by
$e^{2\pi i\varphi\cdot2^{t-1-q}}$ (since $|\psi\rangle$ is a $U$-eigenstate,
applying $U^{2^{t-1-q}}$ just raises the eigenvalue to that power). Summing
the contributions from every qubit whose bit is set in $x$ reproduces
exactly $e^{2\pi i\varphi x}$, because $x=\sum_q b_q2^{t-1-q}$ (the
ordinary binary expansion, MSB-first, matching this platform's own
`StateVector.basis` indexing) is the sum of the individual bit
contributions. So after all controlled-$U$ applications:

$$
\frac{1}{\sqrt{2^t}}\sum_x e^{2\pi i\varphi x}|x\rangle\ \otimes\ |\psi\rangle
$$

Compare this to the QFT's own defining formula,
$\text{QFT}|j\rangle=\frac{1}{\sqrt N}\sum_ke^{2\pi ijk/N}|k\rangle$: the
precision register's state is **exactly $\text{QFT}|\varphi N\rangle$**
whenever $\varphi N$ is an integer ($N=2^t$), matching term for term with
$j=\varphi N$. Applying the inverse QFT therefore recovers
$|\varphi N\rangle$ **exactly**, as a computational basis state, whenever
$\varphi$ is exactly representable with $t$ bits. Measuring the precision
register then gives $\varphi N$ with certainty, and dividing by $N=2^t$
recovers $\varphi$.

### Scope: single-qubit unitaries only

`phaseEstimation` implements this for a $2\times2$ unitary $U$ specifically:
controlled-$U^{2^k}$ needs `applyControlledGate`, which this platform's
engine only supports for a genuine $2\times2$ gate, one control, one
target. A general multi-qubit $U$ would need a controlled-*multi-qubit*-gate
primitive this platform doesn't build (see the engine's "deliberately not
built" scope notes); every worked example in this course therefore uses a
single-qubit unitary with a known eigenstate: a phase gate or a Pauli
rotation, never an arbitrary black-box $U$.

## The QFT, run backwards

Phase estimation is the QFT run in reverse on a phase already written onto
a register by repeated controlled-$U$ applications. It is the same
<Term id="phase-interference">interference</Term> machinery Deutsch-Jozsa used to read out one global bit,
generalized to read out a real number to $t$-bit precision.

Every period-finding algorithm, Shor's included, is built from this
component. The [period-finding explorer](/simulators#period-finding-explorer)
runs that end-to-end circuit live if you want to see where this piece ends
up before the next course derives it.

## Three bits of precision on three-eighths

**Estimate the phase of $U=\text{phaseGate}(2\pi\cdot\frac38)$, eigenstate
$|1\rangle$, using $t=3$ precision qubits.**

$\text{phaseGate}(\theta)=\text{diag}(1,e^{i\theta})$ has two eigenstates.
$|0\rangle$ carries eigenvalue $1$, so it would report $\varphi=0$ and
tell you nothing; $|1\rangle$ carries $e^{i\theta}$, which is the one that
carries the phase being estimated. That is why the run below prepares
$|1\rangle$.

$\varphi=3/8$ is exactly representable in 3 bits ($3/8 = 0.011_2$), so
$\varphi\cdot2^3=3$ exactly. The derivation above guarantees the precision
register measures $|011\rangle=|3\rangle$ with certainty. Directly from the
engine: `phaseEstimation` with this $U$, eigenstate, and $t=3$ gives
probability $1.0$ (to 6 decimal places) on the combined index
corresponding to precision register $=3$, eigenstate qubit $=1$. That is
the derived value, to the last decimal place the engine reports.

<Callout type="warning">
**Expecting an exact answer for a phase not representable in $t$ bits.**
The derivation above assumed $\varphi N$ is an integer; for other phases,
the precision register's state is a superposition peaked near the nearest
representable value. What you get back is still useful, but it arrives as
a probability distribution and has to be read as one.
</Callout>

<Callout type="warning">
**Confusing which qubit controls which power of $U$.** Precision qubit $0$
controls the *largest* power ($U^{2^{t-1}}$), not the smallest; swapping
this convention silently reads out the phase's bits in the wrong order.
</Callout>

## Practice Questions

1. Repeat the derivation's logic for $\varphi=1/4$ with $t=2$ precision
   qubits: which basis state should the precision register measure with
   certainty?

   <details className="answer-reveal">
   <summary>Answer</summary>

   $|01\rangle$, with probability exactly $1$.

   Write $\varphi$ in binary: $1/4 = 0.01_2$, and $t=2$ digits are exactly
   enough to hold it with nothing left over. The pre-measurement state is
   $\tfrac{1}{\sqrt{4}}\sum_x e^{2\pi i\varphi x}|x\rangle$ with
   $\varphi = 1/4$, which is the same phase ramp the forward $\text{QFT}$
   produces from the basis state $|j\rangle$ with $j = 2^t\varphi = 1$. The
   inverse $\text{QFT}$ undoes it exactly, returning $|j\rangle = |01\rangle$.
   The engine agrees: `phaseEstimation` with a phase gate of angle
   $2\pi/4$ and $t=2$ puts probability $1.000000$ on $01$ and zero on the
   other three.

   The condition for certainty is worth naming, because it will not hold in
   general. It is that $2^t\varphi$ is an integer, so that $\varphi$ has an
   exact $t$-bit binary expansion. Here $2^2\times\tfrac14 = 1$. Give the
   same $\varphi$ three precision qubits instead and the answer becomes
   $|010\rangle$, since $2^3\times\tfrac14 = 2$: the same phase, read to one
   more digit, still exactly. The engine confirms $010$ at probability
   $1.000000$ for $t=3$.

   The wrong turn is expecting the register to hold $\varphi$ as a plain
   integer, or to read $|01\rangle$ as "the number one". It holds the
   *numerator*: the measured $t$-bit string $x$ encodes the estimate
   $\varphi \approx x/2^t$, so $01$ at $t=2$ means $1/4$ and $010$ at
   $t=3$ means $2/8$, the same value. Forgetting to divide by $2^t$ is the
   standard way to misread the output by a factor of eight.

   </details>

2. Explain why $U^{2^{t-1-q}}$, not $U^{q}$ or $U^{2^q}$, is the correct
   power for precision qubit $q$, using the binary expansion
   $x=\sum_qb_q2^{t-1-q}$.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The derivation needs the total accumulated phase to come out as
   $e^{2\pi i\varphi x}$, where $x$ is the integer whose bits are the
   precision qubits. Controlled-$U^{m}$ on qubit $q$ contributes
   $e^{2\pi i\varphi m}$ on the branch where $b_q=1$ and nothing otherwise,
   so the total over all qubits is $e^{2\pi i\varphi\sum_q b_q m_q}$. For
   that to equal $e^{2\pi i\varphi x}$ for every $x$, the powers must
   satisfy $\sum_q b_q m_q = x$, and since $x=\sum_q b_q 2^{t-1-q}$ by
   definition of the binary expansion, the only choice is
   $m_q = 2^{t-1-q}$.

   In other words, the exponent is the qubit's *place value*. On this
   platform qubit $0$ is the most significant bit, so it carries place
   value $2^{t-1}$ and controls the largest power; qubit $t-1$ is the
   least significant, place value $2^0$, and controls a single $U$. With
   $t=4$ the powers are $U^8, U^4, U^2, U$ on qubits $0,1,2,3$.

   The two rejected alternatives fail concretely. $U^q$ gives powers
   $0,1,2,3$, which are not place values at all, so qubit $0$ would
   contribute nothing and the accumulated phase would encode
   $\sum_q b_q q$, a quantity many different $x$ share. $U^{2^q}$ gives
   $1,2,4,8$, the right set of powers attached to the wrong qubits, which
   reverses the register's bit order: the answer would come out
   bit-reversed, and the inverse $\text{QFT}$, which expects MSB-first,
   would return the wrong string.

   The wrong turn is treating the exponent convention as arbitrary because
   "you could just relabel the qubits". You could, and then the inverse
   $\text{QFT}$ and its swap layer would have to be relabelled to match.
   The convention is not free once another component has already committed
   to one, and this platform's is that qubit $0$ is most significant
   everywhere.

   </details>

3. What happens to `phaseEstimation`'s precision register if $\varphi=1/3$
   (not exactly representable in any finite number of bits) and $t=3$? You
   don't need to compute exact probabilities; describe qualitatively what
   the derivation predicts.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The certainty disappears and is replaced by a peaked distribution: most
   of the probability lands on the one or two $t$-bit strings nearest
   $2^t\varphi$, with a small tail spread over everything else.

   $\tfrac13 = 0.010101\ldots_2$, and $2^3\times\tfrac13 = 2.667$, which is
   not an integer, so no basis state matches the phase ramp exactly and the
   inverse $\text{QFT}$ has nothing to concentrate perfectly onto. Instead
   the amplitude splits between the two bracketing values, $x=3$ (the
   estimate $3/8 = 0.375$) and $x=2$ ($2/8 = 0.25$), with the nearer one
   favoured. The engine returns $0.6878$ on $011$ and $0.1749$ on $010$,
   which is $86\%$ of the probability on the two nearest bins, and the
   remaining $14\%$ scattered across the other six, none above $0.05$.

   The shape is the standard one and it is worth recognizing. The
   distribution is $\left|\sum_k e^{2\pi ik\delta}\right|^2/2^{2t}$ with
   $\delta$ the mismatch between $\varphi$ and $x/2^t$, which is a Dirichlet
   kernel: a sharp central peak with rapidly decaying side lobes. The
   general theorem says the best $t$-bit estimate is returned with
   probability at least $4/\pi^2 \approx 0.405$, and $0.688$ here is
   comfortably above that floor.

   The practical reading: phase estimation degrades gracefully rather than
   failing. Adding precision qubits both narrows the bin width and
   sharpens the peak, so an unrepresentable $\varphi$ costs you a bounded
   probability of an off-by-one reading rather than a wrong answer, and
   repeating the circuit a few times and taking the mode fixes it.

   The wrong turn is expecting a uniform mess, on the reasoning that an
   irrational-looking phase has no good $t$-bit representative. Every
   $\varphi$ has a nearest $t$-bit representative, and the interference is
   still overwhelmingly constructive there. The engine's largest stray
   bin, $0.047$ on $100$, is the size of the failure.

   </details>

4. Why does this platform's `phaseEstimation` require the caller to already
   know a genuine eigenstate of $U$, rather than accepting an arbitrary
   input state? Then say what happens physically if you feed it a
   superposition of two eigenstates, and why that behaviour is how Shor's
   algorithm actually uses this subroutine.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because the derivation's very first move is
   $U^{m}|\psi\rangle = e^{2\pi i\varphi m}|\psi\rangle$, which pulls the
   eigenvalue out as a number and leaves the eigenstate register untouched.
   That is what lets the phase land on the precision register instead of
   changing the target, and it is the same eigenstate condition phase
   kickback needed. For a non-eigenstate, $U^m|\psi\rangle$ is a different
   state, not a multiple of $|\psi\rangle$, so there is no single $\varphi$
   to estimate and no factorization to exploit.

   Feed it a superposition $|\psi\rangle = \sum_j c_j|u_j\rangle$ of
   eigenstates with eigenvalues $e^{2\pi i\varphi_j}$ and linearity does
   something useful rather than something broken. Each branch runs its own
   phase estimation, and the output is the entangled state
   $\sum_j c_j\,|\widetilde{\varphi_j}\rangle|u_j\rangle$: the precision
   register holds the estimate of $\varphi_j$ correlated with the
   eigenstate it came from. Measuring the precision register then returns
   one $\varphi_j$, chosen at random with probability $|c_j|^2$, and
   collapses the target onto the matching $|u_j\rangle$.

   That is Shor's arrangement, and it is why the subroutine is
   usable at all there. Nobody can prepare an eigenstate of modular
   multiplication by $a$ without already knowing the period, which is the
   thing being computed. What Shor does instead is feed in $|1\rangle$,
   which happens to be an equal superposition of all $r$ relevant
   eigenstates, and accept a randomly chosen $\varphi_j = s/r$ as the
   output. One random multiple of $1/r$, run through continued fractions,
   recovers $r$. The apparent limitation is the mechanism.

   The wrong turn is reading the type signature as a claim that
   non-eigenstate inputs are forbidden by physics. They are not; the
   circuit runs fine and produces the entangled state above. What the
   signature enforces is that the *interpretation* of the output as a
   single number is only valid for an eigenstate input, which is the same
   kind of honest boundary as `concurrenceOfPureState` refusing a density
   matrix.

   </details>

## Summary

- QPE's pre-measurement precision-register state is exactly
  $\text{QFT}|\varphi N\rangle$, derived from tracking each controlled-$U$
  application's phase contribution, not asserted.
- The inverse QFT recovers $\varphi N$ exactly whenever $\varphi$ is
  exactly representable with $t$ precision bits.
- This platform's implementation is restricted to single-qubit unitaries
  with a known eigenstate, a deliberate, documented scope limit, not an
  oversight.
- Verified directly: a $3/8$-phase gate with 3 precision qubits gives
  probability $1.0$ on the correct outcome.
