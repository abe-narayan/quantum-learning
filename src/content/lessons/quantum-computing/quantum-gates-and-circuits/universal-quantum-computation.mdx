## A promise made in passing, nine lessons ago

Building Qubit Circuits computed $HZH=X$ and then said, in passing, that
composing rotations about different axes "makes it possible to build *any*
gate from a small, fixed set of 'universal' ones," promising the idea
would return in the next course. It never did. This course went on to build
CNOT, Bell states, teleportation, BB84, and superdense coding without
pinning down what "universal" means or why any small set deserves the name.
This lesson keeps that promise.

Three questions have to be separated to answer it. Is there a set that
reaches everything? Can it be finite, given that the unitaries form a
continuum? And if it can, which finite set, and why does the standard
answer include a gate as odd-looking as $T$ rather than stopping at the
gates you would naturally reach for?

## Dials that spin in total isolation

Picture each qubit as a dial that a single-qubit gate can spin, but
only that one dial, in total isolation from every other qubit's dial.
No matter how many single-qubit gates run, in whatever order, on
however many qubits, each dial only ever responds to gates applied to
*it*: nothing a single-qubit gate does to qubit 0 can depend on, or
influence, what's happening to qubit 1. Producing genuine correlation
between qubits, the kind CNOT produces, needs a gate that reads one
qubit and acts on another. That's the qualitative reason single-qubit
gates alone can never suffice; the next section proves it exactly.

## Why one entangling gate is mathematically required

### Single-qubit gates alone are not enough

Suppose a circuit acts only with single-qubit gates, never anything
that couples two qubits. On two qubits, such a circuit's total action
is $U\otimes V$ for some single-qubit unitaries $U,V$, possibly the
identity where a qubit is untouched at a given step. Composing several
single-qubit-only layers just composes each qubit's gates locally, so
the total action stays a tensor product of single-qubit unitaries no
matter how many layers the circuit has.

Apply this to any product state $|a\rangle\otimes|b\rangle$:

$$
(U\otimes V)(|a\rangle\otimes|b\rangle) = (U|a\rangle)\otimes(V|b\rangle)
$$

still manifestly a product state, since $U|a\rangle$ and $V|b\rangle$
are each single-qubit states. **A circuit built only from single-qubit
gates maps every product state to a product state, with no exception.**

But CNOT does not have this property: The No-Cloning Theorem already
built $\text{CNOT}(|+\rangle\otimes|0\rangle) =
\frac{1}{\sqrt2}(|00\rangle+|11\rangle)$, an entangled Bell state, from
a product input. No tensor product $U\otimes V$ can equal CNOT, because
$U\otimes V$ can never send a product state to an entangled one and
CNOT demonstrably does. **Single-qubit gates alone, however many of
them, in whatever sequence, can never reach every two-qubit unitary.**
Entangling gates are not an optional convenience; they are
mathematically required for full generality.

### The universality theorem

This platform's single-qubit rotations already reach every point on
the Bloch sphere: Single-Qubit Rotations built $R_n(\theta)$ for
arbitrary axis $n$ and angle $\theta$, and any single-qubit unitary
(up to global phase) is some such rotation. So single-qubit gates alone
already cover all of $U(2)$; what's missing, by the argument above, is
entanglement.

The **universality theorem** (Barenco et al. 1995; stated here as a
known result this lesson doesn't re-derive from scratch, the same
honest scoping Gate Decomposition used for the general Euler
decomposition) says that's *exactly* what's missing:

> Arbitrary single-qubit unitaries, together with CNOT alone, can
> implement any unitary operation on any number of qubits.

<ResearchConnection title="Elementary gates for quantum computation" source="Barenco et al., Physical Review A 52, 3457 (1995)" url="https://arxiv.org/abs/quant-ph/9503016">
The result this lesson leans on: arbitrary single-qubit unitaries plus CNOT alone can implement any unitary operation on any number of qubits. It is the theorem that turns "H, X, Y, Z, S, T, CNOT" from an arbitrary list into a provably complete toolkit.
</ResearchConnection>

The plausibility argument, without the full constructive proof: every
unitary $U(2^n)$ is generated, as a Lie group, by a Lie algebra of
Hermitian generators. Single-qubit gates on each of the $n$ qubits
supply every local generator (acting on one qubit at a time); CNOT
alone supplies enough true two-qubit generators, via commutators of
local generators with the fixed CNOT structure, to eventually reach
every direction in the full $2^n\times2^n$ generator space, not just
the "diagonal" local ones. Reaching every generator direction means
reaching every unitary connected to the identity, arbitrarily closely,
by composing finitely many gates from the set. Since $U(2^n)$ is
connected, that's all of it.

<Callout type="note">
"Reaches every unitary" here means *exactly*, for a specific finite
circuit, for a fixed $n$: the full constructive proof decomposes any
$U\in U(2^n)$ into a product of two-level unitaries (each touching only
a 2-dimensional subspace), then builds each two-level piece from
single-qubit gates and CNOTs using ancilla-free multiplexing. That
construction is real and exact, just long enough (and standard enough)
that this lesson cites it rather than re-deriving all of it, exactly
the choice Gate Decomposition already made for the single-qubit Euler
decomposition.
</Callout>

### Why a discrete set, not a continuous one

The universality theorem above uses *arbitrary* single-qubit gates,
a continuous, 3-parameter family for every gate in the circuit. That's
mathematically clean but physically awkward for two reasons this
platform has already built the pieces to see:

1. **Calibration drift.** Calibration showed that a device's actual
   control parameters have to be re-measured and corrected for
   regularly; an "arbitrary real-valued rotation angle" is never
   implemented with infinite precision, only to whatever accuracy the
   day's calibration achieves.
2. **Fault tolerance needs discreteness.** Stabilizer Formalism Basics
   and the codes around it protect specific, discrete operations
   (Pauli errors, Clifford gates) using specific, discrete code
   structure. There's no way to "error-correct" an arbitrary
   continuous rotation angle the same way; fault-tolerant architectures
   are built around implementing a *fixed, finite* list of gates
   fault-tolerantly, not an infinite continuum of them.

So the practically relevant question isn't just "is there SOME
universal set" (yes, trivially, all single-qubit gates plus CNOT) but
"is there a small, FIXED, discrete set that's still universal, in the
weaker sense of approximating any unitary to any desired accuracy using
finitely many gates from that fixed list?"

### The Clifford group, and why it secretly isn't enough

Restrict to the discrete gates already built throughout Quantum Gates &
Circuits: $H$, $S$, and CNOT. The **<Term id="clifford-group">Clifford group</Term>** is exactly the set
of unitaries that map every Pauli operator to another Pauli operator
under conjugation, $UPU^\dagger \in \{\pm X,\pm Y,\pm Z,\pm iX,\dots\}$
for every Pauli $P$. Building Qubit Circuits already verified $HZH=X$,
exactly this Clifford property for $H$ (Z conjugates to a Pauli, X);
$S$ and CNOT have the same property (checkable the same way).

It's tempting to guess $\{H,S,\text{CNOT}\}$ is already universal,
since it's discrete, includes an entangling gate, and every gate in it
is used throughout this platform's algorithms. It is
**not**, and the reason is the **<Term id="gottesman-knill-theorem">Gottesman-Knill theorem</Term>** (cited here,
not re-derived: the full proof tracks a stabilizer tableau through the
circuit, exactly the bookkeeping Stabilizer Formalism Basics
introduced for error-correcting codes):

> Any circuit built entirely from Clifford gates (state preparation in
> the computational basis, Clifford gates, and Pauli measurements) can
> be simulated by a classical computer in time polynomial in the number
> of qubits.

That theorem is a fact about Clifford circuits, with nothing said yet
about universality. Put the two together yourself before reading on.

Compare this to Computational Cost & Scaling's $16\times2^n$-byte wall:
a *general* $n$-qubit circuit needs exponential classical resources to
simulate, which is why a quantum computer is believed to be
more powerful than a classical one for some problems. A circuit family
that's *always* classically efficient to simulate cannot be the source
of that advantage. Since Clifford circuits are always classically
efficient (Gottesman-Knill), **Clifford alone cannot be a universal gate
set**. Every Clifford circuit is classically simulable, and a universal set
has to reach circuits (Shor's, for one) that are believed not to be.

### T breaks Cliffordness, verified directly

The standard fix adds exactly one more gate, $T=\text{diag}(1,e^{i\pi/4})$
(Gate Decomposition already used $T=R_z(\pi/4)$, up to the global phase
that decomposition explicitly works modulo). Check directly
whether $T$ is Clifford, the same conjugation test used above for $H$:

$$
TXT^\dagger = \begin{pmatrix}1&0\\0&e^{i\pi/4}\end{pmatrix}\begin{pmatrix}0&1\\1&0\end{pmatrix}\begin{pmatrix}1&0\\0&e^{-i\pi/4}\end{pmatrix} = \begin{pmatrix}0&e^{-i\pi/4}\\e^{i\pi/4}&0\end{pmatrix}
$$

Writing $e^{\pm i\pi/4}=\frac{1\pm i}{\sqrt2}$ and comparing to
$X=\begin{pmatrix}0&1\\1&0\end{pmatrix}$ and
$Y=\begin{pmatrix}0&-i\\i&0\end{pmatrix}$:

$$
TXT^\dagger = \frac{1}{\sqrt2}\begin{pmatrix}0&1-i\\1+i&0\end{pmatrix} = \frac{1}{\sqrt2}(X+Y)
$$

computed on this page rather than quoted: `T_GATE.mul(PAULI_X).mul(T_GATE.dagger())`
and `PAULI_X.add(PAULI_Y).scale(Math.SQRT1_2)`, both built from this
platform's own gate matrices, differ by at most {tConjugationMaxDeviation.toExponential(1)}
in any entry. This is
**not** a Pauli operator, not even a phase times one: it's an equal
combination of $X$ and $Y$. So $T$ conjugates a Pauli into something
that isn't a Pauli, and **$T$ is not a Clifford gate.** Adjoining it to
$\{H,S,\text{CNOT}\}$ adds something Clifford circuits alone could
never produce.

<Callout type="note">
$T^2=S$ and $S^2=Z$, so $T$ already contains $S$ (and everything built
from $S$) as a special case; the standard universal set is usually
written $\{H,T,\text{CNOT}\}$, with $S$ left implicit as $T^2$.
</Callout>

### Clifford + T is universal, and Solovay-Kitaev makes it efficient

$\{H,T,\text{CNOT}\}$ (equivalently Clifford+T) is a standard, cited
universal set (Boykin et al. 2000): combined with the universality
theorem above, it's enough to reach every $n$-qubit unitary to
arbitrary accuracy. The single-qubit half of the claim is itself a
surprising fact, stated here without full proof: $H$ and $T$
generate a **dense** subgroup of $SU(2)$, meaning every point on the
Bloch sphere can be approximated arbitrarily closely by *some* finite
word in $H$ and $T$, even though $T$'s own rotation angle ($\pi/4$) is
a perfectly ordinary rational multiple of $\pi$ and would, by itself,
only ever reach 8 points. Density only emerges because $H$ and $T$
rotate about *different* axes; composing rotations about non-parallel
axes by a fixed angle repeatedly is known (a deep, number-theoretic
fact this lesson cites rather than derives) to sweep out a dense set
rather than a finite one.

Density is an existence statement. It does not say how many $H$'s and $T$'s
are needed to hit a given target to a given accuracy $\varepsilon$, and a
set that needed exponentially many would be useless. The
**<Term id="solovay-kitaev-theorem">Solovay-Kitaev theorem</Term>** (Kitaev 1997) settles it:

$$
\text{gate count} = O\!\left(\log^{c}(1/\varepsilon)\right), \quad c\approx 2\text{-}4
$$

Polylogarithmic in $1/\varepsilon$, not exponential. That efficiency
is what turns "Clifford+T can in principle reach anything" into a
practically usable compilation target, the discrete analogue of Gate
Decomposition's exact continuous $R_z,R_y$ decomposition. It's also,
cited here as a forward pointer and explicitly not derived in this
course, *why* $T$ gates specifically are the expensive resource in a
fault-tolerant quantum computer: Clifford gates (including $H$ and
CNOT) can be implemented fault-tolerantly comparatively cheaply,
transversally in codes like Steane's, and by lattice surgery and code
deformation on the surface code, while $T$ needs a separate, costly procedure called
<Term id="magic-state-distillation">magic-state distillation</Term>. The Fault-Tolerant Thresholds capstone's
physical-to-logical qubit overhead is, in real architectures, driven
substantially by this $T$-gate cost: a number this lesson names but,
matching that capstone's own scoping, does not derive.

## The NAND gate's quantum counterpart

This is the quantum analogue of a very old classical fact: NAND alone
is universal for classical Boolean logic, so any classical circuit,
however complex, reduces to NAND gates wired together. $\{H,T,\text{CNOT}\}$
plays the same role here: every circuit on this platform (Bell states,
Grover's algorithm, VQE ansatzes, the 3-qubit codes) is, underneath its
convenient named gates, reachable from a vocabulary of exactly three
gates. That is also why "a quantum programming language" can mean something
general-purpose rather than a fixed menu of special-case circuits: a
compiler targeting Clifford+T, or any other proven-universal set, is
targeting something provably able to express whatever circuit it is asked
for.

## Worked Example: Building Toffoli from Clifford+T

The **Toffoli gate** (CCNOT) flips a target qubit exactly when *both* of
two control qubits are $|1\rangle$. It is a standard reversible
classical AND-like gate, and it is **not** a Clifford
gate. The standard construction below (Nielsen & Chuang, Fig. 4.9)
builds it from nothing but $H$, CNOT, $T$, and $T^\dagger$, a concrete
instance of Clifford+T reaching a gate outside the Clifford group:

## Discrete and entangling is not yet universal

<Callout type="note">
**Thinking "Clifford+T is universal" means any random discrete gate set
is universal.** It isn't automatic. $\{H,S,\text{CNOT}\}$ alone (no
$T$) is discrete, includes an entangling gate, and is still NOT
universal, by Gottesman-Knill. What makes $T$ essential is specifically
that it maps a Pauli to a non-Pauli under conjugation, verified directly
above. Most "reasonable-looking" gates fail that test.
</Callout>

<Callout type="note">
**Confusing "universal in principle" with "cheap in practice."**
Clifford+T can reach any circuit to any accuracy, but that doesn't mean
every gate costs the same. $T$ gates are dramatically more expensive
than Clifford gates on real fault-tolerant hardware (magic-state
distillation, cited above, not derived), which is why minimizing
"$T$-count" (the Toffoli example above needs exactly 7) is its own
active area of circuit optimization, distinct from just minimizing gate
count.
</Callout>

## Practice Questions

1. Prove directly (the same style as this lesson's single-qubit-gates
   argument) that a circuit built only from CNOT gates, with no
   single-qubit gates at all, also can't be universal. (Hint: what does
   CNOT do to every computational basis state, and can that alone
   produce something like $H|0\rangle=|+\rangle$?)

   <details className="answer-reveal">
   <summary>Answer</summary>

   CNOT maps every computational basis state to a computational basis
   state: $|00\rangle\to|00\rangle$, $|01\rangle\to|01\rangle$,
   $|10\rangle\to|11\rangle$, $|11\rangle\to|10\rangle$. Its matrix is
   therefore a permutation matrix, every entry $0$ or $1$, with a single
   $1$ in each row and column. Products of permutation matrices are
   permutation matrices, so a circuit built only from CNOTs, on any number
   of qubits and of any depth, is one permutation matrix.

   **Such a circuit maps every basis state to a basis state, never to a
   superposition.** Applied to $|0\ldots0\rangle$, the output is some
   single basis state $|b\rangle$ with one amplitude equal to $1$. But
   $H|0\rangle = |+\rangle$ has two amplitudes equal to $\tfrac{1}{\sqrt2}$.
   No permutation matrix has an entry $\tfrac{1}{\sqrt2}$, since every
   entry is $0$ or $1$, so no CNOT-only circuit equals $H\otimes I$ or any
   circuit containing it. CNOT alone cannot reach every unitary.

   The counting version of the same point is even blunter. On $n$ qubits,
   CNOT acts on the bit string as $(a,b)\mapsto(a, a\oplus b)$, so
   CNOT-only circuits generate exactly the invertible linear maps over
   $\mathbb{F}_2$, a *finite* group. On two qubits there are $6$ of them,
   and the engine reproduces one, $\text{CNOT}(0,1)$ then
   $\text{CNOT}(1,0)$, as the permutation
   $00\to00$, $01\to11$, $10\to01$, $11\to10$. Six matrices cannot
   approximate a continuum, and the gap is not one you could close with a
   longer circuit; the group is closed, so length buys nothing.

   Note how this pairs with the lesson's other impossibility argument.
   Single-qubit gates alone preserve the product-state property and so
   cannot entangle; CNOT alone preserves the definite-basis-state property
   and so cannot superpose. Each is missing precisely what the other has,
   which is why the universality theorem asks for both. The wrong turn is
   thinking CNOT is disqualified because it is "classical" or has real
   entries. Realness is not the obstruction, and CNOT is a genuine
   entangling gate; what disqualifies it is that it never creates
   superposition, and without superposition there is nothing to entangle.

   </details>

2. Using $HZH=X$ (already verified in Building Qubit Circuits), is
   $H$ itself a Clifford gate by the definition given here? Check
   explicitly that $H$ conjugates $X$ to a Pauli as well (compute
   $HXH$).

   <details className="answer-reveal">
   <summary>Answer</summary>

   Yes, $H$ is Clifford. Note first that $H^\dagger = H$, so the
   conjugation $HPH^\dagger$ is just $HPH$.

   $$
   HXH = \frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}\begin{pmatrix}0&1\\1&0\end{pmatrix}\begin{pmatrix}1&1\\1&-1\end{pmatrix} = \begin{pmatrix}1&0\\0&-1\end{pmatrix} = Z
   $$

   The engine confirms this on the platform's own `HADAMARD` and
   `PAULI_X`. Together with the known $HZH = X$, that is the $X$ and $Z$
   generators handled, and the third case follows without new work:
   $Y = iXZ$, and conjugation respects products, so
   $HYH = i(HXH)(HZH) = iZX = -Y$, which the engine also confirms. A
   leading $-1$ is still a Pauli by the definition given here, which allows
   $\pm$ and $\pm i$ factors, so all three Paulis map to Paulis and $H$
   passes.

   The three results together say something geometric that is worth
   holding on to. $H$ swaps the $x$- and $z$-axes of the Bloch sphere and
   reverses $y$, which is exactly the half turn about the diagonal between
   $x$ and $z$ that the first course described. Clifford gates are
   precisely the gates that permute the Pauli axes rather than tilting
   them into intermediate directions, and it is that rigidity, a finite
   set of allowed permutations, that makes their action trackable with
   bookkeeping rather than with amplitudes. That bookkeeping is what
   Gottesman-Knill turns into an efficient classical simulation, and it is
   the same tableau the stabilizer codes later in this track are built on.

   The contrast with $T$ is now sharp. $TXT^\dagger = \tfrac{1}{\sqrt2}(X+Y)$
   is a tilt halfway between two axes, not a permutation of them, so the
   tableau has nothing to record and the whole method breaks. The slip to
   avoid is concluding from $HZH = X$ alone that $H$ is Clifford. The
   definition quantifies over *every* Pauli, so one case is a necessary
   check and not a sufficient one. Conveniently, checking $X$ and $Z$ is
   enough, since they generate the rest.

   </details>

3. This lesson found $TXT^\dagger=\frac{1}{\sqrt2}(X+Y)$. Without
   redoing the full matrix multiplication, use $T^2=S$ and the fact
   that $S$ IS Clifford ($SXS^\dagger=Y$, a standard identity) to
   sanity-check that $T$ applied *twice* should land back on a genuine
   Pauli. Does $(TXT^\dagger)$ conjugated by $T$ again plausibly return
   to a Pauli, given $T\cdot T=S$?

   <details className="answer-reveal">
   <summary>Answer</summary>

   Yes, and not merely plausibly. It has to, and the answer is exactly $Y$.

   Conjugation composes: conjugating by $T$ and then by $T$ again is the
   same as conjugating once by $T \cdot T$, because

   $$
   T\left(TXT^\dagger\right)T^\dagger = (TT)X(TT)^\dagger = S X S^\dagger = Y .
   $$

   No matrix multiplication is needed beyond the quoted identity. The
   engine confirms all three links independently: $T^2 = S$ exactly,
   $SXS^\dagger = Y$, and the doubly conjugated matrix equals $Y$ to within
   floating-point noise.

   The sanity check does its job because it lets a suspicious intermediate
   result be tested against a known endpoint. $\tfrac{1}{\sqrt2}(X+Y)$ is
   an unusual-looking object, and it would be easy to suspect an algebra
   slip in deriving it. Feed it through one more $T$ and it must land on a
   Pauli, since two $T$s make an $S$ and $S$ is Clifford. It does, so the
   intermediate is corroborated.

   The geometry underneath is the more useful takeaway. $T$ is a $\pi/4$
   rotation about the $z$-axis, which carries the $x$-axis to the
   $45^\circ$ direction between $x$ and $y$: that is precisely
   $\tfrac{1}{\sqrt2}(X+Y)$, an axis, just not one of the three named ones.
   A second $T$ completes the quarter turn and lands on $y$, a named axis
   again. So $T$ is not *anti*-Clifford or lawless; it lands between the
   Pauli axes, and its square lands back on one. Half of a Clifford
   operation is exactly what "outside the Clifford group but only just"
   means, and it is why $T$ is the minimal thing you can add.

   The wrong turn is reading "$T$ is not Clifford" as "$T$ never produces
   Paulis", and then finding the $Y$ here surprising or contradictory. The
   definition is a statement about *every* Pauli under a *single*
   conjugation. Powers of a non-Clifford gate can perfectly well be
   Clifford, and here $T^2 = S$ and $T^4 = Z$ both are. What matters for
   universality is that $T$ itself is not, so circuits containing an odd
   number of $T$s escape the tableau simulation.

   </details>

4. The Toffoli circuit above uses 6 CNOTs and 7 $T$-type gates ($T$ or
   $T^\dagger$). If $T$-count, not total gate count, is what real
   fault-tolerant hardware cares most about minimizing, does this
   circuit's 2 Hadamards and 6 CNOTs matter for cost the same way the 7
   $T$-gates do? Why or why not, based on this lesson's second closing
   note, on "universal in principle" versus "cheap in practice"?

   <details className="answer-reveal">
   <summary>Answer</summary>

   No, and the gap is not a small constant factor. The $H$s and CNOTs are
   Clifford gates and the $T$s are not, and in a fault-tolerant
   architecture that distinction is the cost model.

   Clifford gates can be implemented directly on encoded logical qubits by
   comparatively cheap means: transversally in codes like Steane's, where
   the logical gate is just the physical gate applied to every physical
   qubit in the block, and by lattice surgery or code deformation on the
   surface code. Nothing extra has to be manufactured. $T$ cannot be
   implemented that way, and the standard route is magic-state
   distillation: prepare many noisy copies of a special resource state,
   consume most of them to purify a few, and spend one purified state per
   logical $T$. That distillation factory can dominate the whole machine's
   qubit count and runtime, so a $T$ can cost orders of magnitude more than
   a CNOT rather than a few times more.

   For this circuit the practical reading is that the resource line reads
   "$7$ $T$s", and the $8$ Clifford gates are close to free by comparison.
   That is why $T$-count is quoted as a figure of merit in its own right,
   why lowering a circuit's $T$-count is an active research problem, and
   why a compiler will happily add Clifford gates if doing so removes even
   one $T$.

   Two things stop this from being the whole story, and both matter. The
   first is that "cheap" is not "free": CNOTs still take time, still
   accumulate error, and on hardware with limited connectivity a logical
   CNOT between distant qubits costs routing, which is real. The second is
   that the cost model is a fault-tolerant one. On today's NISQ devices
   there is no encoding, no distillation, and no magic states, and the
   dominant error source is the two-qubit gate. There $T$ is a cheap
   single-qubit rotation and the $6$ CNOTs are what limits the circuit. So
   the honest answer names its regime: $T$-count is the right objective
   for the fault-tolerant era, two-qubit-gate count for the present one,
   and the lesson's warning against confusing "universal in principle"
   with "cheap in practice" cuts both ways.

   </details>

## Summary

- Single-qubit gates alone map every product state to a product state,
  so they can never reach an entangling gate like CNOT; at least one
  true multi-qubit gate is mathematically required for universality.
- The universality theorem (cited): arbitrary single-qubit gates plus
  CNOT can reach any $n$-qubit unitary.
- Real (especially fault-tolerant) hardware wants a small, FIXED,
  discrete gate set instead, both because calibration is never exact
  and because error correction protects specific discrete operations.
- The Clifford group ($H$, $S$, CNOT) is discrete and entangling but
  NOT universal: Gottesman-Knill makes every Clifford circuit
  efficiently classically simulable, which a universal set cannot be.
- $T$ is verified directly, by conjugation, to NOT be a Clifford gate
  ($TXT^\dagger=\frac{1}{\sqrt2}(X+Y)$, not a Pauli); Clifford+T
  ($\{H,T,\text{CNOT}\}$) is a standard, cited universal discrete set,
  made efficient by the Solovay-Kitaev theorem's polylogarithmic
  approximation overhead.
- Worked example: the standard 15-gate, 7-$T$-gate Toffoli-from-Clifford+T
  circuit, verified against the Toffoli truth table on all 8 basis
  states using this platform's own gate-application engine.
