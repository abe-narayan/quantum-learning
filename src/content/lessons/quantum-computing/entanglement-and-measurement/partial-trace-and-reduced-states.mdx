## The question a state vector cannot answer

Multi-Qubit State Vectors showed that a state vector has no answer
whenever the qubits are <Term id="entanglement">entangled</Term>. The density matrix does, through an
operation called the **<Term id="partial-trace">partial trace</Term>**.

The formula for it is short and, presented cold, looks arbitrary: sum over
one qubit's index while holding it matched between bra and ket. So this
lesson does not present it cold. It states one physical requirement any
sensible answer must meet, and then shows that requirement has exactly one
solution, which is the formula.

## One requirement, and the formula it forces

### The requirement that pins down the definition

Whatever "qubit 0's reduced state" $\rho_A$ means, it has to get local
measurements right: for any single-qubit <Term id="observable">observable</Term> $A_{\text{op}}$
acting on qubit 0 only, measuring it on the full 2-qubit state must give
the same answer as measuring it on $\rho_A$ alone:

$$
\text{Tr}\big[(A_{\text{op}}\otimes I)\,\rho_{AB}\big] = \text{Tr}(A_{\text{op}}\,\rho_A)
$$

This is not a guess at a reasonable-sounding property. It is *the*
defining requirement. Anything claiming to be "qubit 0's state" that gets
it wrong for even one observable is not describing qubit 0.

### Deriving the formula

Write the full state's basis as $|ij\rangle$, with $i$ indexing qubit 0
(this platform's convention: qubit 0 is the most significant bit) and
$j$ indexing qubit 1. Expand the left side using
$(A_{\text{op}}\otimes I)_{ij,i'j'}=(A_{\text{op}})_{ii'}\delta_{jj'}$:

$$
\text{Tr}\big[(A_{\text{op}}\otimes I)\rho_{AB}\big] = \sum_{i,j,i'} (A_{\text{op}})_{ii'}\,(\rho_{AB})_{i'j,\,ij}
= \sum_{i,i'} (A_{\text{op}})_{ii'} \left[\sum_j (\rho_{AB})_{i'j,\,ij}\right]
$$

The bracketed sum depends only on $i,i'$; call it $(\rho_A)_{i'i}$.
Then the whole expression is $\sum_{i,i'}(A_{\text{op}})_{ii'}(\rho_A)_{i'i}=\text{Tr}(A_{\text{op}}\rho_A)$,
exactly the right side, for *any* $A_{\text{op}}$. So the matrix

$$
(\rho_A)_{i'i} = \sum_j (\rho_{AB})_{i'j,\,ij}
$$

satisfies the requirement. It is also the only matrix that does, and that
second half takes one more line. Suppose $\sigma$ satisfied the
requirement too. Then $\text{Tr}[A_{\text{op}}(\rho_A-\sigma)]=0$ for
every $A_{\text{op}}$. Choose $A_{\text{op}}$ to be the matrix with a
single 1 in row $i$, column $i'$, and zeros elsewhere; the trace then
picks out exactly the $(i',i)$ entry of $\rho_A-\sigma$, forcing it to
vanish. Running over all $i,i'$ forces every entry to vanish, so
$\sigma=\rho_A$. This is why the requirement has one solution rather
than a family of them.

The formula sums over the traced-out qubit's index, keeping it matched between bra
and ket, while the kept qubit's indices stay free. This is the
**partial trace**, $\rho_A=\text{Tr}_B(\rho_{AB})$. It is not one
reasonable choice among several. It is the *unique* operation making local
observables come out right, which is why the formula's odd-looking index
pattern is forced rather than chosen. `partialTrace.ts` implements this
index sum (generalized to any number of qubits via bitmask indexing, not
hardcoded to 2), following the qubit-0-is-MSB convention `gates.ts`
established for every other multi-qubit operation on this platform.

### A product state: the sanity check

For a product state $\rho_{AB}=\rho_A\otimes\rho_B$, the partial trace has
to return $\rho_A$ unchanged. Tracing out an independent subsystem should
not affect the other one, and a definition that failed this test would be
wrong for reasons having nothing to do with entanglement. Take
$|{+}0\rangle$:

<QuantumStateDisplay state={plusZeroState} label="|+0⟩" />

$$
\text{Tr}_B\big(\rho_{|{+}0\rangle}\big) = \rho_{|+\rangle} = \begin{pmatrix}0.5&0.5\\0.5&0.5\end{pmatrix}, \qquad
\text{Tr}_A\big(\rho_{|{+}0\rangle}\big) = \rho_{|0\rangle} = \begin{pmatrix}1&0\\0&0\end{pmatrix}
$$

Exactly the individual factors, confirmed directly against
`reducedDensityMatrixQubit0`/`reducedDensityMatrixQubit1` in this
module's tests. And as a numeric check of the defining requirement
itself, using $A_{\text{op}}=X$: $\langle{+}0|X\otimes I|{+}0\rangle=1$
(since $|+\rangle$ is $X$'s $+1$-eigenstate), and $\text{Tr}(\rho_{|+\rangle}X)=1$
too: both sides of the requirement agree, not just in the
abstract derivation but for this concrete state.

### An entangled state: something new

Now take the partially entangled state
$|\psi(\theta)\rangle=\cos\theta|00\rangle+\sin\theta|11\rangle$. Its
reduced state on qubit 0 (worked out by the same index sum) is:

$$
\rho_A(\theta) = \begin{pmatrix}\cos^2\theta & 0\\ 0 & \sin^2\theta\end{pmatrix}
$$

Check the defining requirement with $A_{\text{op}}=Z$: the global
expectation is $\langle\psi(\theta)|Z\otimes I|\psi(\theta)\rangle
=\cos^2\theta\,(+1)+\sin^2\theta\,(-1)=\cos2\theta$ (the $|00\rangle,|11\rangle$
cross-terms vanish since $Z\otimes I$ maps each basis term to $\pm$
itself, and $\langle00|11\rangle=0$). And directly from $\rho_A(\theta)$:
$\text{Tr}(\rho_A(\theta)Z)=\cos^2\theta-\sin^2\theta=\cos2\theta$:
identical, for every $\theta$, exactly as the derivation guarantees.

At $\theta=\pi/4$ (a Bell state), $\rho_A=\begin{pmatrix}0.5&0\\0&0.5\end{pmatrix}=I/2$.
The reduced state of one qubit of a maximally entangled pair is *maximally
mixed*, even though the full 2-qubit state $|\Phi^+\rangle$ is pure and
completely specified. Knowing everything about the pair leaves you knowing
nothing about either member. The next lesson takes that apart.

## What earlier lessons could only gesture at

The partial trace answers what earlier lessons could only gesture at.
Measuring qubit 0 of an entangled pair, with qubit 1 never touched,
behaves as if qubit 0 were described by $\rho_A=\text{Tr}_B(\rho_{AB})$,
and it does so by construction rather than by luck: $\rho_A$ was defined
as the unique object that makes it true.

## Reducing the other qubit, for a change

**Compute the reduced state of qubit 1 (not qubit 0) for the Bell state
$|\Psi^+\rangle=\frac{1}{\sqrt2}(|01\rangle+|10\rangle)$.**

In the ordered basis $|00\rangle,|01\rangle,|10\rangle,|11\rangle$,
$|\Psi^+\rangle$ has amplitude $\frac{1}{\sqrt2}$ on $|01\rangle$ and
$|10\rangle$ only, so $\rho_{AB}$'s only nonzero entries are
$\rho_{01,01}=\rho_{10,10}=\tfrac12$ (diagonal) and
$\rho_{01,10}=\rho_{10,01}=\tfrac12$ (off-diagonal). The reduced
$(\rho_B)_{jj'}$ sums over qubit 0's index $i$ while requiring it to
*match* between bra and ket: $(\rho_B)_{jj'}=\sum_i(\rho_{AB})_{ij,ij'}$.
The off-diagonal entry $\rho_{01,10}$ has bra-qubit-0-index $0$ and
ket-qubit-0-index $1$; since these don't match, this entry is *excluded*
from the sum entirely, for any $j,j'$. Only the two diagonal entries
survive: $(\rho_B)_{11}=\rho_{01,01}=\tfrac12$ (from $i=0$) and
$(\rho_B)_{00}=\rho_{10,10}=\tfrac12$ (from $i=1$), with every
off-diagonal $(\rho_B)_{jj'}$, $j\neq j'$, receiving no contribution at
all. Result: $\rho_B=\begin{pmatrix}0.5&0\\0&0.5\end{pmatrix}=I/2$,
maximally mixed, same as $|\Phi^+\rangle$'s reduced states.

## The argument names which qubit disappears

<Callout type="warning">
**Tracing out the wrong qubit.** `partialTrace(rho, 2, [1])` traces out
qubit 1, leaving qubit 0's reduced state. The argument names *which
qubit disappears*, not which one you keep. Mixing this up silently
swaps $\rho_A$ and $\rho_B$ whenever the two aren't equal.
</Callout>

<Callout type="note">
**Expecting the partial trace to "reveal" a hidden pure state.** For an
entangled global state, $\rho_A$ is genuinely mixed; there is no pure
state it's secretly hiding. The mixedness is real, not a computational
artifact.
</Callout>

## Practice Questions

1. Compute $\text{Tr}_B(\rho_{|01\rangle})$ and $\text{Tr}_A(\rho_{|01\rangle})$
   for the computational basis state $|01\rangle$ (a product state).

   <details className="answer-reveal">
   <summary>Answer</summary>

   $$
   \text{Tr}_B(\rho_{|01\rangle}) = \begin{pmatrix}1&0\\0&0\end{pmatrix} = |0\rangle\langle0|, \qquad \text{Tr}_A(\rho_{|01\rangle}) = \begin{pmatrix}0&0\\0&1\end{pmatrix} = |1\rangle\langle1|
   $$

   The engine's `reducedDensityMatrixQubit0` and
   `reducedDensityMatrixQubit1` return exactly these.

   The index sum makes it quick.
   $\rho_{|01\rangle}=|01\rangle\langle01|$ has a single nonzero entry, a
   $1$ in the row and column labelled $01$. Tracing out qubit 1 means
   summing entries $(\rho)_{i'j,\,ij}$ over $j$ with $i,i'$ free, and the
   only surviving term has $i=i'=0$ and $j=1$, giving a $1$ in the
   reduced matrix's $(0,0)$ slot and zeros elsewhere. Tracing out qubit 0
   is the mirror image and lands the $1$ in the $(1,1)$ slot.

   The result is the sanity check the lesson demands of the definition.
   $|01\rangle$ is a product state, $|0\rangle\otimes|1\rangle$, so each
   qubit has a perfectly good state of its own, and the partial trace
   returns those states unchanged. Both are pure, with purity $1$ and
   entropy $0$: no information was lost by describing the qubits
   separately, because there was none stored in the relationship. Contrast
   with a Bell state, where the same operation returns $I/2$ for both
   qubits and every bit of the description has moved into the correlation.

   The wrong turn is expecting the two answers to be equal, or to be the
   same matrix in some basis. They are different because the two qubits are
   in different states here. What *is* general is the pair of purities:
   for a pure global state the two reduced states always have equal purity
   and equal entropy, and that is the theorem the next lessons rest on,
   not an accident of this example.

   </details>

2. For $|\psi(\theta)\rangle=\cos\theta|00\rangle+\sin\theta|11\rangle$,
   verify the defining requirement using $A_{\text{op}}=X$ instead of $Z$.
   ($\rho_A(\theta)$ is diagonal and $X$ has zero diagonal entries, so both
   sides should come out to exactly $0$, for every $\theta$, unlike the
   $Z$ case above.)

   <details className="answer-reveal">
   <summary>Answer</summary>

   Both sides are $0$ for every $\theta$, and the engine confirms it at
   $\theta = 0$, $0.3$ and $\pi/4$.

   The reduced side is immediate. $\rho_A(\theta)=\mathrm{diag}(\cos^2\theta,\sin^2\theta)$
   and $X=\begin{pmatrix}0&1\\1&0\end{pmatrix}$, so $\rho_A X$ has zeros on
   its diagonal, giving $\text{Tr}(\rho_A X)=0$.

   The global side takes one more step but says something more interesting.
   $X\otimes I$ maps $|00\rangle\mapsto|10\rangle$ and $|11\rangle\mapsto|01\rangle$,
   so

   $$
   \langle\psi(\theta)|X\otimes I|\psi(\theta)\rangle = \cos\theta\sin\theta\big(\langle00|01\rangle + \langle11|10\rangle\big) + \cos^2\theta\,\langle00|10\rangle + \sin^2\theta\,\langle11|01\rangle = 0
   $$

   because every one of those four basis overlaps is zero. $X\otimes I$
   flips qubit 0 only, and the state has no term that differs from another
   term in qubit 0 alone: $|00\rangle$ and $|11\rangle$ differ in *both*
   labels. There is nothing for the flipped ket to overlap with.

   That is the real content, and it is the same mechanism as the lesson's
   remark about the excluded $|00\rangle\langle11|$ cross term. The
   $\theta$-dependence of this state lives entirely in a coherence whose
   bra and ket disagree on both qubits, and any observable acting on one
   qubit alone is blind to it. It is why $\rho_A$ comes out diagonal, why
   $\langle X\rangle$ and $\langle Y\rangle$ both vanish on qubit 0, and
   ultimately why the reduced state loses track of the entanglement while
   the global state has not lost anything at all.

   The wrong turn is concluding that the answer is $0$ because the state is
   entangled, and expecting $\langle X\otimes I\rangle$ to be nonzero for a
   product state. It is zero for $|00\rangle$ too, which is $\theta=0$ and
   perfectly unentangled. What makes it vanish is the absence of
   single-qubit-flip coherences, which this whole family lacks whether
   entangled or not. Take $|{+}0\rangle$ instead and
   $\langle X\otimes I\rangle=1$.

   </details>

3. Explain in one sentence why $\text{Tr}_B(\rho_A\otimes\rho_B)=\rho_A$
   must hold for *any* valid $\rho_A,\rho_B$, using this lesson's
   defining requirement (not just by trusting the formula).

   <details className="answer-reveal">
   <summary>Answer</summary>

   For any single-qubit observable $A_{\text{op}}$,
   $\text{Tr}[(A_{\text{op}}\otimes I)(\rho_A\otimes\rho_B)] = \text{Tr}(A_{\text{op}}\rho_A)\,\text{Tr}(I\rho_B) = \text{Tr}(A_{\text{op}}\rho_A)$,
   since the trace of a tensor product factorizes and $\text{Tr}(\rho_B)=1$;
   so $\rho_A$ satisfies the defining requirement, and the lesson's
   uniqueness argument says it is therefore the answer.

   That uniqueness half is the part worth not skipping. Showing that
   $\rho_A$ *works* leaves open whether something else might work too, and
   the lesson closes it by choosing $A_{\text{op}}$ to be the matrix with a
   single $1$ in position $(i,i')$, which forces the corresponding entry of
   any competing $\sigma$ to match $\rho_A$'s. Run over all $i,i'$ and every
   entry is pinned. So "satisfies the requirement" upgrades to "is the
   reduced state".

   Note what the argument did not need: nothing about $\rho_B$ except that
   its trace is $1$. Qubit B could be pure, maximally mixed, or anything in
   between, and qubit A's description is unaffected. That is exactly the
   physical content of "independent", and a definition of partial trace
   that failed here would be broken for reasons having nothing to do with
   entanglement.

   The wrong turn is verifying the claim by multiplying out the index sum
   for a couple of specific matrices. That confirms the formula on those
   examples and gives no reason it holds in general, whereas the argument
   above uses only $\text{Tr}(\rho_B)=1$ and the factorization of the trace,
   and so covers every pair at once.

   </details>

4. `partialTrace` throws an error if asked to trace out every qubit of a
   system. Using the defining requirement, explain why "the reduced state
   of zero qubits" isn't a meaningful object to compute in the first
   place. Then say what value the formula *would* return if it were
   allowed to run, and why a function returning that value would be worse
   than one that throws.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The defining requirement is a statement quantified over observables on
   the kept subsystem: $\rho_A$ is whatever matrix makes
   $\text{Tr}(A_{\text{op}}\rho_A)$ agree with the global expectation for
   every $A_{\text{op}}$. Keep nothing, and there are no observables to
   quantify over. The requirement that was supposed to pin the answer down
   says nothing at all, because there is no local measurement whose
   statistics the answer has to reproduce.

   What the formula would return if allowed to run is $\text{Tr}(\rho)=1$,
   a $1\times1$ matrix holding the number one. It is the same answer for
   every input. A Bell state, a product state, a maximally mixed state and
   any $\rho$ you care to invent all reduce to $[1]$, because that is what
   normalization guarantees and nothing else survives.

   That is precisely why returning it would be worse than throwing. A
   function whose output is constant cannot be doing the job its caller
   thinks it is doing, so any call that reaches it is a bug: a wrong qubit
   index, an off-by-one in a list, a loop that traced out one subsystem too
   many. Returning $[1]$ lets that bug travel downstream, where it becomes
   a purity of $1$ and an entropy of $0$ and a confident, wrong conclusion
   that some state was pure. Throwing turns a silent wrong answer into a
   stack trace at the point of the mistake.

   The wrong turn is reading the error as a limitation of the
   implementation, something a more general version could support. Nothing
   is missing. The object is well defined and carries zero information, and
   the engine's refusal encodes the difference between "cannot be computed"
   and "can be computed and is never what you wanted".

   </details>

## Summary

- The partial trace is uniquely determined by requiring
  $\text{Tr}[(A_{\text{op}}\otimes I)\rho_{AB}]=\text{Tr}(A_{\text{op}}\rho_A)$
  for every local observable $A_{\text{op}}$, not chosen for convenience.
- For a product state, the partial trace returns the untouched factor
  exactly, as a sanity check on the definition.
- For an entangled state, the reduced state is genuinely mixed: for a
  Bell state, exactly maximally mixed ($I/2$) on either qubit.
- This platform's `partialTrace` respects the qubit-0-is-MSB convention
  used everywhere else, generalized to any number of qubits via bitmask
  indexing.
