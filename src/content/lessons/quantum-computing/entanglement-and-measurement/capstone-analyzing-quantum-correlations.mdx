## The state

$$
|\psi\rangle = \sqrt{0.7}\,|00\rangle + \sqrt{0.3}\,e^{i\pi/3}|11\rangle
$$

<QuantumStateDisplay state={capstoneState} label="|ψ⟩ = √0.7|00⟩ + √0.3 e^(iπ/3)|11⟩" />

Unlike every earlier worked example in this course, this state has both
an unequal amplitude split ($0.7/0.3$, not $0.5/0.5$) *and* a nontrivial
relative phase ($e^{i\pi/3}$, not just $\pm1$), a genuine test that
every formula in this course handles complex amplitudes correctly, not
just the real-valued special cases used for teaching clarity earlier.

## Mathematical Development

### Entanglement measures (pure-state tools)

With $a=\sqrt{0.7},b=c=0,d=\sqrt{0.3}\,e^{i\pi/3}$:
$ad-bc=\sqrt{0.7}\sqrt{0.3}\,e^{i\pi/3}=\sqrt{0.21}\,e^{i\pi/3}$, so
$|ad-bc|=\sqrt{0.21}\approx0.4583$. The phase $e^{i\pi/3}$ affects only
$ad-bc$'s phase, not its magnitude, and concurrence only ever uses the
magnitude:

$$
C(|\psi\rangle) = 2\sqrt{0.21} \approx 0.9165
$$

Close to, but noticeably below, a Bell state's $C=1$: this state is
strongly but not maximally entangled. The reduced state
$\rho_A=\text{Tr}_B(\rho)$ has diagonal entries $|a|^2=0.7,|d|^2=0.3$
(the phase disappears entirely from the diagonal, and $b=c=0$ means no
off-diagonal terms either), so $\rho_A=\text{diag}(0.7,0.3)$, already
diagonal, making its von Neumann entropy just the Shannon entropy of
$(0.7,0.3)$:

$$
E(|\psi\rangle) = S(\rho_A) = -0.7\log_2(0.7)-0.3\log_2(0.3) \approx 0.8813 \text{ bits}
$$

Both computed directly by `entanglementEntropy` and
`concurrenceOfPureState`, and cross-checked against Lesson 5's identity:
$1-\text{Tr}(\rho_A^2)=2|ad-bc|^2=2(0.21)=0.42$, so
$\text{Tr}(\rho_A^2)=0.58$, matching `purity(reducedA)` exactly.

### Mixing in noise: which tools still apply

Build a genuinely mixed global state,
$\rho_{\text{noisy}}=0.8\,\rho_\psi+0.2\,(I/4)$, and ask what can still
be computed. `purity(reducedA)` and `vonNeumannEntropy` on the *reduced*
state still work: reduced states are always $2\times2$ for a 2-qubit
system, regardless of whether the global state is pure. Numerically,
the reduced state becomes $\rho_A=\text{diag}(0.66,0.34)$ (the mixing
weight blends linearly into the diagonal, $0.8\times0.7+0.2\times0.5=0.66$,
since partial trace is linear), giving entropy $\approx0.9248$ bits,
slightly higher than the pure state's $0.8813$ (extra classical noise
adds extra uncertainty, on top of the entanglement that was already
there).

But `entanglementEntropy` and `concurrenceOfPureState` **cannot** be
called on $\rho_{\text{noisy}}$ at all: both require a `StateVector`
argument, and $\rho_{\text{noisy}}$, being genuinely mixed, has no state
vector to pass them. This is exactly Lesson 7's warning, not a new
restriction: reduced entropy stops being a valid entanglement measure
once the global state is mixed, so the type signature itself refuses to
let you compute the wrong thing here.

There is a second, sharper boundary. Attempting
`vonNeumannEntropy(rhoNoisy)` **directly on the full $4\times4$ global
density matrix** throws an error,
`eigenvaluesHermitian2x2 requires a 2x2 matrix (got 4x4)`, because
computing it would need the eigenvalues of a general $4\times4$
Hermitian matrix, and this platform's closed-form eigensolver is
explicitly scoped to $2\times2$ only (Lesson 6). `purity` and
`validateDensityMatrix`'s Hermiticity/trace checks *do* still work on
the full $4\times4$ matrix (purity only needs a trace, no
diagonalization), but `validateDensityMatrix`'s positivity check
reports `null` rather than true or false for a matrix this size:
another honest, engine-enforced boundary, not a bug.

### A partial CHSH violation

Using the standard angle configuration from Lesson 11
($\theta_a=0,\theta_{a'}=\pi/2,\theta_b=\pi/4,\theta_{b'}=-\pi/4$),
derived specifically for $|\Phi^+\rangle$ and not this state,
`chshValue` gives $S\approx2.0623$ for $|\psi\rangle$: still above the
classical bound of 2, but only barely, nowhere near $2\sqrt2$. A
numerical search over $B,B'$ (holding $A,A'$ fixed) finds this state can
reach at best $|S|\approx2.20$, a real, genuine violation, consistent
with $C\approx0.92$ indicating strong-but-not-maximal entanglement, and
well short of $2\sqrt2$, consistent with this state not being a Bell
state.

Four independently-built tools, one consistent picture: each bar below
is shown as a fraction of its own maximum, so a taller bar means "more
entangled/correlated" the same way across all four, despite their very
different native scales (the exact numbers are in each caption).

## Physical Interpretation

Every number in this analysis is internally consistent with every other
one: high (but not maximal) concurrence goes with high (but not maximal)
entanglement entropy, goes with a real (but not maximal) CHSH violation:
three independently-built tools, agreeing on the same qualitative
picture from three different directions, exactly as a coherent theory
should. And the honesty boundaries (what happens when a pure-state tool
meets a mixed input, what happens when a $2\times2$-only tool meets a
$4\times4$ matrix) aren't failures of the engine; they're the engine
correctly refusing to compute something it was never built to compute
correctly.

## Common Mistakes

<Callout type="mistake">
**Assuming a relative phase changes concurrence or entropy for this
family of states.** For $a|00\rangle+d|11\rangle$-type states, both
depend only on $|a|,|d|$. The phase of $d$ affects the *state* (and
would matter for e.g. CHSH, which depends on the full complex
amplitudes) but not these two particular derived quantities.
</Callout>

<Callout type="mistake">
**Expecting the Lesson 11 angle configuration to be optimal for every
state.** It was derived for $|\Phi^+\rangle$ specifically. As this
lesson's numerical search shows, a different (and for this state, only
mildly different) angle choice does slightly better for a different
entangled state.
</Callout>

## Summary

- Every tool in this course (density matrix, partial trace, purity,
  entropy, concurrence, CHSH) applies cleanly to a single unfamiliar
  entangled state with a nontrivial phase, agreeing on a consistent
  physical picture.
- Reduced-state tools (`purity`, `vonNeumannEntropy` on a $2\times2$
  reduced matrix) work on any valid density matrix, pure or mixed;
  entanglement-measure tools (`entanglementEntropy`,
  `concurrenceOfPureState`) require a pure global `StateVector` by their
  very type signature.
- Attempting `vonNeumannEntropy` on a full $4\times4$ mixed global state
  throws: a real, engine-enforced boundary at exactly the dimension
  this platform's closed-form eigensolver stops covering.
- A strongly (but not maximally) entangled state gives a real (but
  weaker than $2\sqrt2$) CHSH violation. The three measures built in
  this course agree quantitatively, not just qualitatively.
