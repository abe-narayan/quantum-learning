## Eleven tools, each attached to its own example

The last eleven lessons built a toolkit for describing quantum states
beyond what a state vector can express. Each tool arrived attached to the
example that motivated it, which is good for learning and bad for
confidence: it is easy to mistake "I followed that derivation" for "I could
run that analysis myself."

So the state below appears in none of the earlier lessons, and every tool
gets pointed at it in turn. Two of them will disagree in an instructive
way, and one will fail outright, which is the part worth reading closely.

## The state

$$
|\psi\rangle = \sqrt{0.7}\,|00\rangle + \sqrt{0.3}\,e^{i\pi/3}|11\rangle
$$

<QuantumStateDisplay state={capstoneState} label="|ψ⟩ = √0.7|00⟩ + √0.3 e^(iπ/3)|11⟩" />

Unlike every earlier worked example in this course, this state has both an
unequal amplitude split ($0.7/0.3$, not $0.5/0.5$) *and* a nontrivial
<Term id="global-relative-phase">relative phase</Term> ($e^{i\pi/3}$, not $\pm1$). Those two features are
deliberate. They test whether the formulas handle complex amplitudes, and
not only the real-valued special cases chosen earlier for clarity.

## Every measure, run on the same state

### Entanglement measures (pure-state tools)

With $a=\sqrt{0.7},b=c=0,d=\sqrt{0.3}\,e^{i\pi/3}$:
$ad-bc=\sqrt{0.7}\sqrt{0.3}\,e^{i\pi/3}=\sqrt{0.21}\,e^{i\pi/3}$, so
$|ad-bc|=\sqrt{0.21}\approx0.4583$. The phase $e^{i\pi/3}$ affects only
$ad-bc$'s phase, not its magnitude, and concurrence only ever uses the
magnitude:

$$
C(|\psi\rangle) = 2\sqrt{0.21} \approx 0.9165
$$

Close to, but noticeably below, a Bell state's $C=1$: this state is
strongly but not maximally entangled. The <Term id="partial-trace">reduced state</Term>
$\rho_A=\text{Tr}_B(\rho)$ has diagonal entries $|a|^2=0.7,|d|^2=0.3$
(the phase disappears entirely from the diagonal, and $b=c=0$ means no
off-diagonal terms either), so $\rho_A=\text{diag}(0.7,0.3)$, already
diagonal, making its <Term id="von-neumann-entropy-purity">von Neumann entropy</Term> just the Shannon entropy of
$(0.7,0.3)$:

$$
E(|\psi\rangle) = S(\rho_A) = -0.7\log_2(0.7)-0.3\log_2(0.3) \approx 0.8813 \text{ bits}
$$

Both numbers on this page come straight from `entanglementEntropy` and
`concurrenceOfPureState` rather than from the hand algebra above, which
is what makes the agreement worth anything. Cross-checked against
Lesson 5's identity: $1-\text{Tr}(\rho_A^2)=2|ad-bc|^2=2(0.21)=0.42$, so
$\text{Tr}(\rho_A^2)$ should be $0.58$, and `purity` applied to the
engine's own reduced state returns {capstoneReducedPurity.toFixed(2)}.

### Mixing in noise: which tools still apply

Build a global state that is genuinely mixed,
$\rho_{\text{noisy}}=0.8\,\rho_\psi+0.2\,(I/4)$, and ask what can still
be computed. `purity(reducedA)` and `vonNeumannEntropy` on the *reduced*
state still work: reduced states are always $2\times2$ for a 2-qubit
system, regardless of whether the global state is pure. Numerically,
the reduced state becomes $\rho_A=\text{diag}(0.66,0.34)$ (the mixing
weight blends linearly into the diagonal, $0.8\times0.7+0.2\times0.5=0.66$,
since partial trace is linear), giving entropy $\approx0.9248$ bits,
slightly higher than the pure state's $0.8813$ (extra classical noise
adds extra uncertainty, on top of the entanglement that was already
there).

But `entanglementEntropy` and `concurrenceOfPureState` **cannot** be
called on $\rho_{\text{noisy}}$ at all: both require a `StateVector`
argument, and $\rho_{\text{noisy}}$, being a true mixture, has no state
vector to pass them. This is Lesson 7's warning again, not a new
restriction: reduced entropy stops being a valid entanglement measure
once the global state is mixed, so the type signature itself refuses to
let you compute the wrong thing here.

There is a second, sharper boundary. Attempting
`vonNeumannEntropy(rhoNoisy)` **directly on the full $4\times4$ global
density matrix** throws an error,
`eigenvaluesHermitian2x2 requires a 2x2 matrix (got 4x4)`, because
computing it would need the eigenvalues of a general $4\times4$
Hermitian matrix, and this platform's closed-form eigensolver is
explicitly scoped to $2\times2$ only (Lesson 6). `purity` and
`validateDensityMatrix`'s Hermiticity/trace checks *do* still work on
the full $4\times4$ matrix (purity only needs a trace, no
diagonalization), but `validateDensityMatrix`'s positivity check
reports `null` rather than true or false for a matrix this size:
another honest, engine-enforced boundary, not a bug.

`chshValue` gives $S\approx2.0623$ for $|\psi\rangle$: still above the

numerical search over $B,B'$ (holding $A,A'$ fixed) finds this state can
reach at best $|S|\approx2.20$: a real violation, and still well short of
$2\sqrt2$. It is worth being precise about where that shortfall comes
from, because "the state is less entangled" is only part of it. For a
state $a|00\rangle+d|11\rangle$ measured with in-plane observables
$M(\theta)=\cos\theta\,Z+\sin\theta\,X$, the correlation works out to
$E(\theta_a,\theta_b)=\cos\theta_a\cos\theta_b+2\,\text{Re}(a^*d)\,\sin\theta_a\sin\theta_b$,
and the best achievable $|S|$ is $2\sqrt{1+4\,\text{Re}(a^*d)^2}$. Here
$2\,\text{Re}(a^*d)=C\cos(\pi/3)=0.9165\times0.5=0.4583$, giving
$2\sqrt{1.21}=2.2$ exactly. Strip the phase out ($e^{i0}$ instead of
$e^{i\pi/3}$) and the same amplitudes reach $2\sqrt{1+C^2}\approx2.71$.
The relative phase, which concurrence and entropy ignore entirely,
costs this state most of its CHSH violation, because it tilts the
correlation out of the $X$-$Z$ plane these four observables can see.
(The full [CHSH simulator](/simulators#chsh-bell-test) lets you search
over all four angles by hand, on a Bell state instead of this one, if
you want to see the Lesson-11 configuration recovered as the optimum
there.)

## Where the measures agree, and how far

Concurrence and entanglement entropy agree closely: high but not maximal,
by both measures, and tied together by an exact identity. CHSH agrees on
the qualitative verdict (entangled, provably beyond any local hidden
variable) and disagrees on the amount, and the disagreement is the more
useful result. Concurrence and entropy are properties of the state alone.
A CHSH value is a property of the state *and* the four measurement axes
you chose, so it can be depressed by a bad choice of axes or, as here, by
a relative phase that the axes cannot reach. When two measures of "the
same thing" disagree, the first question is whether they were measuring
the same thing.

The boundaries matter as much as the agreements. A pure-state tool handed
a mixed input, or a $2\times2$-only tool handed a $4\times4$ matrix, does
not quietly return a plausible-looking number. It refuses, which is the
behaviour you want from anything you plan to trust.

## A phase that changes the state without changing these numbers

<Callout type="warning">
**Assuming a relative phase changes concurrence or entropy for this
family of states.** For $a|00\rangle+d|11\rangle$-type states, both
depend only on $|a|,|d|$. The phase of $d$ affects the *state* (and
would matter for e.g. CHSH, which depends on the full complex
amplitudes) but not these two particular derived quantities.
</Callout>

<Callout type="warning">
**Expecting the Lesson 11 angle configuration to be optimal for every
state.** It was derived for $|\Phi^+\rangle$ specifically. As this
lesson's numerical search shows, a different (and for this state, only
mildly different) angle choice does slightly better for a different
entangled state.
</Callout>

## Practice Questions

1. Compute $E(|\psi\rangle)$ and $C(|\psi\rangle)$ for
   $|\psi'\rangle=\sqrt{0.5}|00\rangle+\sqrt{0.5}\,e^{i\pi/6}|11\rangle$,
   and confirm the phase $e^{i\pi/6}$ doesn't change either value
   compared to the ordinary $|\Phi^+\rangle$ (phase $0$).

   <details className="answer-reveal">
   <summary>Answer</summary>

   $C = 1$ and $E = 1$ bit: maximally entangled by both measures, exactly
   as $|\Phi^+\rangle$ is.

   Concurrence first. With $a=\sqrt{0.5}$, $b=c=0$ and
   $d=\sqrt{0.5}\,e^{i\pi/6}$, the determinant is
   $ad = 0.5\,e^{i\pi/6}$, whose magnitude is $0.5$ because
   $|e^{i\pi/6}|=1$. So $C = 2|ad-bc| = 1$. The phase rotated the
   determinant in the complex plane and left its length alone, and $C$ uses
   only the length.

   Entropy next. The reduced state is
   $\rho_A = \mathrm{diag}(|a|^2, |d|^2) = \mathrm{diag}(0.5, 0.5) = I/2$,
   since the diagonal entries are squared magnitudes and a phase does not
   survive a squared magnitude. That gives $E = 1$ bit. The engine returns
   $1.0000000000000002$ for $C$ and $1$ for $E$.

   The general statement for this family is that both measures depend only
   on $|a|$ and $|d|$. That is not a limitation to apologize for. Adding a
   relative phase is applying a local gate, $\mathrm{diag}(1,e^{i\pi/6})$
   on qubit 1 alone, and no local gate can change how entangled a pair is,
   so any correct entanglement measure *must* return the same value. A
   measure that responded to this phase would be measuring something other
   than entanglement.

   The wrong turn is concluding that the phase is therefore physically
   irrelevant. It is a relative phase, not a global one, so $|\psi'\rangle$
   and $|\Phi^+\rangle$ are genuinely different states, distinguishable by
   experiment. The capstone's own CHSH analysis is the demonstration: a
   phase of $e^{i\pi/3}$ on an otherwise identical state costs most of its
   CHSH violation, because the four in-plane observables cannot see a
   correlation that has been tilted out of the $X$-$Z$ plane. Same
   entanglement, different state, different results from a fixed set of
   measurement axes.

   </details>

2. Explain, citing the specific type signatures involved, why
   `concurrenceOfPureState` takes a `StateVector` rather than a `Matrix`
   as its argument, and why this is a feature, not an oversight. Then say
   what would have to be true of a function that could legitimately accept
   a `Matrix`.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The formula is $C = 2|ad-bc|$, built from the four complex amplitudes
   $a,b,c,d$ of a pure state. A `StateVector` is exactly a list of
   amplitudes, so the type carries precisely the input the formula needs.
   A `Matrix` does not: a general density matrix has no amplitudes to read
   off, because a mixture is not any single ket. The function's
   implementation makes this concrete by delegating to `testSeparability`,
   which also takes a `StateVector` and computes `determinantMagnitude`
   from the same four numbers.

   The feature is that the type signature enforces the mathematical
   precondition at compile time. Lesson 7 proved that reduced entropy stops
   being an entanglement measure once the global state is mixed, and the
   same failure would apply to any pure-state formula wrongly extended.
   Because `concurrenceOfPureState` cannot be handed
   $\rho_{\text{noisy}} = 0.8\rho_\psi + 0.2(I/4)$, there is no way to
   obtain a confident, meaningless number from it. The alternative, a
   function accepting a `Matrix` and silently applying a pure-state
   formula, would return a plausible value that means nothing, which is the
   worst failure mode available.

   A function that could legitimately accept a `Matrix` would have to
   compute a genuine mixed-state entanglement measure, and that is a real
   and much harder object. Wootters' concurrence for mixed states is the
   standard one, and it needs the eigenvalues of
   $\rho\,(\sigma_y\otimes\sigma_y)\,\rho^*\,(\sigma_y\otimes\sigma_y)$,
   a $4\times4$ non-Hermitian eigenvalue problem, well outside the
   closed-form $2\times2$ solver this platform scopes itself to. It
   coincides with $2|ad-bc|$ on pure states, so the current function is its
   restriction, not a rival to it. Building it would mean adding a general
   eigensolver first, which the capstone's own error message about
   $4\times4$ matrices already flags as out of scope.

   The wrong turn is treating the signature as an inconvenience to route
   around, for instance by extracting a "closest pure state" from
   $\rho_{\text{noisy}}$ and passing that. That produces a number about a
   different state, and the difference is exactly the noise you were trying
   to account for.

   </details>

3. Using Lesson 5's identity, predict $\text{Tr}(\rho_A^2)$ for a state
   with $|ad-bc|=0.48$, and check it against a value between this
   lesson's $|\psi\rangle$ ($|ad-bc|\approx0.458$, purity $0.58$) and a
   Bell state ($|ad-bc|=0.5$, purity $0.5$). Then give the same state's
   concurrence and entanglement entropy, and check those against the same
   two reference points.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The identity gives

   $$
   \text{Tr}(\rho_A^2) = 1 - 2(0.48)^2 = 1 - 0.4608 = 0.5392 ,
   $$

   which sits between the Bell state's $0.5$ and the capstone state's
   $0.58$, as it must, since $0.48$ sits between $0.5$ and $0.458$ and the
   identity is monotonic in $|ad-bc|$.

   Concurrence is immediate: $C = 2(0.48) = 0.96$, between the capstone
   state's $0.9165$ and the Bell state's $1$.

   Entropy takes one more step. For a state $a|00\rangle+d|11\rangle$ with
   $|a||d| = 0.48$ and $|a|^2+|d|^2=1$, the two squared magnitudes satisfy
   $x(1-x) = 0.2304$, so $x^2 - x + 0.2304 = 0$ and
   $x = \left(1 \pm \sqrt{1-0.9216}\right)/2 = (1\pm0.28)/2$, giving
   $\rho_A = \mathrm{diag}(0.64, 0.36)$. Then

   $$
   E = -0.64\log_2 0.64 - 0.36\log_2 0.36 = 0.4121 + 0.5306 = 0.9427 \text{ bits,}
   $$

   which the engine confirms as $0.9426831892554921$. Between the capstone
   state's $0.8813$ and the Bell state's $1$, completing the pattern.

   All three move in step, and here they move by nearly the same fraction
   of their remaining range: from the capstone state to this one, purity
   closes $51\%$ of its gap to the floor of $0.5$, concurrence $52\%$ of
   its gap to $1$, entropy $52\%$ of its gap to $1$ bit. That near-match is
   a feature of this narrow family rather than a general law, since the
   three are tied to one another by exact but nonlinear identities. Over a
   wider range they separate, as the previous lesson's comparison of
   $C(\theta)$ against $E(\theta)$ near $\theta=0$ shows. What is general is
   that they always agree on the ranking and never on the scale, so a claim
   like "this state is $96\%$ as entangled as a Bell pair" is only
   meaningful once you say which measure the percentage is on.

   The wrong turn is inferring the CHSH value from any of these. A state
   with $C=0.96$ can violate CHSH strongly or barely, depending on its
   relative phase and on which axes you measure, exactly as this lesson's
   own $S\approx2.06$ against a possible $2.20$ shows.

   </details>

4. This lesson found $\rho_{\text{noisy}}$'s reduced entropy
   ($\approx0.9248$) is *higher* than $|\psi\rangle$'s own entanglement
   entropy ($\approx0.8813$), even though mixing in noise should reduce
   entanglement. Explain why this isn't a contradiction, using this
   lesson's discussion of what reduced entropy conflates once the global
   state is mixed.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because the two numbers are not the same quantity. $0.8813$ is an
   entanglement entropy, computed from a pure global state, where
   $S(\rho_A)$ is entitled to be read as entanglement. $0.9248$ is just the
   entropy of a reduced state, computed from a mixed global state, where
   the same formula no longer measures entanglement and never claimed to.

   Follow the arithmetic and the two sources become visible. Partial trace
   is linear, so $\rho_A$ for the noisy state is
   $0.8\,\mathrm{diag}(0.7,0.3) + 0.2\,\mathrm{diag}(0.5,0.5) = \mathrm{diag}(0.66,0.34)$,
   which the engine confirms, with entropy $0.9248$ bits. The mixing pulled
   the reduced state closer to $I/2$, and closer to $I/2$ means higher
   entropy, full stop. It got there by adding classical randomness, not by
   adding correlation.

   So $S(\rho_A)$ for a mixed global state is a sum of two things it cannot
   separate: uncertainty about qubit A because it is entangled with B, and
   uncertainty about qubit A because the preparation was already a
   classical mixture. Here the first component went down, as the noise
   diluted the entangled fraction, and the second went up by more, so the
   total rose. Lesson 7's $I/4$ case is the extreme version of the same
   effect, where the first component is zero and the reading is still a
   full bit.

   The engine enforces the distinction rather than leaving it to the
   reader, which is worth noticing as design. `entanglementEntropy` and
   `concurrenceOfPureState` both require a `StateVector` and so cannot be
   called on $\rho_{\text{noisy}}$ at all, while `vonNeumannEntropy` on the
   reduced $2\times2$ state runs happily and returns $0.9248$. The number
   is correct; only its interpretation as entanglement is unavailable, and
   the type system is what stops you from claiming otherwise.

   The wrong turn is concluding that noise increased the entanglement, or
   that the $0.8813$ figure was wrong. Both numbers are right about their
   own questions. What is wrong is comparing them as though they answered
   the same one, and the general lesson is that a formula's validity
   conditions are part of the formula.

   </details>

## Summary

- Every tool in this course (density matrix, partial trace, purity,
  entropy, concurrence, CHSH) applies cleanly to a single unfamiliar
  entangled state with a nontrivial phase, agreeing on a consistent
  physical picture.
- Reduced-state tools (`purity`, `vonNeumannEntropy` on a $2\times2$
  reduced matrix) work on any valid density matrix, pure or mixed;
  entanglement-measure tools (`entanglementEntropy`,
  `concurrenceOfPureState`) require a pure global `StateVector` by their
  very type signature.
- Attempting `vonNeumannEntropy` on a full $4\times4$ mixed global state
  throws, an engine-enforced boundary at the dimension where this
  platform's closed-form eigensolver stops.
- A strongly (but not maximally) entangled state gives a real (but
  weaker than $2\sqrt2$) CHSH violation. Concurrence and entanglement
  entropy agree quantitatively with each other; CHSH agrees on the
  verdict and not on the number, because it also depends on the
  measurement axes and on a relative phase the other two ignore.
