## The smallest thing that catches one flip

Bit flips happen. This lesson builds the smallest code that catches one: a
single $X$ error on any of three <Term id="physical-qubit">physical qubits</Term>, detected and reversed.

Notice what it will need, and what it will not. CNOT and partial
measurement, both built and tested in earlier courses. No new gate, no new
postulate, nothing this track has not already derived. The whole content
of the code is *which* qubits get connected to which, and that is what the
circuit below encodes.

Here is the entire scheme in one picture. The first two CNOTs spread one
logical qubit across three physical ones; the next four write two parity
checks into a pair of ancillas; then only the ancillas are measured.

## Encode, extract a syndrome, decode, correct

### Encoding

Starting from a single <Term id="logical-qubit">logical qubit</Term> $\alpha|0\rangle+\beta|1\rangle$ on
qubit 0, with two fresh qubits at $|0\rangle$:

$$
(\alpha|0\rangle+\beta|1\rangle)|00\rangle = \alpha|000\rangle+\beta|100\rangle \xrightarrow{\text{CNOT}(0,1)} \alpha|000\rangle+\beta|110\rangle \xrightarrow{\text{CNOT}(0,2)} \alpha|000\rangle+\beta|111\rangle
$$

Each CNOT copies qubit 0's value into a fresh qubit, not cloning the
*superposition* (which <Term id="no-cloning-theorem">no-cloning</Term> forbids), only entangling the fresh
qubits' computational-basis value with qubit 0's, term by term. The
result, $\alpha|000\rangle+\beta|111\rangle$, is `encodeBitFlipCode`'s
exact output.

### The syndrome

Append two ancilla qubits (indices 3,4), and extract two parities via
CNOTs into them: $\text{CNOT}(0,3),\text{CNOT}(1,3)$ puts qubit 0
$\oplus$ qubit 1's value onto ancilla 3; $\text{CNOT}(1,4),\text{CNOT}(2,4)$
puts qubit 1 $\oplus$ qubit 2's value onto ancilla 4. For the *unerrored*
codeword both parities are $0$, since all three data bits agree in each
term of the superposition. Measuring the two ancillas (a real partial
measurement, via `measureQubit`, as built in Quantum Gates & Circuits)
gives a **syndrome** $(s_1,s_2)$ without measuring the three data qubits.

### The decode table

If a single $X$ error hit exactly one data qubit, exactly the parities
involving that qubit flip:

| Syndrome $(s_1,s_2)$ | Error location |
|---|---|
| $(0,0)$ | none |
| $(1,0)$ | qubit 0 |
| $(1,1)$ | qubit 1 |
| $(0,1)$ | qubit 2 |

`decodeBitFlipSyndrome` implements exactly this table. Applying $X$ to
the indicated qubit (or nothing, for $(0,0)$) restores the original
encoded state exactly, verified directly for every one of the four
cases, on an arbitrary $\alpha,\beta$, not just checked once.

### Why this doesn't collapse the logical information

The syndrome depends only on whether data qubits *agree*, never on their
individual values. Both $|000\rangle$ and $|111\rangle$ give syndrome
$(0,0)$, so measuring it reveals nothing about whether the state leans
toward $|000\rangle$ or $|111\rangle$, which is to say nothing about
$\alpha$ versus $\beta$.

That is the whole trick, and it is worth stating as a general principle:
a measurement extracts only what its outcomes distinguish. Design the
measurement so the outcomes are identical across the branches you want to
protect, and the protected structure survives.

## Three qubits doing what one cannot

Three physical qubits, entangled, do what no single qubit can: hold one
logical qubit's information so that a bit flip on any one of the three is
both detectable and reversible, with nobody ever looking at the protected
superposition.

The cost is visible in the same sentence. Three physical qubits for one
logical one, plus two ancillas, to survive one error of one type. That
ratio is the reason fault tolerance is expensive, and it gets worse before
it gets better.

## Tracing an error on the middle qubit

**Trace the correction cycle for an $X$ error on qubit 1.**

Encoded state: $\alpha|000\rangle+\beta|111\rangle$. After $X$ on qubit 1:
$\alpha|010\rangle+\beta|101\rangle$. Syndrome extraction: ancilla 3
picks up qubit0$\oplus$qubit1 $=0\oplus1=1$ for both terms (checking
$|010\rangle$: $0\oplus1=1$; $|101\rangle$: $1\oplus0=1$), so syndrome bit
$s_1=1$ with certainty. Ancilla 4 picks up qubit1$\oplus$qubit2
$=1\oplus0=1$ (both terms again), so $s_2=1$. Syndrome $(1,1)\to$ qubit 1,
matching the decode table exactly. Applying $X$ to qubit 1 gives back
$\alpha|000\rangle+\beta|111\rangle$, the original encoded state,
confirmed by direct engine computation to floating-point precision.

## Measuring the data destroys the data

<Callout type="warning">
**Measuring the data qubits directly to check for errors.** That collapses
$\alpha|000\rangle+\beta|111\rangle$ onto $|000\rangle$ or $|111\rangle$
and destroys the encoded superposition, which is the failure mode syndrome
extraction exists to avoid.
</Callout>

<Callout type="warning">
**Expecting this code to correct a phase-flip ($Z$) error.** It doesn't.
A $Z$ error on any data qubit leaves every parity unchanged (the
relative sign between $|000\rangle$ and $|111\rangle$ isn't something
$Z_0Z_1$ or $Z_1Z_2$-style parity checks detect), so this code is silent
to it. The next lesson builds the code that catches this case, and the one
after that combines the two.
</Callout>

## Practice Questions

1. Trace the correction cycle for an $X$ error on qubit 0, computing both
   syndrome bits from the actual computational-basis terms.

   <details className="answer-reveal">
   <summary>Answer</summary>

   The syndrome comes out $(1,0)$, the table points at qubit 0, and
   applying $X_0$ returns the state exactly.

   Start from the encoded state and flip the leftmost bit of every term,
   since qubit 0 is the most significant position:

   $$
   \alpha|000\rangle+\beta|111\rangle
   \;\xrightarrow{\;X_0\;}\;
   \alpha|100\rangle+\beta|011\rangle.
   $$

   Ancilla 3 carries $q_0\oplus q_1$. On $|100\rangle$ that is
   $1\oplus0=1$; on $|011\rangle$ it is $0\oplus1=1$. Ancilla 4 carries
   $q_1\oplus q_2$. On $|100\rangle$ that is $0\oplus0=0$; on
   $|011\rangle$ it is $1\oplus1=0$. So $s_1=1$ and $s_2=0$.

   Both branches agreeing is not a coincidence and it is the reason the
   whole scheme is safe. $X_0$ flips the same bit in both terms, so it
   changes both parities in the same way, and the two ancillas come out
   $(1,0)$ with probability $1$ rather than at random. An outcome that
   was certain before the measurement carries no information about
   $\alpha$ and $\beta$, and a measurement that learns nothing about a
   degree of freedom cannot collapse it.

   The decode table sends $(1,0)$ to qubit 0. Apply $X_0$ again and, since
   $X^2=I$ on each branch,

   $$
   \alpha|100\rangle+\beta|011\rangle
   \;\xrightarrow{\;X_0\;}\;
   \alpha|000\rangle+\beta|111\rangle,
   $$

   the original encoded state with $\alpha$ and $\beta$ untouched. Note
   that the recovery was chosen without knowing either of them, which is
   the property that makes this a code rather than a repair of one
   particular state.

   </details>

2. Trace the correction cycle for an $X$ error on qubit 2.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Syndrome $(0,1)$, correction $X_2$.

   $$
   \alpha|000\rangle+\beta|111\rangle
   \;\xrightarrow{\;X_2\;}\;
   \alpha|001\rangle+\beta|110\rangle.
   $$

   Ancilla 3 reads $q_0\oplus q_1$: $0\oplus0=0$ on the first term,
   $1\oplus1=0$ on the second, so $s_1=0$. Ancilla 4 reads
   $q_1\oplus q_2$: $0\oplus1=1$ and $1\oplus0=1$, so $s_2=1$. The table
   sends $(0,1)$ to qubit 2, and $X_2$ restores
   $\alpha|000\rangle+\beta|111\rangle$.

   Placed beside the other two traces, the table stops looking like a
   list to memorize. Qubit 0 sits in only the first check, so it moves
   only $s_1$. Qubit 2 sits in only the second check, so it moves only
   $s_2$. Qubit 1 sits in both, so it moves both. Three distinguishable
   patterns, plus $(0,0)$ for no error, and two ancillas are exactly
   enough. That "exactly" is also a warning: with all four syndrome
   values already spoken for, the code has no capacity left for anything
   heavier, which is what question 4 runs into.

   </details>

3. Explain why the syndrome for a $Z$-error case would come out $(0,0)$,
   "no error detected," even though an error actually occurred (a
   concrete illustration of the phase-flip warning just above).

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because the ancillas read bit values, and a $Z$ error changes no bit
   value. It changes a sign.

   $Z|0\rangle=|0\rangle$ and $Z|1\rangle=-|1\rangle$, so applying $Z$ to
   qubit 0 leaves $|000\rangle$ alone and sends $|111\rangle$ to
   $-|111\rangle$:

   $$
   \alpha|000\rangle+\beta|111\rangle
   \;\xrightarrow{\;Z_0\;}\;
   \alpha|000\rangle-\beta|111\rangle.
   $$

   Every term still has three agreeing bits. $q_0\oplus q_1=0$ and
   $q_1\oplus q_2=0$ in both branches, so the syndrome is $(0,0)$ with
   certainty and the recovery step correctly concludes, from the
   information it has, that there is nothing to do.

   Nothing has been repaired, though. Take $\alpha=\beta=1/\sqrt2$: the
   state was the logical $|+\rangle$ and is now the logical $|-\rangle$,
   which is orthogonal to it. That is the largest error a single logical
   qubit can suffer, and the code cannot see it at all.

   It is worth being precise about what this costs the code, because the
   usual shorthand overstates its strength. Against $X$ errors alone the
   three-qubit code has distance 3: it takes three flips to move one
   codeword to another. As a general quantum code, which is what a
   distance figure normally means, its distance is $1$, because $Z_0$ is a
   weight-1 operator that commutes with both stabilizers and still acts
   nontrivially on the encoded state. One qubit's worth of the wrong kind
   of noise defeats it. The next lesson fixes the blind spot by rotating
   the basis, and the one after that stacks the two constructions so that
   neither blind spot survives.

   </details>

4. What happens to this code's guarantee if $X$ errors occur
   simultaneously on *two* different data qubits, rather than just one?
   (Hint: compute the resulting syndrome and check whether it matches any
   single-qubit entry in the decode table.)

   <details className="answer-reveal">
   <summary>Answer</summary>

   The guarantee is gone, and the failure is not a shrug but an own goal:
   the code reliably converts a two-qubit error into a complete logical
   bit flip.

   Each syndrome bit is a parity, so a check whose two qubits are *both*
   hit flips twice and reads as clean. Take the three cases in turn,
   reading the parities off the first branch (the second gives the same
   answer, as always):

   | Error | Corrupted state | $s_1=q_0\oplus q_1$ | $s_2=q_1\oplus q_2$ | Table says | Net operator applied |
   |---|---|---|---|---|---|
   | $X_0X_1$ | $\alpha\vert110\rangle+\beta\vert001\rangle$ | $1\oplus1=0$ | $1\oplus0=1$ | qubit 2 | $X_0X_1X_2$ |
   | $X_0X_2$ | $\alpha\vert101\rangle+\beta\vert010\rangle$ | $1\oplus0=1$ | $0\oplus1=1$ | qubit 1 | $X_0X_1X_2$ |
   | $X_1X_2$ | $\alpha\vert011\rangle+\beta\vert100\rangle$ | $0\oplus1=1$ | $1\oplus1=0$ | qubit 0 | $X_0X_1X_2$ |

   Every weight-2 error impersonates the weight-1 error on the one qubit
   it did not touch, so the recovery obligingly flips that qubit too, and
   the register ends up with all three flipped:

   $$
   X_0X_1X_2\big(\alpha|000\rangle+\beta|111\rangle\big)
   = \alpha|111\rangle+\beta|000\rangle.
   $$

   That is the logical $X$. The syndrome afterwards is $(0,0)$, so the
   code reports success on a state whose logical bit has been flipped.

   The tempting wrong turn is to read this as a decoder bug that a
   cleverer table would fix. It is not. Two ancillas give four syndromes
   and there are already four things to distinguish, so the three
   weight-2 errors have nowhere to go. $X_0X_1$ and $X_2$ produce
   *identical* syndromes, so no rule reading only $(s_1,s_2)$ can tell
   them apart, and the states they leave behind are not identical:
   $X_2$ gives $\alpha|001\rangle+\beta|110\rangle$ while $X_0X_1$ gives
   $\alpha|110\rangle+\beta|001\rangle$, the same two terms with
   $\alpha$ and $\beta$ exchanged. The two differ by exactly $X_0X_1X_2$,
   the logical $X$, which is why guessing wrong here is not a small
   error but the largest one available. The decoder's
   choice of $X_2$ is the right one, in fact, in the sense that it is the
   more likely explanation whenever single flips are more common than
   double flips. It is a maximum-likelihood guess that is sometimes
   wrong.

   That last observation is worth following one step further, because it
   is the seed of the whole threshold story. Take flips to be
   independent with probability $p$ per data qubit, and take the
   syndrome extraction and the recovery gate to be free of error
   themselves, which is the assumption doing the most work here. Then
   the code fails when two or three qubits flip:

   $$
   P_{\text{fail}} = 3p^2(1-p)+p^3 = 3p^2-2p^3.
   $$

   Compare that to the bare qubit's $p$. The encoding helps exactly when
   $3p^2-2p^3<p$, which rearranges to $(2p-1)(p-1)>0$ and so to
   $p<\tfrac12$. Below that crossover, redundancy buys you something.
   Above it, you have added more places for errors to happen than the
   code can repair, and encoding makes the qubit worse. The capstone
   lesson takes this shape and calls it a threshold, with one warning
   attached: a real threshold sits orders of magnitude lower than
   $\tfrac12$, because there the checking circuitry is faulty too, and
   the crossover arrives as soon as the checks inject errors faster than
   they remove them.

   </details>

## Summary

- Encoding: two CNOTs turn $\alpha|0\rangle+\beta|1\rangle$ into
  $\alpha|000\rangle+\beta|111\rangle$.
- Syndrome extraction uses two ancilla qubits and an actual partial
  measurement; the data qubits' superposition is never directly touched.
- The 4-entry decode table identifies which (if any) qubit had an $X$
  error; applying $X$ to that qubit exactly restores the original state,
  verified for every case, not merely argued.
- This code is silent to $Z$ errors entirely, a real, documented
  limitation the next lesson's dual code addresses.
