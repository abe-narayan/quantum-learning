## Motivation

Bit flips happen. This lesson builds the smallest code that catches one: a
single $X$ error on any of three <Term id="physical-qubit">physical qubits</Term>, detected and reversed.

Notice what it will need, and what it will not. CNOT and partial
measurement, both built and tested in earlier courses. No new gate, no new
postulate, nothing this pillar has not already derived. The whole content
of the code is *which* qubits get connected to which, and that is what the
circuit below encodes.

Here is the entire scheme in one picture. The first two CNOTs spread one
logical qubit across three physical ones; the next four write two parity
checks into a pair of ancillas; then only the ancillas are measured.

## Mathematical Development

### Encoding

Starting from a single <Term id="logical-qubit">logical qubit</Term> $\alpha|0\rangle+\beta|1\rangle$ on
qubit 0, with two fresh qubits at $|0\rangle$:

$$
(\alpha|0\rangle+\beta|1\rangle)|00\rangle = \alpha|000\rangle+\beta|100\rangle \xrightarrow{\text{CNOT}(0,1)} \alpha|000\rangle+\beta|110\rangle \xrightarrow{\text{CNOT}(0,2)} \alpha|000\rangle+\beta|111\rangle
$$

Each CNOT copies qubit 0's value into a fresh qubit, not cloning the
*superposition* (which <Term id="no-cloning-theorem">no-cloning</Term> forbids), only entangling the fresh
qubits' computational-basis value with qubit 0's, term by term. The
result, $\alpha|000\rangle+\beta|111\rangle$, is `encodeBitFlipCode`'s
exact output.

### The syndrome

Append two ancilla qubits (indices 3,4), and extract two parities via
CNOTs into them: $\text{CNOT}(0,3),\text{CNOT}(1,3)$ puts qubit 0
$\oplus$ qubit 1's value onto ancilla 3; $\text{CNOT}(1,4),\text{CNOT}(2,4)$
puts qubit 1 $\oplus$ qubit 2's value onto ancilla 4. For the *unerrored*
codeword both parities are $0$, since all three data bits agree in each
term of the superposition. Measuring the two ancillas (a real partial
measurement, via `measureQubit`, as built in Quantum Gates & Circuits)
gives a **syndrome** $(s_1,s_2)$ without measuring the three data qubits.

### The decode table

If a single $X$ error hit exactly one data qubit, exactly the parities
involving that qubit flip:

| Syndrome $(s_1,s_2)$ | Error location |
|---|---|
| $(0,0)$ | none |
| $(1,0)$ | qubit 0 |
| $(1,1)$ | qubit 1 |
| $(0,1)$ | qubit 2 |

`decodeBitFlipSyndrome` implements exactly this table. Applying $X$ to
the indicated qubit (or nothing, for $(0,0)$) restores the original
encoded state exactly, verified directly for every one of the four
cases, on an arbitrary $\alpha,\beta$, not just checked once.

### Why this doesn't collapse the logical information

The syndrome depends only on whether data qubits *agree*, never on their
individual values. Both $|000\rangle$ and $|111\rangle$ give syndrome
$(0,0)$, so measuring it reveals nothing about whether the state leans
toward $|000\rangle$ or $|111\rangle$, which is to say nothing about
$\alpha$ versus $\beta$.

That is the whole trick, and it is worth stating as a general principle:
a measurement extracts only what its outcomes distinguish. Design the
measurement so the outcomes are identical across the branches you want to
protect, and the protected structure survives.

## Physical Interpretation

Three physical qubits, entangled, do what no single qubit can: hold one
logical qubit's information so that a bit flip on any one of the three is
both detectable and reversible, with nobody ever looking at the protected
superposition.

The cost is visible in the same sentence. Three physical qubits for one
logical one, plus two ancillas, to survive one error of one type. That
ratio is the reason fault tolerance is expensive, and it gets worse before
it gets better.

## Worked Example

**Trace the correction cycle for an $X$ error on qubit 1.**

Encoded state: $\alpha|000\rangle+\beta|111\rangle$. After $X$ on qubit 1:
$\alpha|010\rangle+\beta|101\rangle$. Syndrome extraction: ancilla 3
picks up qubit0$\oplus$qubit1 $=0\oplus1=1$ for both terms (checking
$|010\rangle$: $0\oplus1=1$; $|101\rangle$: $1\oplus0=1$), so syndrome bit
$s_1=1$ with certainty. Ancilla 4 picks up qubit1$\oplus$qubit2
$=1\oplus0=1$ (both terms again), so $s_2=1$. Syndrome $(1,1)\to$ qubit 1,
matching the decode table exactly. Applying $X$ to qubit 1 gives back
$\alpha|000\rangle+\beta|111\rangle$, the original encoded state,
confirmed by direct engine computation to floating-point precision.

## Common Mistakes

<Callout type="warning">
**Measuring the data qubits directly to check for errors.** That collapses
$\alpha|000\rangle+\beta|111\rangle$ onto $|000\rangle$ or $|111\rangle$
and destroys the encoded superposition, which is the failure mode syndrome
extraction exists to avoid.
</Callout>

<Callout type="warning">
**Expecting this code to correct a phase-flip ($Z$) error.** It doesn't.
A $Z$ error on any data qubit leaves every parity unchanged (the
relative sign between $|000\rangle$ and $|111\rangle$ isn't something
$Z_0Z_1$ or $Z_1Z_2$-style parity checks detect), so this code is silent
to it. The next lesson builds the code that catches this case, and the one
after that combines the two.
</Callout>

## Summary

- Encoding: two CNOTs turn $\alpha|0\rangle+\beta|1\rangle$ into
  $\alpha|000\rangle+\beta|111\rangle$.
- Syndrome extraction uses two ancilla qubits and an actual partial
  measurement; the data qubits' superposition is never directly touched.
- The 4-entry decode table identifies which (if any) qubit had an $X$
  error; applying $X$ to that qubit exactly restores the original state,
  verified for every case, not merely argued.
- This code is silent to $Z$ errors entirely, a real, documented
  limitation the next lesson's dual code addresses.
