## Motivation

The target is a Bell state, built originally in the Quantum Gates &
Circuits course. There is no new physics in this lesson. It runs this
course's machinery end to end on a system you already know, which is the
best way to find out whether the machinery makes sense to you.

## Intuition

$\hat Z$ on a single qubit has two nondegenerate eigenvalues, no
degeneracy to worry about. Move to *two* qubits, and an <Term id="observable">observable</Term> that
only looks at *one* of them ($\hat Z$ on qubit 0, ignoring qubit 1
entirely) automatically becomes degenerate on the 4-dimensional combined
space: two different values of qubit 1 give the *same* eigenvalue. The
degeneracy arises here for the most ordinary reason there is, an
observable that ignores part of the system, rather than from a contrived
construction.

## Mathematical Development

### Building the observables

Let $Z_0=Z\otimes I$ (Pauli-$Z$ on qubit 0, identity on qubit 1) and
$Z_1=I\otimes Z$ (identity on qubit 0, Pauli-$Z$ on qubit 1), both
constructed directly via this platform's existing `Matrix.tensor()`, no
new engine code needed. Their eigenvalues on the four basis states:

| State | $Z_0$ | $Z_1$ |
|---|---|---|
| $\lvert00\rangle$ | $+1$ | $+1$ |
| $\lvert01\rangle$ | $+1$ | $-1$ |
| $\lvert10\rangle$ | $-1$ | $+1$ |
| $\lvert11\rangle$ | $-1$ | $-1$ |

$Z_0$ alone is degenerate ($+1$ on both $|00\rangle,|01\rangle$); so is
$Z_1$. But the *pair* $(Z_0,Z_1)$ gives four distinct tuples, a CSCO for
this space, of the kind Complete Sets of Commuting Observables described
abstractly.

Written out as matrices, both operators are diagonal, and the degeneracy
is visible as repeated entries down the diagonal:

/>

Each matrix repeats each of its two eigenvalues twice, which is the
degeneracy stated in numbers: $Z_0$ cannot tell $|00\rangle$ from
$|01\rangle$, because it assigns them the same diagonal entry. What makes
the pair complete is that they repeat in *different patterns*, $(+,+,-,-)$
against $(+,-,+,-)$, so reading both diagonals down together gives four
distinct labels.

### Why they commute

Operators acting on *different* tensor factors always commute: using
$(A\otimes B)(C\otimes D)=(AC)\otimes(BD)$,

$$
Z_0Z_1 = (Z\otimes I)(I\otimes Z) = (ZI)\otimes(IZ) = Z\otimes Z = (IZ)\otimes(ZI) = (I\otimes Z)(Z\otimes I) = Z_1Z_0
$$

so $[Z_0,Z_1]=0$, confirmed by computation rather than asserted. Nothing
in that line used any property of $Z$: $A\otimes I$ and $I\otimes B$
commute for *any* $A,B$, because they act on independent subsystems.

### Measuring $Z_0$ on an entangled state

Take the Bell state $|\Phi^+\rangle=\tfrac{1}{\sqrt2}(|00\rangle+
|11\rangle)$. In amplitude order $(|00\rangle,|01\rangle,|10\rangle,
|11\rangle)$, this is $\left(\tfrac1{\sqrt2},0,0,\tfrac1{\sqrt2}\right)$.
$Z_0$'s eigenvalue $+1$ projector is $P_+=\mathrm{projectorOntoSubspace}
(\{|00\rangle,|01\rangle\})$ (degenerate, spans two basis states). By
the generalized <Term id="born-rule">Born rule</Term>,

$$
P(Z_0{=}{+}1) = \left|\frac1{\sqrt2}\right|^2 + |0|^2 = \frac12
$$

Suppose the outcome is $+1$. $P_+|\Phi^+\rangle$ keeps only the
$|00\rangle,|01\rangle$ components: $\left(\tfrac1{\sqrt2},0,0,0\right)$,
which, already <Term id="normalization">normalized</Term>, collapses to exactly $|00\rangle$.

On the now-collapsed $|00\rangle$, $Z_1$'s eigenvalue is $+1$ with
**certainty** ($|00\rangle$ is already a $Z_1$-eigenstate). The full pair
$(Z_0,Z_1)=(+1,+1)$ now uniquely identifies the state as $|00\rangle$,
which is the CSCO machinery of this course doing on a real two-qubit
state what the abstract argument said it would.

## Physical Interpretation

This *is* the Bell state's famous perfect correlation, seen through this
course's formalism instead of asserted as a special fact: measuring
qubit 0 as $0$ forces qubit 1 to also be $0$, because the only
$|\Phi^+\rangle$-component consistent with $Z_0{=}{+}1$ is $|00\rangle$.
There is no $|01\rangle$ component in $|\Phi^+\rangle$ at all. The
"spooky" correlation from Bell States and Entanglement is this lesson's
projector-and-collapse mechanics applied to an entangled input, with no
extra ingredient.

## Worked Example

**Suppose the $Z_0$ outcome had instead been $-1$. What state results,
and what does $Z_1$ then give with certainty?**

$P_-$ keeps the $|10\rangle,|11\rangle$ components of $|\Phi^+\rangle$:
only $|11\rangle$ is present, so the state collapses to $|11\rangle$
directly. Measuring $Z_1$ on $|11\rangle$ then gives $-1$ with certainty,
the two qubits are again perfectly correlated ($Z_0=Z_1=-1$ this time),
consistent with $|\Phi^+\rangle$ containing only the $|00\rangle$ and
$|11\rangle$ terms.

## Common Mistakes

<Callout type="note">
**Thinking $Z_0$ and $Z_1$ commuting is special to the Bell state.**
It's a property of the *operators* ($A\otimes I$ vs. $I\otimes B$),
independent of which state they're applied to. The Bell state is an
interesting *input* to observables that were already compatible before it
arrived.
</Callout>

<Callout type="warning">
**Expecting $Z_0$ alone to fully determine the state.** It's degenerate
on this 4-dimensional space by construction. Only the *pair*
$(Z_0,Z_1)$ is a complete set here.
</Callout>

## Summary

- $Z_0=Z\otimes I$ and $Z_1=I\otimes Z$ each have degenerate eigenvalues
  alone, but form a complete set of commuting observables together.
- Operators on different tensor factors always commute, a general,
  directly-verified fact, not specific to this example.
- Measuring $Z_0$ on the Bell state $|\Phi^+\rangle$ and collapsing gives
  exactly the correlated outcome Bell States and Entanglement already
  described qualitatively, now derived from this course's own
  machinery.
