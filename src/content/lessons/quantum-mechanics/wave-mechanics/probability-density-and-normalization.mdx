## Intuition

$|\psi(x)|^2$ is a probability density exactly like a mass density or a
population density: to get an actual probability (a plain number between
0 and 1), you integrate the density over a region. The *total* probability
integrated over all of space must be exactly 1, because the particle is
*somewhere* with certainty.

## Mathematical Development

### Normalization

$$
\int_{-\infty}^{\infty} |\psi(x)|^2\,dx = 1
$$

Any function with finite $\int|\psi|^2\,dx = N < \infty$ can be
normalized: replace $\psi \to \psi/\sqrt{N}$, since
$\int|\psi/\sqrt N|^2 dx = (1/N)\int|\psi|^2 dx = N/N = 1$.

### Probability of a region

The probability of finding the particle in $[a,b]$ is

$$
P(a \le x \le b) = \int_a^b |\psi(x)|^2\,dx
$$

which is literally what `Wavefunction1D.probabilityDensity()` returns
pointwise, summed (as a Riemann sum, `probability * dx`) over the
relevant grid points. This platform's `probabilityLeftAndRightOf`
function used by the Wavefunction Explorer's <Term id="quantum-tunneling">tunneling</Term> comparison is
exactly this integral, split at the barrier.

### Why normalization survives time evolution

This is not a separate assumption. It's forced by the dynamics postulate.
Time evolution is $|\psi(t)\rangle = U(t)|\psi(0)\rangle$ for a <Term id="unitary-operator">unitary</Term>
$U(t)$ (derived from Hermiticity of $H$ in the Time Evolution lesson of the
last course, and reproven directly for position space two lessons ahead).
Unitary operators preserve inner products exactly:

$$
\langle\psi(t)|\psi(t)\rangle = \langle\psi(0)|U^\dagger(t)U(t)|\psi(0)\rangle = \langle\psi(0)|\psi(0)\rangle = 1
$$

using $U^\dagger U = I$. So if $\psi(0)$ starts normalized, it is
*exactly* normalized at every later time: not approximately, not on
average, exactly. The Wavefunction Explorer's split-operator time
evolution is built from three factors that are each individually a pure
phase (multiplication by a unit-modulus number, either pointwise in
position space or via a unitary Fourier transform), so the simulator's
`Norm ‖ψ‖` readout staying at $1.0000$ for as long as you let it run isn't
a coincidence or good luck. It's this unitarity theorem, holding to
floating-point precision.

## Physical Interpretation

Norm conservation is probability conservation: the particle doesn't
appear or disappear, get created or destroyed, as time passes. Any
numerical method that lets the norm drift is quietly violating this, one
of the reasons the split-operator method (built from exact-phase factors)
is the right tool, rather than say a naive explicit finite-difference
scheme, which does not automatically preserve norm and can even blow up.

## Worked Example

**$\psi(x) = A\,e^{-x^2/(2\sigma^2)}$ for a real constant $\sigma$. Find
$A$, and find $P(-\sigma \le x \le \sigma)$.**

$\int_{-\infty}^{\infty} e^{-x^2/\sigma^2}\,dx = \sigma\sqrt{\pi}$ (a
standard Gaussian integral), so normalization requires
$|A|^2\sigma\sqrt\pi = 1$, giving $A = (\pi\sigma^2)^{-1/4}$. The region
probability $P(-\sigma\le x\le\sigma) = \int_{-\sigma}^{\sigma}|\psi|^2 dx$
evaluates (numerically, via the standard normal CDF) to
$\mathrm{erf}(1) \approx 0.843$: $|\psi(x)|^2\propto e^{-x^2/\sigma^2}$ has
standard deviation $\sigma/\sqrt2$, not $\sigma$, so integrating out to
$\pm\sigma$ covers $\pm\sqrt2$ standard deviations rather than $\pm1$,
here computed from an actual quantum probability
density rather than pulled from a statistics table.

## Common Mistakes

<Callout type="warning">
**Forgetting to square before integrating.** Normalization uses
$|\psi(x)|^2$, not $\psi(x)$. For a complex $\psi$, that's
$\psi(x)^*\psi(x)$, not $\psi(x)^2$.
</Callout>

<Callout type="warning">
**Assuming any function can be normalized.** If $\int|\psi|^2 dx$
diverges (e.g. $\psi(x)=1$ for all $x$, a plane wave), no rescaling fixes
it. Such states aren't literally normalizable and require special
handling (briefly touched on in the Free-Particle Wave Packets lesson).
</Callout>

## Summary

- $\int|\psi(x)|^2 dx = 1$ is normalization; $\int_a^b|\psi(x)|^2 dx$ is
  the probability of being found in $[a,b]$.
- Any wavefunction with finite $\int|\psi|^2 dx$ can be normalized by
  rescaling.
- Unitary time evolution preserves the <Term id="inner-product">inner product</Term> exactly, so a
  normalized state stays normalized forever: a theorem, not an
  approximation, and one the simulator's exact norm conservation
  demonstrates directly.
