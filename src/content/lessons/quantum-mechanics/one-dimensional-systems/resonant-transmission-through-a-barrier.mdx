export const resonanceEnergy = 5;
export const resonanceBarrierHeight = 2;
export const resonanceK2 = Math.sqrt(2 * (resonanceEnergy - resonanceBarrierHeight));
export const transmissionAt = (L) =>
  1 / (1 + (resonanceBarrierHeight ** 2 * Math.sin(resonanceK2 * L) ** 2) / (4 * resonanceEnergy * (resonanceEnergy - resonanceBarrierHeight)));

export const resonanceK1 = Math.sqrt(2 * resonanceEnergy);

export const cMul = (a, b) => [a[0] * b[0] - a[1] * b[1], a[0] * b[1] + a[1] * b[0]];
export const cDiv = (a, b) => [
  (a[0] * b[0] + a[1] * b[1]) / (b[0] * b[0] + b[1] * b[1]),
  (a[1] * b[0] - a[0] * b[1]) / (b[0] * b[0] + b[1] * b[1]),
];
export const cExp = (theta) => [Math.cos(theta), Math.sin(theta)];
export const cAbs2 = (a) => a[0] * a[0] + a[1] * a[1];
export const cConj = (a) => [a[0], -a[1]];
export const cScale = (s, a) => [s * a[0], s * a[1]];

export const barrierT = (L) =>
  cDiv(cExp(-resonanceK1 * L), [
    Math.cos(resonanceK2 * L),
    -((resonanceK1 ** 2 + resonanceK2 ** 2) / (2 * resonanceK1 * resonanceK2)) * Math.sin(resonanceK2 * L),
  ]);

export const barrierC = (L) =>
  cScale(0.5 * (1 + resonanceK1 / resonanceK2), cMul(barrierT(L), cExp((resonanceK1 - resonanceK2) * L)));

export const barrierD = (L) =>
  cScale(0.5 * (1 - resonanceK1 / resonanceK2), cMul(barrierT(L), cExp((resonanceK1 + resonanceK2) * L)));

export const barrierR = (L) => [barrierC(L)[0] + barrierD(L)[0] - 1, barrierC(L)[1] + barrierD(L)[1]];

export const barrierRegion1DensityAt = (x, L) =>
  1 + cAbs2(barrierR(L)) + 2 * (barrierR(L)[0] * Math.cos(2 * resonanceK1 * x) + barrierR(L)[1] * Math.sin(2 * resonanceK1 * x));

export const barrierRegion2DensityAt = (x, L) =>
  cAbs2(barrierC(L)) +
  cAbs2(barrierD(L)) +
  2 *
    (cMul(barrierC(L), cConj(barrierD(L)))[0] * Math.cos(2 * resonanceK2 * x) -
      cMul(barrierC(L), cConj(barrierD(L)))[1] * Math.sin(2 * resonanceK2 * x));

export const barrierRegion3DensityAt = (L) => cAbs2(barrierT(L));

export const barrierDensityAt = (x, L) =>
  x < 0 ? barrierRegion1DensityAt(x, L) : x <= L ? barrierRegion2DensityAt(x, L) : barrierRegion3DensityAt(L);

export const barrierPotentialAt = (x, L) => (x >= 0 && x <= L ? resonanceBarrierHeight : 0);

export const barrierWaveXValues = Array.from({ length: 281 }, (_, i) => -3 + (i / 280) * 8);
export const barrierWaveWidths = [0.5, 1.0, Math.PI / resonanceK2, 1.8, 2.2, (2 * Math.PI) / resonanceK2, 3.2];
export const barrierWaveFrames = barrierWaveWidths.map((L) => ({
  paramLabel: `L = ${L.toFixed(3)}`,
  xValues: barrierWaveXValues,
  potential: barrierWaveXValues.map((x) => barrierPotentialAt(x, L)),
  density: barrierWaveXValues.map((x) => barrierDensityAt(x, L)),
  markers: [
    { x: 0, label: "x = 0" },
    { x: L, label: "x = L" },
  ],
}));

## Above the barrier, where classical physics gets dull

Tunneling and the Finite Barrier covered $E<V_0$: a barrier taller than
the particle's energy, crossed only by the exponentially-suppressed
<Term id="quantum-tunneling">tunneling mechanism</Term>. Now turn the energy up past the top of the
barrier, to $E>V_0$, and ask what a particle with energy to spare does
with an obstacle it can plainly clear. Classically the question is dull:
all of it crosses, every time, and the barrier is no obstacle worth
mentioning. Quantum mechanics disagrees on both counts. At most energies
the barrier reflects part of the beam even though the particle "should"
sail over it. Then, at a specific and predictable sequence of energies,
the reflection vanishes *completely*: $T=1$, exactly, not approximately.
Why should a solid obstruction turn perfectly transparent at some
energies and stay partly reflective at all the others?

## The same three regions, one more boundary

A barrier with $E>V_0$ has the *same* three-region structure as the
step-potential problem, just with a third region (transmitted wave)
past a *second* boundary. The difference that matters: inside the
barrier the <Term id="wavefunction">wavefunction</Term> still **oscillates** (not decays, since
$E>V_0$ there means $k$ is real inside too), unlike the tunneling
case's exponential decay. Two boundaries also means two reflected waves,
one from entering the barrier and one from leaving it, and those two can
interfere with each other. Where they cancel, nothing reflects. That
cancellation is the resonance.

## The transmission formula, and where it hits one

### The three-region setup

Barrier of height $V_0$, full width $L$, spanning $0$ to $L$; particle
energy $E>V_0$. Inside the barrier, $k_2=\sqrt{2(E-V_0)}$ (real,
oscillatory, the key difference from tunneling's $\kappa=\sqrt{2(V_0-E)}$).
Matching $\psi,\psi'$ at *both* $x=0$ and $x=L$ (four equations, the same
kind of boundary-matching used for the step, just doubled) gives, after
elimination of every <Term id="amplitude">amplitude</Term> except the incident and transmitted ones,
the standard closed-form result (a longer algebraic exercise than the
single-step case, not repeated in full here):

$$
\boxed{\;T = \left[1 + \frac{V_0^2\sin^2(k_2L)}{4E(E-V_0)}\right]^{-1}\;}
$$

This platform's `barrierScatteringTransmission` function implements that
formula, tested against the $V_0\to0$ limit ($T\to1$, no barrier) and
against the resonance condition below.

The formula is worth reading before it is plotted. Only $L$ appears
inside a $\sin$, and only in the denominator.

### The resonance condition

$T=1$ exactly whenever $\sin(k_2L)=0$, i.e.

$$
k_2L = n\pi, \qquad n=1,2,3,\ldots
$$

At these special widths, the barrier is **perfectly transparent**:
every incident particle transmits and none reflects, despite the barrier
being, in every other sense, a real obstacle.

Sweeping barrier width
$L$ at fixed $E=5,V_0=2$ makes the oscillation, and the resonance peaks
hitting exactly $T=1$, directly visible:

Every peak touches exactly $1$, never overshooting, and the peaks repeat
with spacing $\pi/k_2\approx1.283$ in $L$, the periodicity
$\sin^2(k_2L)=0$ predicts. Read the troughs as well: at this energy they
only fall to $T=0.9375$, so a barrier well above which the particle is
travelling is a weak obstacle at every width, and the resonances are
sharpening a small effect rather than rescuing transmission from near
zero. Lower $E$ toward $V_0$ and the troughs deepen sharply, since the
$4E(E-V_0)$ in the denominator shrinks.

That $T(L)$ curve is the aggregate outcome. The mechanism behind each
peak is the standing wave $|\psi(x)|^2$ forms: oscillating for
$x<0$ from the incident and reflected waves interfering, oscillating
again *inside* the barrier from its own two boundary-matched
components, and flat past $x=L$ where only the transmitted wave
survives:

half-wavelengths, respectively, between $x=0$ and $x=L$, and the

doesn't close up evenly at $x=L$, and some ripple persists for $x<0$.

## The physics of an anti-reflective coating

This is the quantum-mechanical counterpart of an anti-reflective optical
coating. A thin film reflects light at both of its surfaces, and at
specific wavelengths those two reflections destructively interfere,
cancelling the net reflection. Here the two boundaries of the barrier
play the role of the film's two surfaces, and the resonance condition
$k_2L=n\pi$ is the same "round-trip phase is a multiple of $2\pi$"
condition that governs optical thin-film interference. Light and matter
agree here because both obey a wave equation matched across a boundary,
and neither derivation ever asked what kind of wave it was.

The effect is engineered on purpose. Resonant tunneling diodes (RTDs)
use a thin quantum well sandwiched between two barriers, engineered so
a transmission resonance sits at a specific electron energy. Applying a
voltage shifts that resonance relative to the incoming electrons: as
the bias increases, current first rises sharply as electrons sweep
through the resonance, then *drops* as the bias pushes past it, even
though the voltage keeps climbing. That drop is negative differential
resistance, a behavior no ordinary resistor has, and it makes RTDs
useful in high-frequency oscillators and fast switching circuits. The
device runs on the same physics as this lesson's single barrier, just
with two barriers instead of one and the resonance tuned electrically
instead of by sweeping $L$ by hand.

## The first resonant width at E = 5

**For $E=5$, $V_0=2$ (natural units), find the barrier width $L$ that
produces the first resonance, and confirm $T=1$ there.**

$$
k_2 = \sqrt{2(5-2)} = \sqrt6 \approx 2.4495
$$

First resonance ($n=1$): $L=\pi/k_2\approx1.2825$. Substituting into the
transmission formula, $\sin(k_2L)=\sin(\pi)=0$ exactly, so the
$\sin^2$ term vanishes and $T=1/[1+0]=1$, which this platform's test
suite for `barrierScatteringTransmission` asserts independently.
For comparison, at a *non*-resonant width like $L=1$: $k_2L\approx2.449$
(not a multiple of $\pi$), giving $T\approx0.9736$, still high (a
narrow barrier relative to the wavelength), but not exactly 1.

## Oscillating with width, rather than decaying

<Callout type="warning">
**Confusing this formula with the tunneling ($E<V_0$) case.** The
tunneling regime's transmission falls off roughly as $e^{-2\kappa L}$
(Tunneling and the Finite Barrier); this regime's oscillates with $L$
via $\sin^2(k_2L)$ and can reach exactly $1$, qualitatively different
behavior, because the wavefunction oscillates rather than decays inside
the barrier.
</Callout>

<Callout type="note">
**Thinking resonance requires fine-tuning both $E$ and $L$
independently.** For a *fixed* barrier ($V_0,L$ given), resonances occur
at a discrete, predictable sequence of *energies* $E$ satisfying
$k_2(E)L=n\pi$, an experimentally realistic, adjustable knob (scan the
incident particle's energy) rather than an impossible-to-achieve
coincidence.
</Callout>

## Practice Questions

1. For $E=6,V_0=3,L=1$, compute $T$ using the boxed formula. Then find
   the nearest resonant width for these $E$ and $V_0$, and say how far
   $L=1$ actually sits from it.

   <details className="answer-reveal">
   <summary>Answer</summary>

   $T\approx0.9516$, and the nearest resonance is at $L\approx1.2825$, so
   $L=1$ falls about $0.28$ short of it.

   Start with the wavenumber inside the barrier:

   $$
   k_2 = \sqrt{2(E-V_0)} = \sqrt{2(6-3)} = \sqrt6 \approx 2.44949
   $$

   At $L=1$ that gives $k_2L\approx2.44949$ radians, so
   $\sin(k_2L)\approx0.63823$ and $\sin^2(k_2L)\approx0.40734$. The
   prefactor is

   $$
   \frac{V_0^2}{4E(E-V_0)} = \frac{9}{4(6)(3)} = \frac{9}{72} = 0.125
   $$

   and therefore

   $$
   T = \left[1 + 0.125(0.40734)\right]^{-1} = \frac{1}{1.050918} \approx 0.95156
   $$

   matching the engine's `barrierScatteringTransmission(6, 3, 1)`.

   **Where the resonances are.** $T=1$ requires $\sin(k_2L)=0$, so
   $L_n = n\pi/k_2 = n\pi/\sqrt6 \approx 1.28255n$. The first sits at
   $L_1\approx1.2825$ and the second at $L_2\approx2.5651$. Our $L=1$ is
   $0.2825$ below the first, or equivalently $k_2L=2.449$ against the
   $\pi\approx3.142$ that resonance demands: about $78\%$ of the way
   there.

   That distance is why $T$ came out at $0.95$ rather than $1$, and it is
   also why $0.95$ is still high. Read the prefactor: $0.125$ is small, so
   even at the *worst* width, where $\sin^2=1$, transmission only falls to
   $1/1.125\approx0.889$. At this energy the barrier is a weak obstacle
   everywhere, and the resonance is sharpening an already-small effect.
   Push $E$ down toward $V_0$ and the $4E(E-V_0)$ in the denominator
   collapses, the prefactor blows up, and the troughs between resonances
   become deep.

   The slip to watch is evaluating $\sin(k_2L)$ in degrees. In radians
   $k_2L=2.449$ gives $\sin=0.638$; read as degrees it gives $0.043$, and
   $T$ comes out at $0.99977$, wrong in the fourth decimal and wrong in
   its reasoning. Every angle in this formula is a phase, and phases are
   radians.

   </details>

2. Find the *second* resonant width ($n=2$) for the $E=5,V_0=2$ example
   above, confirm $T=1$ there, and then say how the whole family of
   resonant widths would move if the barrier height were doubled to
   $V_0=4$ at the same energy.

   <details className="answer-reveal">
   <summary>Answer</summary>

   $L_2 = 2\pi/\sqrt6 \approx 2.5651$. Doubling $V_0$ to $4$ pushes every
   resonant width out to $L_n\approx2.2214n$, spacing them nearly $1.7$
   times further apart.

   For the original barrier, $k_2=\sqrt{2(5-2)}=\sqrt6\approx2.44949$ and
   the condition $k_2L=n\pi$ gives

   $$
   L_1 = \frac{\pi}{\sqrt6} \approx 1.28255, \qquad L_2 = \frac{2\pi}{\sqrt6} \approx 2.56510
   $$

   exactly twice the first, since the condition is linear in $n$.
   Confirming $T=1$: $\sin(k_2L_2)=\sin(2\pi)=0$ exactly, so the entire
   correction term in the denominator vanishes and $T=1/[1+0]=1$. The
   engine returns $1$ at both widths, not $0.999$: this is an exact
   cancellation, not a numerical near-miss.

   **Doubling the barrier height.** At $V_0=4$ with $E=5$ still,

   $$
   k_2 = \sqrt{2(5-4)} = \sqrt2 \approx 1.41421, \qquad L_n = \frac{n\pi}{\sqrt2} \approx 2.22144\,n
   $$

   so $L_1$ moves from $1.2825$ out to $2.2214$ and every later resonance
   moves with it. The reason is physical rather than algebraic: a taller
   barrier leaves the particle less kinetic energy inside it, so it
   travels more slowly there, so its wavelength inside is *longer*. The
   resonance condition asks the barrier to hold a whole number of half
   wavelengths, and a longer wavelength needs a wider barrier to fit one.

   Two consequences follow from the same reading.

   The spacing between consecutive resonances is $\pi/k_2$, independent of
   $n$: they are evenly spaced, all the way up, which is what the plot's
   uniform peaks show. It is the *scale* of that spacing that responds to
   $E$ and $V_0$, never its uniformity.

   And the resonances vanish entirely once $E<V_0$. Then $k_2$ turns
   imaginary, $\sin(k_2L)$ becomes $i\sinh(\kappa L)$, and the $\sin^2$
   in the denominator becomes a $\sinh^2$ that only ever grows. There are
   no zeros left, transmission decays monotonically, and the formula turns
   smoothly into the tunneling regime the Wave Mechanics course covered.
   One formula, two behaviours, with $E=V_0$ as the switch.

   </details>

3. Explain in one or two sentences why the resonance condition depends
   only on $k_2L$ (not on $V_0$ or $E$ separately). Connect this to the
   optical thin-film analogy's "round-trip phase" language. Then say what
   $V_0$ and $E$ *do* control in the formula, given that they plainly
   appear in it.

   <details className="answer-reveal">
   <summary>Answer</summary>

   Because resonance is the condition that the term $\sin^2(k_2L)$
   vanishes, and $E$ and $V_0$ reach that term only through the single
   combination $k_2L$: the phase the wave accumulates crossing the
   barrier once. $E$ and $V_0$ appear separately elsewhere in the formula,
   and what they control there is how *deep the troughs* between
   resonances get, never where the peaks sit.

   **The round-trip reading.** A wave crossing the barrier and reflecting
   back off the far boundary accumulates phase $2k_2L$ on the round trip.
   The two reflected waves, one from each boundary, cancel when that
   round-trip phase is a whole number of full turns, $2k_2L=2n\pi$, which
   is $k_2L=n\pi$. That is the same condition an anti-reflective coating
   is engineered to meet, and the derivation never asked what kind of wave
   it was: only that it obeys a wave equation and is matched across two
   boundaries. Light and electrons agree here for that reason rather than
   by analogy.

   **What $E$ and $V_0$ do control.** Look at where they sit:

   $$
   T = \left[1 + \frac{V_0^2\sin^2(k_2L)}{4E(E-V_0)}\right]^{-1}
   $$

   The prefactor $V_0^2/[4E(E-V_0)]$ multiplies the $\sin^2$, so it sets
   the *amplitude* of the oscillation without touching its zeros. At the
   troughs, where $\sin^2=1$, transmission dips to
   $[1+V_0^2/(4E(E-V_0))]^{-1}$, and that is the number the prefactor
   governs. For $E=5,V_0=2$ it is $0.9375$, a shallow trough; drive $E$
   toward $V_0$ and $4E(E-V_0)$ collapses, the prefactor diverges, and the
   troughs plunge toward zero while the peaks stay pinned at exactly $1$.
   That is the behaviour the lesson's own $V_0$-slider chart shows: the
   peak never degrades, only the transmission on either side of it does.

   So the formula separates cleanly into two jobs. $k_2L$ decides *where*
   the barrier is transparent, and $V_0^2/[4E(E-V_0)]$ decides *how much
   it matters* to be off resonance. The first is pure interference
   geometry; the second is the impedance mismatch inherited from the
   single-step problem.

   </details>

## Summary

- For $E>V_0$, transmission through a barrier is
  $T=[1+V_0^2\sin^2(k_2L)/(4E(E-V_0))]^{-1}$, oscillating with barrier
  width rather than decaying exponentially (the tunneling regime's
  behavior).
- $T=1$ exactly whenever $k_2L=n\pi$: perfect transmission at discrete
  resonant energies, directly analogous to anti-reflective optical
  coatings.
- This regime is the complement to Wave Mechanics' tunneling treatment.
  Together, $E<V_0$ and $E>V_0$ describe scattering off a rectangular
  barrier at every energy.
