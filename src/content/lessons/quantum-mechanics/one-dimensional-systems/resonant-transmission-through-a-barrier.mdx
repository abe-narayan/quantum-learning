export const resonanceEnergy = 5;
export const resonanceBarrierHeight = 2;
export const resonanceK2 = Math.sqrt(2 * (resonanceEnergy - resonanceBarrierHeight));
export const transmissionAt = (L) =>
  1 / (1 + (resonanceBarrierHeight ** 2 * Math.sin(resonanceK2 * L) ** 2) / (4 * resonanceEnergy * (resonanceEnergy - resonanceBarrierHeight)));

export const resonanceK1 = Math.sqrt(2 * resonanceEnergy);

export const cMul = (a, b) => [a[0] * b[0] - a[1] * b[1], a[0] * b[1] + a[1] * b[0]];
export const cDiv = (a, b) => [
  (a[0] * b[0] + a[1] * b[1]) / (b[0] * b[0] + b[1] * b[1]),
  (a[1] * b[0] - a[0] * b[1]) / (b[0] * b[0] + b[1] * b[1]),
];
export const cExp = (theta) => [Math.cos(theta), Math.sin(theta)];
export const cAbs2 = (a) => a[0] * a[0] + a[1] * a[1];
export const cConj = (a) => [a[0], -a[1]];
export const cScale = (s, a) => [s * a[0], s * a[1]];

export const barrierT = (L) =>
  cDiv(cExp(-resonanceK1 * L), [
    Math.cos(resonanceK2 * L),
    -((resonanceK1 ** 2 + resonanceK2 ** 2) / (2 * resonanceK1 * resonanceK2)) * Math.sin(resonanceK2 * L),
  ]);

export const barrierC = (L) =>
  cScale(0.5 * (1 + resonanceK1 / resonanceK2), cMul(barrierT(L), cExp((resonanceK1 - resonanceK2) * L)));

export const barrierD = (L) =>
  cScale(0.5 * (1 - resonanceK1 / resonanceK2), cMul(barrierT(L), cExp((resonanceK1 + resonanceK2) * L)));

export const barrierR = (L) => [barrierC(L)[0] + barrierD(L)[0] - 1, barrierC(L)[1] + barrierD(L)[1]];

export const barrierRegion1DensityAt = (x, L) =>
  1 + cAbs2(barrierR(L)) + 2 * (barrierR(L)[0] * Math.cos(2 * resonanceK1 * x) + barrierR(L)[1] * Math.sin(2 * resonanceK1 * x));

export const barrierRegion2DensityAt = (x, L) =>
  cAbs2(barrierC(L)) +
  cAbs2(barrierD(L)) +
  2 *
    (cMul(barrierC(L), cConj(barrierD(L)))[0] * Math.cos(2 * resonanceK2 * x) -
      cMul(barrierC(L), cConj(barrierD(L)))[1] * Math.sin(2 * resonanceK2 * x));

export const barrierRegion3DensityAt = (L) => cAbs2(barrierT(L));

export const barrierDensityAt = (x, L) =>
  x < 0 ? barrierRegion1DensityAt(x, L) : x <= L ? barrierRegion2DensityAt(x, L) : barrierRegion3DensityAt(L);

export const barrierPotentialAt = (x, L) => (x >= 0 && x <= L ? resonanceBarrierHeight : 0);

export const barrierWaveXValues = Array.from({ length: 281 }, (_, i) => -3 + (i / 280) * 8);
export const barrierWaveWidths = [0.5, 1.0, Math.PI / resonanceK2, 1.8, 2.2, (2 * Math.PI) / resonanceK2, 3.2];
export const barrierWaveFrames = barrierWaveWidths.map((L) => ({
  paramLabel: `L = ${L.toFixed(3)}`,
  xValues: barrierWaveXValues,
  potential: barrierWaveXValues.map((x) => barrierPotentialAt(x, L)),
  density: barrierWaveXValues.map((x) => barrierDensityAt(x, L)),
  markers: [
    { x: 0, label: "x = 0" },
    { x: L, label: "x = L" },
  ],
}));

<LessonHook eyebrow="Why this matters">
  At most energies a barrier partially reflects a particle that
  classically should sail right over it. At a specific, predictable
  sequence of energies, it becomes perfectly, exactly transparent.
</LessonHook>

## Motivation

Tunneling and the Finite Barrier covered $E<V_0$: a barrier taller than
the particle's energy, crossed only by the exponentially-suppressed
<Term id="quantum-tunneling">tunneling mechanism</Term>. This lesson covers the complementary regime,
$E>V_0$: the particle has enough energy to classically cross the
barrier, so *something* transmits. Classically all of it does, every
time, and the barrier is no obstacle worth mentioning. Quantum mechanics
disagrees on both counts. At most energies the barrier reflects part of
the beam even though the particle "should" sail over it. Then, at a
specific and predictable sequence of energies, the reflection vanishes
*completely*: $T=1$, exactly, not approximately. A barrier that is by
every classical measure a solid obstruction becomes perfectly
transparent.

## Intuition

A barrier with $E>V_0$ has the *same* three-region structure as the
step-potential problem, just with a third region (transmitted wave)
past a *second* boundary. The difference that matters: inside the
barrier the <Term id="wavefunction">wavefunction</Term> still **oscillates** (not decays, since
$E>V_0$ there means $k$ is real inside too), unlike the tunneling
case's exponential decay. Two boundaries also means two reflected waves,
one from entering the barrier and one from leaving it, and those two can
interfere with each other. Where they cancel, nothing reflects. That
cancellation is the resonance.

## Mathematical Development

### The three-region setup

Barrier of height $V_0$, full width $L$, spanning $0$ to $L$; particle
energy $E>V_0$. Inside the barrier, $k_2=\sqrt{2(E-V_0)}$ (real,
oscillatory, the key difference from tunneling's $\kappa=\sqrt{2(V_0-E)}$).
Matching $\psi,\psi'$ at *both* $x=0$ and $x=L$ (four equations, the same
kind of boundary-matching used for the step, just doubled) gives, after
elimination of every <Term id="amplitude">amplitude</Term> except the incident and transmitted ones,
the standard closed-form result (a longer algebraic exercise than the
single-step case, not repeated in full here):

$$
\boxed{\;T = \left[1 + \frac{V_0^2\sin^2(k_2L)}{4E(E-V_0)}\right]^{-1}\;}
$$

This platform's `barrierScatteringTransmission` function implements that
formula, tested against the $V_0\to0$ limit ($T\to1$, no barrier) and
against the resonance condition below.

### The resonance condition

$T=1$ exactly whenever $\sin(k_2L)=0$, i.e.

$$
k_2L = n\pi, \qquad n=1,2,3,\ldots
$$

At these special energies, the barrier is **perfectly transparent**:
every incident particle transmits and none reflects, despite the barrier
being, in every other sense, a real obstacle.

## Physical Interpretation

This is the quantum-mechanical counterpart of an anti-reflective optical
coating. A thin film reflects light at both of its surfaces, and at
specific wavelengths those two reflections destructively interfere,
cancelling the net reflection. Here the two boundaries of the barrier
play the role of the film's two surfaces, and the resonance condition
$k_2L=n\pi$ is the same "round-trip phase is a multiple of $2\pi$"
condition that governs optical thin-film interference. Light and matter
agree here because both obey a wave equation matched across a boundary,
and neither derivation ever asked what kind of wave it was.

The effect is engineered on purpose. Resonant tunneling diodes (RTDs)
use a thin quantum well sandwiched between two barriers, engineered so
a transmission resonance sits at a specific electron energy. Applying a
voltage shifts that resonance relative to the incoming electrons: as
the bias increases, current first rises sharply as electrons sweep
through the resonance, then *drops* as the bias pushes past it, even
though the voltage keeps climbing. That drop is negative differential
resistance, a behavior no ordinary resistor has, and it makes RTDs
useful in high-frequency oscillators and fast switching circuits. The
device runs on the same physics as this lesson's single barrier, just
with two barriers instead of one and the resonance tuned electrically
instead of by sweeping $L$ by hand.

## Worked Example

**For $E=5$, $V_0=2$ (natural units), find the barrier width $L$ that
produces the first resonance, and confirm $T=1$ there.**

$$
k_2 = \sqrt{2(5-2)} = \sqrt6 \approx 2.4495
$$

First resonance ($n=1$): $L=\pi/k_2\approx1.2825$. Substituting into the
transmission formula, $\sin(k_2L)=\sin(\pi)=0$ exactly, so the
$\sin^2$ term vanishes and $T=1/[1+0]=1$, which this platform's test
suite for `barrierScatteringTransmission` asserts independently.
For comparison, at a *non*-resonant width like $L=1$: $k_2L\approx2.449$
(not a multiple of $\pi$), giving $T\approx0.9736$, still high (a
narrow barrier relative to the wavelength), but not exactly 1.

## Common Mistakes

<Callout type="warning">
**Confusing this formula with the tunneling ($E<V_0$) case.** The
tunneling regime's transmission falls off roughly as $e^{-2\kappa L}$
(Tunneling and the Finite Barrier); this regime's oscillates with $L$
via $\sin^2(k_2L)$ and can reach exactly $1$, qualitatively different
behavior, because the wavefunction oscillates rather than decays inside
the barrier.
</Callout>

<Callout type="note">
**Thinking resonance requires fine-tuning both $E$ and $L$
independently.** For a *fixed* barrier ($V_0,L$ given), resonances occur
at a discrete, predictable sequence of *energies* $E$ satisfying
$k_2(E)L=n\pi$, an experimentally realistic, adjustable knob (scan the
incident particle's energy) rather than an impossible-to-achieve
coincidence.
</Callout>

## Summary

- For $E>V_0$, transmission through a barrier is
  $T=[1+V_0^2\sin^2(k_2L)/(4E(E-V_0))]^{-1}$, oscillating with barrier
  width rather than decaying exponentially (the tunneling regime's
  behavior).
- $T=1$ exactly whenever $k_2L=n\pi$: perfect transmission at discrete
  resonant energies, directly analogous to anti-reflective optical
  coatings.
- This regime is the complement to Wave Mechanics' tunneling treatment.
  Together, $E<V_0$ and $E>V_0$ describe scattering off a rectangular
  barrier at every energy.
