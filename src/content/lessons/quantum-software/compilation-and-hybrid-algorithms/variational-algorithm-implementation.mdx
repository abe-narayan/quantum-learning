## Engineering Development

### Building the ansatz with QuantumCircuit

Instead of Quantum Algorithms II's `ansatzState` (a direct matrix
computation), build the identical physical ansatz using
`QuantumCircuit`:

```
const circuit = new QuantumCircuit(1);
circuit.ry(0, theta);
const state = runCircuit(circuit);
```

This is genuinely the "software" version of the same physics, the
circuit-as-data pattern (Circuit Representation in Code) applied to a
variational algorithm specifically.

### Computing the cost function

For the simplest case, $H=Z$: since $\langle Z\rangle=P(0)-P(1)$
directly from measurement probabilities, no separate matrix-expectation
machinery is even needed.
`state.probabilities()[0] - state.probabilities()[1]` computes
$\langle Z\rangle$ directly from the circuit's own output.

### The optimization loop, and verification

A simple grid search over $\theta\in[0,2\pi]$ (the same
"smallest correct optimizer" choice Quantum Algorithms II's `runVqe`
already used) finds the minimum at exactly $\theta=\pi$, with
$\langle Z\rangle=-1$, matching `exactGroundStateEnergy(PAULI_Z)=-1`
EXACTLY, confirming the `QuantumCircuit`-based implementation reproduces
Quantum Algorithms II's matrix-based result precisely, despite being
built through a completely different (software-first) code path. This
page's own grid search, run live over all 41 points, traces out the
full cost landscape the optimizer is searching:

### Extending to a nontrivial Hamiltonian

For $H=0.6Z+0.8X$ (exact ground energy $-1$, since
$\sqrt{0.6^2+0.8^2}=1$), a two-parameter ansatz
(`circuit.ry(0,theta).rz(0,phi)`) with $\langle H\rangle$ computed via
direct matrix application to the circuit's output amplitudes,
grid-searched over both $\theta$ and $\phi$, converges to
$\langle H\rangle\approx-0.9996$, within $0.04\%$ of the true $-1$
ground energy, limited only by grid resolution (a finer grid would
close the gap further, exactly as the Variational Method course already
established for a completely different, continuous-wavefunction, trial
family).

Unlike the single-parameter case, this cost landscape is genuinely
two-dimensional: $\langle H\rangle$ is now a function of a $(\theta,\phi)$
plane, not a single curve. This page's own $15\times15$ grid search,
run live over both parameters, traces out that entire plane as a
color-mapped heatmap, with the grid's own minimum marked directly:

## Physical Interpretation

This is the entire Quantum Software pillar's thesis made concrete: the
SAME physics (VQE, already fully built in Quantum Algorithms II) can be
implemented via genuinely different SOFTWARE PATTERNS (direct matrix
computation vs. circuit-as-data), and, when both are correct, they
agree exactly. Software structure is a real engineering choice; it
doesn't change the underlying physics being computed.

## Worked Example

**Confirm the QuantumCircuit-based single-parameter result matches
Quantum Algorithms II's exactGroundStateEnergy exactly, and explain why
exact (not approximate) agreement is expected here specifically.**

Grid search over `circuit.ry(0,theta)`'s $\langle Z\rangle$ finds the
minimum at $\theta=\pi$ (a grid point landed exactly on it), giving
$-1$, matching `exactGroundStateEnergy(PAULI_Z)=-1` to the full
precision tested. Exact agreement (not just "close") is expected here
because $H=Z$'s ground state is EXACTLY $|1\rangle$, which the
$R_y(\theta)$ ansatz family can reach exactly at $\theta=\pi$, unlike
the two-parameter $0.6Z+0.8X$ case, where the grid search's finite
resolution leaves a small (but shrinkable) residual gap.

## Common Mistakes

<Callout type="mistake">
**Assuming a QuantumCircuit-based and a matrix-based VQE implementation
would give different physics.** They compute the identical underlying
quantities. This lesson's exact agreement with `exactGroundStateEnergy`
confirms this directly, not just plausibly.
</Callout>

<Callout type="mistake">
**Expecting every optimization to converge exactly, the way the
single-parameter H=Z case did.** The two-parameter case's small residual
gap (grid resolution, not a real physics discrepancy) is the more
typical situation. Exact convergence at $\theta=\pi$ for $H=Z$ is a
special, checkable coincidence of that specific problem's structure.
</Callout>
